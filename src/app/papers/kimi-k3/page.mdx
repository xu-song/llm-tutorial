# Kimi K3：开源 3T 的混合注意力与 LatentMoE

2026 年 7 月，月之暗面发布了 Kimi K3：2.78T 总参数、每 token 激活 104.2B 的 MoE 模型——**世界首个开源的 3T 级模型**，原生多模态、1M token 上下文。<Cite n={1} />它整体落后 Claude Fable 5 与 GPT-5.6 Sol，但领先其余开源与多数闭源模型，官方口径是「开源最强」。这篇笔记拆解它相对 [K2](/papers/kimi-k2) 的三处架构跃迁：**KDA 线性注意力与 MLA 的混合**、把注意力搬进深度方向的 **AttnRes**、以及在 896 专家的极端稀疏下稳住优化的 **Stable LatentMoE**——三件事合计换来约 **2.5× scaling efficiency**。<Cite n={[1,2,3]} />

> 📌 前置：K3 是 [Kimi K2](/papers/kimi-k2) 的直接续作（Muon 优化器、agentic 数据合成、joint RL 全部继承）；RL 部分与 [Kimi K1.5](/papers/kimi-k15) 一脉相承。稀疏注意力路线可对照 [DeepSeek-V3.2](/papers/deepseek-v3-2) 的 DSA 阅读。

## 一、动机：3T 级模型撞上的三堵墙

K2 的答案（超稀疏 MoE + MuonClip）解决「1T 训练稳不稳」；K3 要解决「再往上翻 2.7 倍，哪些部件先碎」。<Cite n={[1,2]} />报告的诊断：纯 softmax 注意力在 1M 上下文下计算与显存都不可行；残差连接把全部历史压进一个向量，深模型的信息流有瓶颈；MoE 专家数逼近千级时，激活爆炸与负载均衡双双失灵。对应的三个解法是混合 KDA–MLA、AttnRes 与 Stable LatentMoE。先看 K2 → K3 的架构账本（论文 Table 1）:<Cite n={1} />

## 二、KDA：先擦除、再写入的线性注意力

### 2.1 递归：delta rule + 通道级遗忘门

KDA（Kimi Delta Attention）是线性注意力：维护一个固定大小的循环状态 $\mathbf{S}_t \in \mathbb{R}^{d_k \times d_v}$，读写都是 O(1)，序列方向天然线性。<Cite n={[1,3]} />它的特别之处是在 vanilla 线性注意力的加性更新 $S_t = S_{t-1} + k_t v_t^\top$（只加不减）之前，先做一步**擦除**:

$$
\mathbf{S}_t=\big(\mathbf{I}-\beta_t\mathbf{k}_t\mathbf{k}_t^\top\big)\operatorname{Diag}(\mathbf{\alpha}_t)\,\mathbf{S}_{t-1}+\beta_t\mathbf{k}_t\mathbf{v}_t^\top,\qquad \tilde{\mathbf{o}}_t=\mathbf{S}_t^\top\mathbf{q}_t
$$

拆开看三项：① $\operatorname{Diag}(\mathbf{\alpha}_t)$,$\mathbf{\alpha}_t \in (0,1)^{d_k}$ 是**通道级遗忘门**，每个 key 通道有独立的单步保留率；② $(\mathbf{I}-\beta_t\mathbf{k}_t\mathbf{k}_t^\top)$ 是 delta rule 的擦除项——写入新值之前，先把 $k_t$ 方向上的旧分量投影掉，等价于「改写」而非「叠加」；③ $\beta_t \in (0,1)$ 控制写入强度。$\mathbf{q}_t, \mathbf{k}_t$ 经过 ShortConv + Swish + L2 归一化，$\mathbf{\alpha}_t$ 与 $\beta_t$ 均由 $\mathbf{x}_t$ 经 sigmoid 产生。

两个 K3 特有的修正：

- **下界对数衰减**：Kimi Linear 用 $-\mathrm{Softplus}$ 映射，log-decay 无下界；K3 改为缩放 sigmoid $\mathbf{g}_t = g_{\min}\operatorname{Sigmoid}(e^A\mathbf{z}_t) \in (g_{\min}, 0)$($g_{\min}=-5$)。<Cite n={1} />有界区间让 chunkwise 计算的所有因果 tile 都能走稠密 Tensor Core 矩阵乘，而不是逐位置对的特殊计算；
- **满秩输出门**：输出从 Kimi Linear 的低秩门换成满秩投影 $\mathbf{y}_t=\mathbf{W}_o\big[\operatorname{Sigmoid}(\mathbf{W}_g\mathbf{x}_t)\odot\operatorname{RMSNorm}(\tilde{\mathbf{o}}_t)\big]$——数据相关的逐通道门控，先 RMSNorm 再门控，防循环状态幅值漂移。

### 2.2 混合配比：每 3 层 KDA 配 1 层 Gated MLA

线性注意力省算力但有损；K3 的做法是 69 层 KDA 与 24 层 Gated MLA 周期交错（**每个块 3 KDA + 1 MLA**）。<Cite n={1} />MLA 层提供全局精确交互，KDA 层提供位置敏感、偏重近期的序列混合。更彻底的是**位置编码整个扔掉**：K3 对所有 MLA 层用 NoPE（无显式位置编码），位置信息由 KDA 的门控与衰减机制隐式承载——因此上下文从 128K 扩到 1M，**不需要任何 RoPE 缩放或插值**。

配 KCP（KDA Context Parallelism）做序列维切分，百万 token 训练才成为可能：段间转移矩阵可以并行求值再合并，每段的精确初始状态可恢复。

用 numpy 手写一遍 delta rule 递归，对比 vanilla 加性线性注意力，直观感受「先擦除再写入」:

<CodeRunner defaultCode={String.raw`
import numpy as np

rng = np.random.default_rng(0)
d_k, d_v, T = 16, 8, 200                   # key 维 / value 维 / 序列长
k = rng.normal(size=(T, d_k))
k /= np.linalg.norm(k, axis=1, keepdims=True)   # 模拟 L2Norm 后的 key
v = rng.normal(size=(T, d_v)) * 0.3
beta = rng.uniform(0.3, 1.0, size=T)            # 写入强度
alpha = rng.uniform(0.9, 1.0, size=(T, d_k))    # 通道级保留率

# —— vanilla 线性注意力:只加不减 ——
S_add, S_kda = np.zeros((d_k, d_v)), np.zeros((d_k, d_v))
n_add, n_kda = [], []
for t in range(T):
    S_add = S_add + np.outer(k[t], v[t])             # 加性更新
    n_add.append(np.linalg.norm(S_add))
    # —— KDA:先通道衰减、再擦除 k 方向、后写入 ——
    S_kda = (np.eye(d_k) - beta[t]*np.outer(k[t], k[t])) @ (alpha[t][:,None]*S_kda)
    S_kda = S_kda + beta[t]*np.outer(k[t], v[t])     # delta 写入
    n_kda.append(np.linalg.norm(S_kda))

print("序列长 T =", T)
print("vanilla 状态范数:  早期=%.2f  末=%.2f  (单调膨胀,旧信息撤不掉)" % (n_add[10], n_add[-1]))
print("KDA    状态范数:  早期=%.2f  末=%.2f  (有界,可改写)" % (n_kda[10], n_kda[-1]))

# —— 检索精度:写入 200 个 (k_t, v_t) 对,再逐个用 k_t 查询 ——
# 干净的关联记忆要求 k_i 查回 v_i 且互不串扰:k_i S v_j 应接近 0 (i≠j)
cross_add, cross_kda = [], []
for t in range(0, 200, 10):
    # 用随机无关方向 k_rand 探测状态里残留的 v_t 分量(模拟串扰)
    kr = rng.normal(size=d_k); kr /= np.linalg.norm(kr)
    cross_add.append(abs(kr @ S_add @ v[t]) / (np.linalg.norm(v[t]) + 1e-9))
    cross_kda.append(abs(kr @ S_kda @ v[t]) / (np.linalg.norm(v[t]) + 1e-9))
print()
print("无关方向上的串扰(|k_rand S v_t| / |v_t|):")
print("  vanilla 平均=%.3f   KDA 平均=%.3f" % (np.mean(cross_add), np.mean(cross_kda)))
print("加性更新把所有历史混叠在一起;擦除 + 衰减让状态保持「可寻址」")

## 三、AttnRes：残差连接的注意力化

标准残差把所有前层信息压进单个 $\mathbf{h}_l$——报告的类比很妙：这相当于「深度方向的 RNN」。<Cite n={1} />既然序列方向上 [Transformer](/papers/attention-transformer) 用注意力取代了 RNN，深度方向也可以照搬：**AttnRes 让第 $l$ 层选择性检索所有前层的表示，而不是均匀累加**。每层学一个伪查询 $\mathbf{q}_l=\mathbf{w}_l$，键值取前层输出 $\mathbf{k}_i=\mathbf{v}_i=f_i(\mathbf{h}_i)$（含第 0 层的词嵌入），注意力核带 RMSNorm 防大层主导：

$$
\phi(\mathbf{q},\mathbf{k})=\exp\big(\mathbf{q}^\top\operatorname{RMSNorm}(\mathbf{k})\big),\qquad
\alpha_{i\to l}=\frac{\phi(\mathbf{q}_l,\mathbf{k}_i)}{\sum_{j=0}^{l-1}\phi(\mathbf{q}_l,\mathbf{k}_j)},\qquad
\mathbf{h}_l=\sum_{i=0}^{l-1}\alpha_{i\to l}\cdot\mathbf{v}_i
$$

93 层存所有前层表示开销 O（Ld）。**Block AttnRes** 把 L 层切成 N 个块，块内求和成单个表示 $\mathbf{b}_n=\sum_{j\in\mathcal{B}_n}f_j(\mathbf{h}_j)$，注意力只在 N 个块表示上做——开销降到 O（Nd）。经验上 N≈8 就能恢复大部分收益；K3 的 93 层切成 8 个 12 层的块（计嵌入层共 9 块）。这也给了投机解码一个抓手：EAGLE-3 风格的 draft 模型直接取第 1、4、末尾 AttnRes 块的输出做特征融合。

## 四、Stable LatentMoE：896 选 16 的稳定性工程

### 4.1 潜空间路由 + 两个失效模式

激活 16/896（sparsity 56）的极端稀疏带来一个问题：常规 MoE 每个被选专家都吃全宽 $d$=7168 的 token 表示，通信量随路由倍数暴涨。**LatentMoE** 的解法是分层：共享专家（2 个）保留全宽通路做通用变换，路由专家全部工作在 $\ell$=3584 的潜空间（0.5× 宽）:<Cite n={1} />

$$
\mathbf{u}=\sum_{i\in\mathcal{T}_k(\mathbf{x})}p_i\,E_i^{\mathrm{routed}}(\mathbf{W}^{\downarrow}\mathbf{x}),\qquad
\mathbf{y}=\sum_{j=1}^{N_s}E_j^{\mathrm{shared}}(\mathbf{x})+\mathbf{W}^{\uparrow}\operatorname{RMSNorm}(\mathbf{u})
$$

但 $W^{\downarrow}$ → 门控多分支 FFN → $W^{\uparrow}$ 近乎**四个连续矩阵乘**的链，在 2.8T 参数量级上直接激活爆炸；同时 896 个专家也超出了既有无辅助损失均衡的适用域。Stable LatentMoE 用三个组件逐一压制：<Cite n={1} />

1. **上投影前加 RMSNorm**（见上式）——爆炸的内部激活先被归一化再升维；
2. **SiTU-GLU 激活**:$\big[\beta_1\tanh(\mathbf{W}_g\mathbf{x}/\beta_1)\odot\operatorname{Sigmoid}(\mathbf{W}_g\mathbf{x})\big]\odot\big[\beta_2\tanh(\mathbf{W}_u\mathbf{x}/\beta_2)\big]$，取 $\beta_1=4,\beta_2=25$，逐点输出有界($|f|\le\beta_1\beta_2=100$)，而 SwiGLU 无界；$\beta\to\infty$ 时退回 SwiGLU;
3. **Quantile Balancing** 换掉固定步长符号更新（下节）。

### 4.2 Quantile Balancing：从「迈固定步子」到「直接解出均衡点」

路由沿用 sigmoid 打分 + bias 干预选择（不进梯度、不改混合权重）:

$$
\mathcal{T}_i=\operatorname{argtop}_k(\mathbf{s}_i+\mathbf{b}),\qquad
p_{i,j}=\frac{s_{i,j}}{\sum_{r\in\mathcal{T}_i}s_{i,r}}
$$

老的均衡法([DeepSeek-V3](/papers/deepseek-v3) 同款)每步给 bias 加固定符号修正 $b_j \leftarrow b_j + \gamma\,\operatorname{sign}(\bar\ell-\ell_j)$:$\gamma$ 大了负载震荡，小了追不上。896 个专家时彻底不够用。**QB 的思路是跳过迭代，一步解出「让每个专家恰好拿到目标负载」的 bias**：m 个 token 路由到 n 个专家选 top-k，目标负载 $q=mk/n$；一次前向里把 Top-k 换成 Top-（k+1），第 （k+1） 名就是 token $i$ 的入选门槛 $\alpha_i$；然后取<Cite n={1} />

$$
\hat b_j \leftarrow -\operatorname{quantile}_{1-k/n}\big(\mathbf{s}_{:,j}-\mathbf{\alpha}\big),\qquad
\mathbf{b} \leftarrow \hat{\mathbf{b}}-\operatorname{mean}(\hat{\mathbf{b}})\,\mathbf{1}
$$

直觉：margin $s_{i,j}-\alpha_i$ 是「token $i$ 选专家 $j$ 还差多少」；把 bias 设在 margin 的 $(1-k/n)$ 分位上，恰好有 $q$ 个 margin 越过阈值。这一步是对均衡指派问题对偶形式的精确坐标最小化——**没有学习率类的超参数**，千级专家也在几步内收敛。大规模训练时用每专家直方图估计分位数（区间计数、可加合并，一次 all-reduce 汇总）。

<CodeRunner defaultCode={String.raw`
import numpy as np

rng = np.random.default_rng(3)
m, n, k = 4096, 64, 8              # token 数 / 专家数 / 每 token 激活
S = rng.beta(2, 5, size=(m, n))    # 模拟 sigmoid 路由分(天然不均衡)
target = m * k / n

def loads(S, b):
    sel = np.argsort(-(S + b), axis=1)[:, :k]      # top-k 选择
    return np.bincount(sel.ravel(), minlength=n)

b_sign = np.zeros(n); b_qb = np.zeros(n)
print(f"目标负载 q = {target:.0f} / 专家(m={m}, n={n}, k={k})")
print(f"{'步':>4s} {'符号更新 max/min':>20s}   {'QB max/min':>16s}")

for step in range(6):
    # —— 符号更新:gamma * sign(目标 - 实际) ——
    l = loads(S, b_sign)
    b_sign += 0.05 * np.sign(target - l)
    # —— QB:Top-(k+1) 取门槛,margin 分位数一步定 bias ——
    a = -np.sort(-(S + b_qb), axis=1)[:, k]        # 第 k+1 名 = 入选门槛 alpha_i
    b_qb = -np.quantile(S - a[:, None], 1 - k/n, axis=0)
    b_qb -= b_qb.mean()

    ls, lq = loads(S, b_sign), loads(S, b_qb)
    print(f"{step:>4d} {ls.max():>8d} / {ls.min():<8d}   {lq.max():>6d} / {lq.min():<6d}")

print()
print("符号更新:步长小收敛慢,步长大震荡(896 专家时彻底追不上)")
print("QB:一步逼近均衡,无学习率类超参数")

## 五、训练与后训练

**预训练**：Muon 升级为 **Per-Head Muon**——Q/K/V 投影的动量按头切分、逐头正交化，避免大梯度头主导共享更新方向，Newton-Schulz 在窄块上也更便宜；沿用 K2 的权重裁剪。<Cite n={[1,2]} />学习率用**余弦衰减**——scaling law 研究发现余弦与 WSD 的最优超参差异显著，固定最小学习率对比下余弦始终占优。上下文四阶段爬升（预训练 8K→64K、cooldown 256K→1M），长上下文数据靠合成补足。视觉塔 **MoonViT-V2**（401M，27 层，patch 14）**从头用 next-token prediction 训练**——放弃 SigLIP 初始化的原因是稳定性：预训练编码器接上 LLM 后联合优化梯度尖峰频繁；从头训练反而更稳，文本视觉从头混合训练（原生多模态，非后接编码器）。<Cite n={1} />

**后训练**是「专家网络 + 蒸馏」的放大版：RL 在通用 / agentic / coding 三域 × （low, high， max） 三档推理强度上各训一个专家（共 9 个），再用 **MOPD 多教师在线蒸馏**合并回单模型——蒸馏奖励是对数比 $\operatorname{clip}(\mathrm{sg}(\log\pi_{\text{teacher}}/\pi_\theta), -R_{\max}, R_{\max})$，按域和强度切换教师。<Cite n={[1,5]} />三个值得记的设计：

- **Reasoning Effort RL**：每道题按冷启动模型估一个 token 预算 $b_0(x)$，轨迹总 token 超过 $\tau\cdot b_0(x)$ 则奖励直接记 −1；$\tau$ 从大到小退火，产出低/高/最大三档强度的专家——「想多久」变成可训练的旋钮；
- **Agentic GRM**：不可验证任务沿用 K2 的锦标赛式两两比较，但 judge 被强制走四步协议（读产出 → 生成 rubric → 逐项打分 → 记分板），并配冗长度控制——超过 $\sigma\ell_0$ 的候选自动输掉比较，专防「长即好」的 reward hacking;
- **部署感知**：MXFP4 量化感知训练贯穿整个 SFT+RL（专家权重 MXFP4、激活 MXFP8），MTP 层转 EAGLE-3 draft（7 步展开）直接按接受率优化。

百万 token 的 agentic RL 靠两件基建：partial rollout（λ 比例完成即暂停换批，长尾轨迹不堵迭代）+ 外部 KV cache 池（空闲前缀写回 CPU DRAM、复用前预取，KDA 状态与 MLA 块同生命周期）。沙箱是新开源的 **AgentENV**(microVM，支持检查点/恢复)，外加容器与 GPU 沙箱覆盖不同任务面。

## 六、RL 任务合成：知识图谱引导

K2 已经证明 agentic 数据要「造环境」；K3 把「造任务」也工程化了。<Cite n={[1,2]} />**知识图谱引导的任务合成**维护一棵自演化的分层 DAG：粗粒度种子节点出发，每个节点派一个 agent 做多轮网络检索、查重去重后挂上更细的子节点，直到概念足够原子；再按目标分布采样节点（单个或相关组合）生成关键词，连祖先上下文一起检索源材料，最后选任务类型合成题目。合成出的任务覆盖知识密集与编码两个域，供 RL 直接消费。

## 八、局限与批判

1. **整体仍落后第一梯队**：报告自己承认 trailing Fable 5 与 GPT-5.6 Sol；差距集中在深度推理（CritPt 23.4 vs Sol 32.3）与知识密集任务——后者受预训练 FLOPs 总量约束，不是后训练能补的。
2. **线性注意力的精度税**：69/93 层是 KDA，长程精确检索靠 24 层 MLA 兜底；RULER 类精确检索基准上的表现报告没有单独披露，与 [DeepSeek-V3.2](/papers/deepseek-v3-2) 的 DSA（保留精确 softmax、只稀疏化）是两种哲学，孰优孰劣尚无同台对比。
3. **许可证与可复现性**：论文本身 CC BY-NC-ND；权重走 Kimi K3 License（商用需登记），比 K2 的 Modified MIT 收紧。QB、KCP、MoonEP 等组件的工程实现门槛不低，复现 3T 训练超出几乎所有人的预算——方法可学，结果难验。
4. **后训练叙事的密度问题**：9 专家 + MOPD + Reasoning Effort RL + Agentic GRM + QAT 的流水线堆得很满，但各组件的独立消融有限；「effort 分档」实际收益多大、蒸馏与 RL 各占多少，报告未拆开。

## 小结

- **架构**：93 层混合注意力（69 KDA + 24 Gated MLA，3：1 交错）+ AttnRes(深度方向的注意力，块化到 N=8)+ Stable LatentMoE（896 路由专家活在 3584 维潜空间、16 激活、2 全宽共享专家）；NoPE 靠 KDA 门控隐式编码位置，免改位置编码直扩 1M。
- **稳定性三件套**：潜空间上投影前 RMSNorm、SiTU-GLU 有界激活、Quantile Balancing 分位数定 bias——分别压制 2.8T 级的激活爆炸与千级专家的均衡失灵。
- **训练**：Per-Head Muon + 余弦衰减 + 原生多模态（视觉塔从头 next-token 训练），换来对 K2 约 2.5× scaling efficiency；后训练 3 域 × 3 强度共 9 个 RL 专家，MOPD 蒸馏合并。
- **结果**:agentic（SWE-Marathon 42.0、BrowseComp 91.2）与多模态文档（OmniDocBench 91.1）多项最优，整体开源第一、总榜落后 Fable 5 与 GPT-5.6 Sol；亮点是用闭源旗舰零头的成本站上性价比前沿。

K3 的信息量在于：它是「线性注意力 + 极端稀疏 MoE + 深度方向注意力」三条非主流路线第一次在 3T 量级上的合流验证——每一件单看都不新，但让它们在 2.78T 参数上同时稳定工作，靠的是一整套针对性稳定性工程（RMSNorm 位置、有界激活、分位数均衡、逐头正交化）。读懂 K3，基本就读懂了 2026 年开源前沿模型的架构赌注。
