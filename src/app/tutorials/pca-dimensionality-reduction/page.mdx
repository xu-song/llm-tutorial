# 📐 PCA 降维

数据动辄几十、上百个特征,既难可视化、又拖慢模型,还可能冗余(很多特征高度相关)。**主成分分析(PCA)** 是最经典的**降维**方法:它把高维数据投影到少数几个新方向上,在尽量少丢信息的前提下大幅压缩维度。

> 想象把一团斜着分布的点「拍扁」到一条线上 —— 选对了方向,虽然降成一维,却几乎保留了全部「散布」信息。

## 核心思想:沿方差最大的方向投影

PCA 的关键洞察:**信息 ≈ 方差(数据的散布程度)**。一个方向上的数据越分散,它承载的信息越多。PCA 要找的就是**让投影后方差最大**的方向 —— 这个方向叫**第一主成分(PC1)**;与它正交、方差次大的是 PC2,以此类推。

降维就是只保留前几个主成分,丢掉方差很小(信息量很低)的方向。

Shlens 的经典教程 *A Tutorial on Principal Component Analysis* 里有一张直观的示意图:对同一团二维数据,沿不同方向投影,保留的方差天差地别 —— 「拍扁」的角度选错,信息就挤没了:

## 动手旋转投影方向

下面是一团沿对角线相关分布的二维数据(蓝点)。**拖动滑块旋转红色投影轴**,红点是数据投影到该轴上的位置,右侧实时显示**投影保留的方差占比**。试着找到让占比**最大**的角度 —— 那就是 PC1:

<PCAExplorer />

你会发现:

- 当红线**对准数据的拉伸方向**时,投影点铺得最开,保留方差接近 100%
- 当红线**垂直于**数据方向时,所有点挤成一团,方差损失惨重
- 这正是 PCA 自动做的事:**解出方差最大的方向,无需手动旋转**

那 PCA「解方向」到底怎么解?不是靠拖滑块试,而是一步到位的线性代数——**协方差矩阵的特征分解**。特征向量就是各主成分方向,对应的特征值就是该方向上的方差:

```
# PCA 伪代码(特征分解版)
Xc = X - X.mean(axis=0)          # 1. 中心化:每列减去均值
C  = (Xc.T @ Xc) / (n - 1)       # 2. 协方差矩阵 (d×d)
vals, vecs = eig(C)              # 3. 特征分解:vecs 是方向, vals 是该方向方差
idx  = argsort(vals)[::-1]       # 4. 按特征值降序排(方差大的主成分在前)
W    = vecs[:, idx[:k]]          # 5. 取前 k 个特征向量(前 k 个主成分)
Z    = Xc @ W                    # 6. 投影:n×d → n×k,完成降维
# 解释方差占比 = vals[idx[:k]] / vals.sum()
```

第 3 步也常用 **SVD**(对 `Xc` 直接奇异值分解)替代,数值更稳,`scikit-learn` 内部就是这么做的——但「中心化 → 找方差最大的正交方向 → 投影」这条主线不变。

Shlens 的教程里也画出了 SVD 的几何图景:任何数据矩阵都可以分解成「旋转 × 拉伸 × 旋转」,其中那次拉伸正是各主成分方向上的伸缩比例(奇异值)—— 特征分解与 SVD 殊途同归:

## 用 scikit-learn 实现

真实代码里,PCA 几行就能完成,并能告诉你每个主成分**解释了多少方差**:

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.decomposition import PCA

# 一团沿对角线相关的二维数据
rng = np.random.RandomState(0)
base = rng.randn(100, 1)
X = np.hstack([base * 2 + rng.randn(100, 1) * 0.3,
               base * 1 + rng.randn(100, 1) * 0.3])

pca = PCA(n_components=2).fit(X)
print("各主成分解释的方差占比:", pca.explained_variance_ratio_.round(3))
print("PC1 方向(单位向量):", pca.components_[0].round(3))

# 只保留 1 个主成分:二维 → 一维,信息损失多少?
keep1 = pca.explained_variance_ratio_[0]
print(f"\\n只保留 PC1 → 维度减半,仍保留 {keep1:.1%} 的信息")
`} />

## 经典案例:用 PCA 可视化高维数据

PCA 最实用的场景之一:把几十维数据压到 2 维,**画出来用眼睛看**。下面把经典的鸢尾花数据集(4 维)降到 2 维:

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.decomposition import PCA
from sklearn.datasets import load_iris

iris = load_iris()
X, y = iris.data, iris.target   # 150 样本 × 4 特征

pca = PCA(n_components=2)
X2d = pca.fit_transform(X)

print("原始维度:", X.shape, "→ 降维后:", X2d.shape)
print("两个主成分共保留方差:", pca.explained_variance_ratio_.sum().round(3))

# 看三类花在 2D 主成分空间里是否分得开
for c in range(3):
    pts = X2d[y == c]
    print(f"  类 {c} ({iris.target_names[c]}): "
          f"PC1 范围 [{pts[:,0].min():.1f}, {pts[:,0].max():.1f}]")
`} />

> 💡 仅用 2 个主成分就保留了鸢尾花约 **98%** 的方差 —— 4 维几乎无损地压成了 2 维,正好能画在平面上。

## 典型应用场景

- **数据可视化**:把高维数据降到 2D/3D 画散点图,肉眼观察分组与离群点
- **加速 / 去噪**:训练前先降维,减少特征数、去掉噪声方向,模型更快更稳
- **图像压缩**:人脸图像用前几十个主成分(特征脸 Eigenfaces)即可近似重建
- **去除多重共线性**:主成分两两正交,天然消除特征间的高度相关
- **基因/金融数据**:成千上万维特征,先 PCA 抓住主要变化方向

## 常见问题 FAQ

**Q:PCA 之前一定要标准化吗?**
通常要。PCA 看方差,若某特征量纲特别大(如「收入」vs「年龄」),会主导主成分。一般先用 `StandardScaler` 标准化,让各特征同等参与。

**Q:该保留几个主成分?**
常看**累计解释方差比**:保留到累计 90%~95% 即可。也可画「碎石图(scree plot)」找拐点,思路和 K-means 的肘部法则类似。

**Q:PCA 和特征选择有什么区别?**
特征选择是**挑出原始特征的子集**;PCA 是**构造新特征**(原特征的线性组合)。PCA 的主成分通常没有直观的业务含义,牺牲了可解释性换取压缩率。

**Q:PCA 是监督还是无监督?**
**无监督** —— 它只看特征 `X` 的方差结构,完全不用标签 `y`。若想用标签做有监督降维,可用 LDA(线性判别分析)。

**Q:PCA 只能处理线性结构吗?**
是的,它找的是线性方向。数据呈非线性流形(如卷曲的瑞士卷)时,PCA 效果有限,可改用 **t-SNE**、**UMAP** 或 **核 PCA**。

## 动手作业

1. **手动找 PC1**:在上面交互组件里旋转红线,记录让保留方差最大的角度,再对比 `sklearn` 解出的 `pca.components_[0]` 方向是否一致。
2. **碎石图**:对鸢尾花数据取 `n_components=4`,画出 `explained_variance_ratio_` 的柱状图,观察方差如何集中在前几个主成分。
3. **降维 + 分类**:先用 PCA 把数据降到 2 维,再训练 KNN 或逻辑回归,对比降维前后的准确率和速度。
4. **重建误差**:用 `pca.inverse_transform` 把降维结果还原回原空间,计算与原始数据的均方误差,体会「保留方差越多,重建越准」。
5. **思考题**:为什么说「方差最大的方向 ≈ 信息最多的方向」?如果两个特征完全无关(各自独立),PCA 还能压缩吗?

## 小结

| 要点 | 说明 |
|---|---|
| 目标 | 找方差最大的正交方向(主成分),投影降维 |
| 直觉 | 方差 ≈ 信息;沿数据拉伸方向投影损失最小 |
| 关键指标 | **解释方差比**,累计到 90%+ 决定保留几维 |
| 前置 | 一般先**标准化**,PCA 对量纲敏感 |
| 局限 | 只抓线性结构、主成分难解释;非线性用 t-SNE/UMAP |

> 🎯 一句话:**PCA 沿方差最大的方向投影,用最少的维度留住最多的信息。** 它是高维数据可视化、压缩、去噪的瑞士军刀,也是无监督学习里和 K-means 并列的两大基石之一。
