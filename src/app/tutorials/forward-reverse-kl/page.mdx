# ↔️ 前向 KL vs 反向 KL

上一篇[交叉熵 = KL = NLL](/tutorials/ce-kl-nll-equivalence)里,我们一直默认「最小化 KL」朝一个方向。但 KL 散度**不对称**:

$$
D_{KL}(P\parallel Q)\neq D_{KL}(Q\parallel P)
$$

这不只是个数学细节——**朝哪个方向优化,会让模型学出完全不同的结果**。这是理解 VAE、扩散模型、RLHF、知识蒸馏的分水岭,也是本篇要讲清楚的唯一一件事。

## 一个会「暴露」方向差异的场景

设真实分布 $P$ 是**双峰**的(数据里有两簇),而我们只能用一个**单峰**高斯 $Q$ 去拟合——这是模型能力有限时的常见处境。逼近不完美时,两种方向会给出**截然不同**的「最优解」:

$$
\underbrace{\min_\theta D_{KL}(P\parallel Q_\theta)}_{\text{前向 · 铺得广}}
\qquad\text{vs}\qquad
\underbrace{\min_\theta D_{KL}(Q_\theta\parallel P)}_{\text{反向 · 抓得准}}
$$

## 两个方向,两种性格

- **前向 KL** $D_{KL}(P\parallel Q)=\sum P\log\frac{P}{Q}$:期望在**真实分布 $P$ 下**取。凡是 $P$ 有质量的地方,$Q$ 一旦为 0 就会被 $\log\frac{P}{0}\to\infty$ 重罚——所以 $Q$ 被迫**覆盖所有峰**,宁可摊宽落在两峰中间(**模式覆盖 / 求均值 · mean-seeking**)。**这正是最大似然、分类交叉熵训练做的事**(只需从数据集 $P$ 采样)。
- **反向 KL** $D_{KL}(Q\parallel P)=\sum Q\log\frac{Q}{P}$:期望在**模型 $Q$ 下**取。凡是 $Q$ 有质量的地方,$P$ 必须也有——所以 $Q$ 被「零强制(zero-forcing)」远离 $P\approx0$ 的低谷,干脆**收窄抓住单个峰**,忽略其余(**模式寻找 / 择一 · mode-seeking**)。变分推断、最大熵强化学习、RLHF 用的是这个方向。

一句话对照:

| | 前向 $D_{KL}(P\parallel Q)$ | 反向 $D_{KL}(Q\parallel P)$ |
|---|---|---|
| 期望在谁下取 | 真实分布 $P$ | 模型 $Q$ |
| 惩罚什么 | $P>0$ 而 $Q\approx0$(漏峰) | $Q>0$ 而 $P\approx0$(冒进) |
| 拟合不足时的行为 | 铺开、覆盖所有峰(求均值) | 收窄、抓住单峰(择一) |
| 谁在用 | 最大似然、交叉熵、预训练 | 变分推断、最大熵 RL、RLHF |
| 俗称 | mean-seeking / 模式覆盖 | mode-seeking / 模式寻找 |

论文里的实验图直观展示了这对性格。下图来自一篇高维变分推断综述:蓝色是真实分布 $p$(相关系数 0.9 的二维高斯,倾斜的长椭圆);用**均值场**(只能表达轴对齐的圆形结构)近似时,最小化 **exclusive(反向)KL** 得到红色的小圆——收窄骑在峰顶、不管尾巴;最小化 **inclusive(前向)KL** 得到绿色的大圆——铺得更宽、宁可高估方差也要盖住整个分布:

# 在一维网格上离散化,直接按定义算两个方向的 KL
x = np.linspace(-8, 8, 400)
dx = x[1] - x[0]

def gauss(mu, sig):
    g = np.exp(-0.5 * ((x - mu) / sig) ** 2)
    return g / (g.sum() * dx)          # 归一化成概率密度

# P 是 -3 和 +3 处的双峰
P = 0.5 * gauss(-3, 0.8) + 0.5 * gauss(3, 0.8)

eps = 1e-12
# 每个位置的「逐点贡献」(被积函数);沿 x 积分(乘 dx 求和)就是总 KL
def fwd_pointwise(P, Q):   # 前向 D(P||Q):积分在 P 下取
    return P * np.log((P + eps) / (Q + eps))
def rev_pointwise(P, Q):   # 反向 D(Q||P):积分在 Q 下取
    return Q * np.log((Q + eps) / (P + eps))

def kl(pointwise):
    return np.sum(pointwise) * dx      # 逐点贡献沿 x 求和 = 总 KL

# 候选单峰 Q:要么骑在中间铺宽,要么抓住其中一个峰
Q_mid  = gauss(0, 2.5)     # 覆盖两峰、落在中间(前向偏爱)
Q_peak = gauss(3, 0.8)     # 抓住右峰、忽略左峰(反向偏爱)

for name, Q in [("Q 骑中间铺宽", Q_mid), ("Q 抓住单峰", Q_peak)]:
    f = kl(fwd_pointwise(P, Q)); r = kl(rev_pointwise(P, Q))
    print(f"{name}:  前向 KL = {f:6.3f}   反向 KL = {r:6.3f}")
print("\\n前向 KL 更偏爱『骑中间』,反向 KL 更偏爱『抓单峰』")

> 📈 看下排两张图:曲线在某个 $x$ 越高,就表示那个位置对 KL 的「罚分」越重,**整条曲线下的面积就是总 KL**。左列 $Q$ 骑中间时,**反向**(红)在两峰中间的低谷猛烈冒尖——因为那里 $Q>0$ 而 $P\approx0$;右列 $Q$ 只抓右峰时,**前向**(蓝)在被遗漏的左峰处猛烈冒尖——因为那里 $P>0$ 而 $Q\approx0$。这正是「前向不敢漏峰、反向不敢冒进」的逐点来源。

> 💡 一句话:**前向 KL 铺得广(监督学习默认),反向 KL 抓得准(生成/强化学习)。** 需要对称度量时,可用两者的平均——**JS 散度**(Jensen-Shannon,GAN 的原始目标):
>
> $$ D_{JS}(P,Q) = \tfrac12 D_{KL}(P\parallel M) + \tfrac12 D_{KL}(Q\parallel M),\qquad M=\tfrac{P+Q}{2} $$

## 实际应用案例

方向的选择不是纸上谈兵——它直接决定了下面这些真实系统的行为。规律始终是那一条:**要「不漏、覆盖全部」就用前向;要「求稳、收窄择一」就用反向。**

### 案例 1 · 语言模型预训练 → 前向 KL

GPT 预训练最小化交叉熵,等价于最小化 $D_{KL}(P_\text{数据}\parallel Q_\theta)$——**前向**。数据分布 $P$ 里出现过的说法,模型 $Q$ 都得给上概率,否则漏一处就被 $\log\frac{P}{0}\to\infty$ 重罚。这也是为什么基础模型「什么都会一点」、生成多样但偶尔一本正经胡说:它被迫覆盖所有模式,包括低质量的那些。

### 案例 2 · RLHF / 对齐 → 反向 KL 约束

对齐阶段(PPO、DPO 等)的目标里通常有一项 $\beta\,D_{KL}(\pi_\theta\parallel\pi_\text{ref})$——**反向**,把新策略 $\pi_\theta$ 拴在参考模型 $\pi_\text{ref}$ 附近。反向的「零强制」性格正合需要:$\pi_\theta$ 不敢跑到 $\pi_\text{ref}$ 概率极低的地方去,于是**收窄到少数高奖励、又不离谱的回答**,避免为了刷奖励而胡乱冒进(reward hacking)。系数 $\beta$ 就是「探索 vs 守规矩」的旋钮。

<CodeRunner defaultCode={`
import numpy as np

# 玩具版 RLHF:5 个候选回答,各有奖励 r;参考模型给出 pi_ref
# 目标: max_pi  E_pi[r] - (1/beta) * D_KL(pi || pi_ref)
# 该目标有闭式解:pi ∝ pi_ref * exp(beta * r)  —— 反向 KL 把 pi 拴在 pi_ref 附近
r       = np.array([0.0, 1.0, 2.0, 5.0, 0.5])   # 第 4 个回答奖励最高但也许"离谱"
pi_ref  = np.array([0.30, 0.30, 0.20, 0.05, 0.15])

def aligned_policy(beta):
    w = pi_ref * np.exp(beta * r)
    return w / w.sum()

for beta in [0.0, 0.5, 2.0]:
    pi = aligned_policy(beta)
    print(f"beta={beta:>3}:  pi = {np.round(pi,3)}   (最高奖励项概率={pi[3]:.3f})")

print("\\nbeta=0 完全听参考模型;beta 越大越追奖励,但反向 KL 拦着它别跑太偏")

### 案例 3 · 变分推断 / VAE → 反向 KL

VAE、贝叶斯变分推断要用一个简单分布 $q$ 去近似复杂后验 $p$,最小化的是 $D_{KL}(q\parallel p)$——**反向**。好处是只需在 $q$ 下采样、可导好优化;代价是**低估不确定性**:$q$ 会缩进后验的某一个峰,把其他峰忽略掉(variational inference 的经典「过度自信」)。

### 案例 4 · 知识蒸馏 → 通常前向

标准知识蒸馏让学生 $Q$ 匹配老师的软标签 $P$,最小化 $D_{KL}(P\parallel Q)$——**前向**,要学生**覆盖老师的整个概率分布**(不只是 top-1),这正是软标签比硬标签更有信息量的原因。近年一些「on-policy 蒸馏」反过来用反向,让学生只在自己会生成的地方对齐老师,各有取舍。

### 案例 5 · GAN → JS 散度(两个方向的平均)

原始 GAN 的判别器最优时,生成器目标等价于最小化 $D_{JS}(P\parallel Q)$——前向与反向的对称平均。它的**反向成分**正是 GAN 臭名昭著的 **mode collapse**(模式坍缩)根源:生成器倾向龟缩到少数几个能骗过判别器的模式,而不去覆盖数据的全部多样性。

| 应用 | 优化方向 | 想要的效果 |
|---|---|---|
| LM 预训练 / 交叉熵 | 前向 $D_{KL}(P\|Q_\theta)$ | 覆盖数据所有说法,不漏 |
| RLHF / 对齐 | 反向 $D_{KL}(\pi_\theta\|\pi_\text{ref})$ | 收窄到高奖励、别离参考太远 |
| VAE / 变分推断 | 反向 $D_{KL}(q\|p)$ | 好采样好优化(代价:低估不确定性) |
| 知识蒸馏 | 多为前向 $D_{KL}(P_\text{师}\|Q_\text{生})$ | 学生覆盖老师整个软分布 |
| GAN | JS(前向+反向平均) | 对称相似度(易 mode collapse) |

## 常见问题 FAQ

**Q:前向、反向到底谁是「前」?容易记混。**
按惯例 $D_{KL}(P\parallel Q)$ 里 $P$ 是**真实分布**、$Q$ 是**模型**:「从真实到模型」为**前向**。判断行为只需记一条:**期望在谁下取,就迁就谁的支撑**——前向在 $P$ 下取,所以不敢漏掉 $P$ 的任何峰(铺开);反向在 $Q$ 下取,所以只要 $Q$ 待的地方 $P$ 不为 0 就行(收窄)。

**Q:训练大模型用哪个方向?**
预训练用**前向**(最大似然 / 交叉熵),要 $Q$ **覆盖** $P$ 的所有模式,不能漏;RLHF / 对齐常带**反向** KL 项(如 $D_{KL}(\pi_\theta\parallel\pi_\text{ref})$),把策略 $\pi_\theta$ **约束**在参考模型附近、择优收窄。取决于你要「不漏」还是「求稳」。

**Q:为什么反向 KL 会「模式坍缩」?**
因为反向惩罚的是「$Q>0$ 但 $P\approx0$」。$Q$ 要避免踩进 $P$ 的低谷,最省事的做法就是龟缩到某一个峰里,其余峰完全放弃——在多峰目标下就表现为只生成一种模式(GAN 的 mode collapse、VI 的过度自信都是这个根源)。

**Q:JS 散度既然对称,为什么不总用它?**
JS 有界(0 到 1 bit)、对称,适合当「相似度」度量(GAN 早期目标)。但它没有 KL 那种「一个方向对应最大似然、另一个方向对应变分下界」的漂亮解析结构,优化性质也不如 KL 友好,所以训练目标里 KL 仍是主力。

## 动手作业

1. **不对称性**:用代码取一组 $P\neq Q$,分别算 $D_{KL}(P\|Q)$ 和 $D_{KL}(Q\|P)$,确认两者不相等。
2. **复现两种偏好**:改上面代码框里 `Q_mid`、`Q_peak` 的 $\mu,\sigma$,找一个让**前向 KL 最小**的 $Q$ 和一个让**反向 KL 最小**的 $Q$,对比它们长得多不一样。
3. **零强制惩罚**:构造一个在 $P>0$ 处 $Q=0$ 的例子,看前向 KL 如何爆到无穷;再反过来构造 $Q>0$ 处 $P=0$,看反向 KL 爆炸。
4. **JS 散度**:实现 $D_{JS}$,验证它对调 $P,Q$ 不变,且始终 $\le 1$ bit。

## 小结

| 概念 | 公式 | 行为 / 用途 |
|---|---|---|
| 前向 KL | $D_{KL}(P\parallel Q)$ | 覆盖所有模式(铺得广)· 最大似然 / 交叉熵 / 预训练 |
| 反向 KL | $D_{KL}(Q\parallel P)$ | 抓住单个模式(抓得准)· 变分推断 / 最大熵 RL / RLHF |
| JS 散度 | $\tfrac12 D_{KL}(P\|M)+\tfrac12 D_{KL}(Q\|M)$ | 对称、有界 · GAN 原始目标 |
