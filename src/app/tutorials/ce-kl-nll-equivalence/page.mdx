# 🟰 一个恒等式:交叉熵 = KL = NLL

在分类和语言模型的代码里,你会反复看到同一行损失:`-log(预测给正确类的概率)`。它有时被叫「交叉熵」,有时叫「KL 散度」,有时叫「负对数似然(NLL)」。**这三个名字,在 one-hot 标签下指向的是同一个数。** 这一篇把它们为什么相等,一步步算清楚。

> 📚 这是「信息论」板块承上启下的一篇。上一篇[交叉熵与 KL 散度](/tutorials/cross-entropy-kl)分别定义了这几个量;这一篇证明它们在 one-hot 下塌缩为一;下一篇[前向 KL vs 反向 KL](/tutorials/forward-reverse-kl)讲 KL 方向的差异。

## 先摆好三个定义

设真实分布为 $P$、模型预测分布为 $Q$,类别下标为 $i$:

$$
\begin{aligned}
\text{交叉熵} \quad & H(P,Q) = -\sum_i P_i \log Q_i \\
\text{KL 散度} \quad & D_{KL}(P\parallel Q) = \sum_i P_i \log \frac{P_i}{Q_i} \\
\text{熵} \quad & H(P) = -\sum_i P_i \log P_i
\end{aligned}
$$

它们由上一篇的恒等式串起来:

$$
H(P,Q) = H(P) + D_{KL}(P\parallel Q)
$$

一般情况下这三者是**三个不同的数**。真正让它们塌缩的,是「标签是 one-hot」这个条件。

## 关键前提:one-hot 标签

分类任务里,真实标签通常是 **one-hot**:正确类别为 $y$,则

$$
P_y = 1, \qquad P_i = 0 \;\; (i \neq y)
$$

也就是「真相百分百确定,就是第 $y$ 类」。下面四步都建立在这个前提上(约定 $0\log 0 = 0$)。

## 四步推导

**第 1 步 · 交叉熵展开。** 代入 one-hot,求和里只有 $i=y$ 那一项非零:

$$
H(P,Q) = -\sum_i P_i\log Q_i
= -\underbrace{1\cdot\log Q_y}_{i=y} - \sum_{i\neq y}\underbrace{0\cdot\log Q_i}_{=\,0}
= -\log Q_y
$$

**第 2 步 · one-hot 的熵为 0。** 同样代入:

$$
H(P) = -\sum_i P_i\log P_i
= -\,1\cdot\underbrace{\log 1}_{=\,0} - \sum_{i\neq y}0\cdot\log 0 = 0
$$

直觉:one-hot 是完全确定的分布,没有任何随机性,不确定性自然是 0。

**第 3 步 · KL 散度展开。**

$$
D_{KL}(P\parallel Q) = \sum_i P_i\log\frac{P_i}{Q_i}
= 1\cdot\log\frac{1}{Q_y} + \sum_{i\neq y}0\cdot\log\frac{0}{Q_i}
= -\log Q_y
$$

**第 4 步 · 三者合一。** 把恒等式 $H(P,Q)=H(P)+D_{KL}$ 与第 2 步的 $H(P)=0$ 结合,再加上单样本的 NLL 本就是 $-\log Q_y$(模型给真实类的概率取负对数),四个量完全相等:

$$
\boxed{\;
\underbrace{-\log Q_y}_{\text{NLL}}
\;=\; \underbrace{H(P,Q)}_{\text{交叉熵}}
\;=\; \underbrace{D_{KL}(P\parallel Q)}_{\text{KL 散度}}
\quad(P \text{ 为 one-hot})
\;}
$$

## 代码验证:三个量真的相等

拖不动公式没关系,直接算给自己看。下面对同一组 $Q$ 分别用三个定义计算,结果应当一致:

<CodeRunner defaultCode={`
import numpy as np

def cross_entropy(P, Q):
    P, Q = np.array(P, float), np.array(Q, float)
    return -np.sum(P * np.log(Q + 1e-12))

def kl(P, Q):
    P, Q = np.array(P, float), np.array(Q, float)
    m = P > 0                      # 只在 P>0 处求和(0*log0=0)
    return np.sum(P[m] * np.log(P[m] / (Q[m] + 1e-12)))

# 4 类分类,真实类别 y=0,标签是 one-hot
y = 0
P = [1, 0, 0, 0]
Q = [0.7, 0.2, 0.06, 0.04]     # 模型预测(softmax 之后)

print("交叉熵 H(P,Q) =", round(cross_entropy(P, Q), 6))
print("KL 散度 D_KL  =", round(kl(P, Q), 6))
print("NLL -log Q[y] =", round(-np.log(Q[y]), 6))
print("熵 H(P)       =", round(cross_entropy(P, P), 6), " (one-hot -> 0)")
print("\\n三个数相等 -> 分类损失怎么叫都行")
`} />

## 为什么软标签会打破它

塌缩的唯一功臣是 $H(P)=0$。一旦标签不是 one-hot,这个前提就没了。

设真实分布是**软标签**(如[知识蒸馏](/tutorials/ml-losses)里 teacher 给出的概率 $P=(0.7,0.2,0.1)$),则 $H(P)>0$,恒等式退回完整形态:

$$
H(P,Q) = \underbrace{H(P)}_{>\,0} + D_{KL}(P\parallel Q)
$$

此时交叉熵比 KL **多出一个常数 $H(P)$**——两者数值**不再相等**。

<CodeRunner defaultCode={`
import numpy as np

def cross_entropy(P, Q):
    P, Q = np.array(P, float), np.array(Q, float)
    return -np.sum(P * np.log(Q + 1e-12))

def kl(P, Q):
    P, Q = np.array(P, float), np.array(Q, float)
    m = P > 0
    return np.sum(P[m] * np.log(P[m] / (Q[m] + 1e-12)))

P = [0.7, 0.2, 0.1]            # 软标签,不是 one-hot
Q = [0.5, 0.3, 0.2]

HP = cross_entropy(P, P)       # = H(P)
print("熵 H(P)      =", round(HP, 4), " (>0!)")
print("交叉熵 H(P,Q)=", round(cross_entropy(P, Q), 4))
print("KL 散度 D_KL =", round(kl(P, Q), 4))
print("差值 H(P,Q)-D_KL =", round(cross_entropy(P, Q) - kl(P, Q), 4), " == H(P)")
`} />

> 💡 好消息:对**给定数据** $H(P)$ 是常数,所以「最小化交叉熵」和「最小化 KL」的**最优解仍然一样**——优化谁都行,只是数值不同。这正是分类任务能放心地直接拿交叉熵当损失、不去管熵项的根本原因:one-hot 标签下压根没有熵可减。

> 💡 **看点**:$H(P)$ 段只由真实分布 $P$ 决定,与模型预测 $Q$ 无关——所以调预测准度时它一动不动。这就是「交叉熵 = KL + 常数」里那个常数的样子:它对参数求导为零,梯度只来自 KL 段,于是最小化交叉熵与最小化 KL **给出同一个最优解**。软硬度拖到 1(one-hot)时橙段消失,三个量在数值上也合一。

## 常见问题 FAQ

**Q:既然三者相等,为什么代码里几乎只写交叉熵?**
因为交叉熵最好算——one-hot 下就是一句 `-log(正确类概率)`,不需要显式构造 $P$ 分布再求 KL。框架里的 `CrossEntropyLoss` / `NLLLoss` 算的都是这个数。

**Q:KL 和交叉熵到底差在哪?**
差一个 $H(P)$。one-hot 时 $H(P)=0$,两者相等;软标签时 $H(P)>0$,交叉熵 = KL + 常数。无论哪种情况,**最小化二者等价**(因为 $H(P)$ 与模型参数无关)。

**Q:那到底该说「最小化交叉熵」还是「最小化 KL」?**
都对。严谨地讲,训练想让 $Q$ 逼近 $P$,本质是最小化 $D_{KL}(P\|Q)$;工程上写成交叉熵是因为好实现。两种说法指向同一个优化目标。

**Q:这和最大似然(MLE)是什么关系?**
NLL 就是负对数似然,最小化 NLL = 最大化似然 = MLE。所以这条恒等式其实把**编码理论(交叉熵)、分布度量(KL)、统计估计(MLE)** 三套语言在分类问题上统一了。详见[交叉熵与 KL 散度](/tutorials/cross-entropy-kl)里的 MLE 小节。

## 小结

| 场景 | $H(P)$ | 交叉熵 vs KL vs NLL |
|---|---|---|
| **one-hot 标签**(普通分类) | $=0$ | 三者完全相等,都等于 $-\log Q_y$ |
| **软标签**(蒸馏等) | $>0$ | 交叉熵 = KL + $H(P)$,数值不等 |
| 两种情况共同点 | — | 最小化交叉熵 ⇔ 最小化 KL(最优解一致) |

> 🎯 一句话记住:**分类损失叫什么名字不重要——one-hot 让熵消失,交叉熵、KL、NLL 塌缩成同一个 $-\log Q_y$。** 下一篇看 KL 散度[朝不同方向优化](/tutorials/forward-reverse-kl)会学出多不一样的模型。
