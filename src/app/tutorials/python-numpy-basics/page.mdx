# 🐍 Python 与 NumPy 基础

后面的每一篇教程都要写一点 Python、用一点 NumPy。如果你是**零基础**或久没碰代码,这一篇帮你打好地基。所有代码块都能**直接运行、随手修改** —— 这是学编程最快的方式:改一改,跑一跑,看结果。

> 不用安装任何东西。点「运行」,Python 就在你的浏览器里跑起来了。

## 变量与基本类型

变量就是给一个值起名字。Python 不需要声明类型,赋值即创建:

<CodeRunner defaultCode={`
name = "小明"        # 字符串 str
age = 20             # 整数 int
height = 1.75        # 浮点数 float
is_student = True    # 布尔 bool

print(name, "今年", age, "岁")
print("身高", height, "米")
print("是学生吗?", is_student)

# 用 f-string 把变量嵌进字符串(最常用)
print(f"{name} 的身高是 {height} 米")
`} />

## 列表:有序的一组数据

列表(list)是 Python 里最常用的容器,用方括号 `[]`:

<CodeRunner defaultCode={`
scores = [88, 92, 79, 95, 60]

print("全部成绩:", scores)
print("第一个:", scores[0])      # 下标从 0 开始
print("最后一个:", scores[-1])   # 负数从末尾数
print("前三个:", scores[:3])     # 切片 [start:end]
print("一共几门:", len(scores))

scores.append(100)               # 末尾追加
print("加一门后:", scores)
print("平均分:", sum(scores) / len(scores))
`} />

## 条件与循环

让程序「做判断」和「重复做事」:

<CodeRunner defaultCode={`
scores = [88, 92, 79, 95, 60]

for s in scores:
    if s >= 90:
        level = "优秀"
    elif s >= 60:
        level = "及格"
    else:
        level = "不及格"
    print(f"分数 {s} → {level}")

# 列表推导式:一行生成新列表(Python 的精髓)
passed = [s for s in scores if s >= 60]
print("\\n及格的成绩:", passed)
`} />

> 💡 **列表推导式** `[表达式 for x in 列表 if 条件]` 是 Python 最地道的写法,后面教程里随处可见,务必读懂。

## 函数:把代码打包复用

用 `def` 定义函数,把一段逻辑封装起来,给它起个名字:

<CodeRunner defaultCode={`
def mean(numbers):
    """计算平均值"""
    return sum(numbers) / len(numbers)

def standardize(numbers):
    """标准化:减均值。机器学习预处理的常见第一步"""
    m = mean(numbers)
    return [x - m for x in numbers]

data = [10, 20, 30, 40, 50]
print("平均值:", mean(data))
print("减去均值后:", standardize(data))
`} />

## NumPy:机器学习的数值计算基石

纯 Python 列表算数值又慢又啰嗦。**NumPy** 提供了高效的**数组(array)**,几乎所有 ML 库(scikit-learn、PyTorch)都建立在它之上。先感受「向量化」—— 对整个数组一次性运算,不用写循环:

<CodeRunner defaultCode={`
import numpy as np

a = np.array([1, 2, 3, 4, 5])

# 整个数组一起运算,无需循环!
print("每个元素 +10:", a + 10)
print("每个元素 ×2 :", a * 2)
print("每个元素平方:", a ** 2)

print("\\n求和:", a.sum())
print("均值:", a.mean())
print("标准差:", a.std().round(4))
print("最大值:", a.max())
`} />

## NumPy 数组运算与广播

两个数组可以逐元素相加相乘;形状不同时 NumPy 会自动「广播」(broadcasting):

<CodeRunner defaultCode={`
import numpy as np

x = np.array([1, 2, 3])
y = np.array([10, 20, 30])

print("逐元素相加:", x + y)
print("逐元素相乘:", x * y)
print("点积(内积):", np.dot(x, y))   # 1*10 + 2*20 + 3*30

# 二维数组(矩阵)
M = np.array([[1, 2, 3],
              [4, 5, 6]])
print("\\n矩阵形状:", M.shape)        # (2 行, 3 列)
print("按列求和:", M.sum(axis=0))     # 压缩掉行维度 → 每列一个结果
print("按行求和:", M.sum(axis=1))
print("整体 +100:\\n", M + 100)        # 广播:标量作用于每个元素
`} />

> 💡 **`shape`(形状)和 `axis`(轴)**是 NumPy 的两个核心概念。报错十有八九是形状不匹配 —— 随时 `print(arr.shape)` 检查。

## 布尔索引:筛选数据

ML 里经常要「挑出满足条件的样本」,NumPy 用布尔数组优雅地做到:

<CodeRunner defaultCode={`
import numpy as np

ages = np.array([15, 22, 17, 30, 19, 12])

mask = ages >= 18          # 得到布尔数组
print("是否成年:", mask)
print("成年人的年龄:", ages[mask])     # 用布尔数组筛选
print("成年人数:", (ages >= 18).sum()) # True 当 1 来求和

# 一步到位:把所有未成年的年龄改成 18
ages[ages < 18] = 18
print("修正后:", ages)
`} />

## 典型应用场景

这些基础在后续教程里**立刻就会用到**:

- **`np.array` + 向量化**:线性回归里一次性算出所有预测值 `w * x + b`
- **`.mean()`**:计算 MSE 损失、梯度的平均
- **布尔索引**:KNN 里筛选最近的 K 个邻居、剔除异常值
- **`shape` / `reshape`**:把数据整理成模型要求的「行=样本,列=特征」格式
- **`np.dot`**:神经网络每一层本质都是矩阵乘法

## 常见问题 FAQ

**Q:Python 列表和 NumPy 数组到底用哪个?**
小规模、混合类型用列表;数值计算、机器学习一律用 NumPy 数组 —— 它快几十倍,还支持向量化和广播。

**Q:`a + 10` 为什么不用写循环?**
这就是**向量化**:NumPy 在底层用 C 循环对每个元素运算,比 Python 显式循环快得多,代码也更短。养成「能向量化就别写 for」的习惯。

**Q:老报 `shape` 不匹配的错怎么办?**
ML 代码里最常见的 bug。随时 `print(arr.shape)` 确认维度;记住二维是 `(行, 列)`,模型通常要求 `(样本数, 特征数)`,必要时用 `.reshape(-1, 1)` 调整。

**Q:`axis=0` 和 `axis=1` 总记混?**
记一句话:**`axis` 是「被压缩掉」的那个维度**。`axis=0` 压缩掉行维度 → 得到每列的结果;`axis=1` 压缩掉列维度 → 得到每行的结果。

**Q:为什么下标从 0 开始?**
计算机的历史约定。记住:`n` 个元素的合法下标是 `0` 到 `n-1`,最后一个用 `[-1]` 最方便。
