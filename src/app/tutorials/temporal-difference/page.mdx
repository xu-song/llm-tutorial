# ⏱️ 时序差分学习:边走边学

[动态规划](/tutorials/dynamic-programming)能精确求解 MDP,但它有个硬前提:**模型必须已知**——你得写得出转移概率 $P(s'\mid s,a)$ 和奖励函数。现实中环境往往是个黑箱,只能**一边交互、一边学**。

**时序差分学习(Temporal Difference, TD)** 正是干这个的,而且它巧妙地**融合了两种思想**:

- 像[蒙特卡洛](/tutorials/monte-carlo)一样,**不需要模型**,纯从经验(采样到的 $s,a,r,s'$)里学;
- 像[动态规划](/tutorials/dynamic-programming)一样,**自举(bootstrapping)**——用「下一状态的当前估计」来更新当前状态,不必等到回合结束。

Sutton 有句名言概括它:**「从一个猜测中学习另一个猜测」(learning a guess from a guess)**。[Q-learning、SARSA](/tutorials/reinforcement-learning) 都是 TD 方法——你其实早就见过它,这一篇把它的来龙去脉讲透。

## TD(0):最简单的时序差分

先看**预测问题**:给定一个策略,估计它的状态价值 $V(s)$。TD(0) 的更新规则是:

$$
V(s) \leftarrow V(s) + \alpha\big[\underbrace{r + \gamma V(s')}_{\text{TD 目标}} - \underbrace{V(s)}_{\text{旧估计}}\big]
$$

方括号里那一项叫 **TD 误差(TD error)** $\delta = r + \gamma V(s') - V(s)$:它衡量「用实际走了一步后的新信息,回头看旧估计差了多少」,然后朝这个方向挪一小步 $\alpha$。

对比一下三种方法更新 $V(s)$ 时**用什么当目标**:

| 方法 | 更新目标 | 需要模型? | 何时能更新 |
|---|---|---|---|
| 动态规划 | $\sum_{s'}P(s'\mid s,a)[r+\gamma V(s')]$(全期望) | **要** | 随时(纸上算) |
| 蒙特卡洛 | $G_t$(实际走到底的整条回报) | 不要 | **回合结束后** |
| TD(0) | $r+\gamma V(s')$(走一步 + 自举) | 不要 | **每一步**(在线) |

TD 既甩掉了 DP 对模型的依赖,又不必像 MC 那样苦等回合结束——**走一步就能学一步**。

## 亲手实现:随机游走预测

Sutton 的经典例子:一条链 A–B–C–D–E–F–G,两端 A、G 是终点。从中间 D 出发,每步 50% 左 / 50% 右,走到 G 得奖励 1、走到 A 得 0。每个非终点状态的**真实价值 = 从它出发最终走到右端 G 的概率**——B 到 F 恰好是 $\tfrac16,\tfrac26,\tfrac36,\tfrac46,\tfrac56$。

看 TD(0) 如何**不知道任何转移概率**、纯靠随机游走就把这些值估出来:

<CodeRunner defaultCode={`
import numpy as np
rng = np.random.default_rng(1)

# 状态 0..6 = A..G,A/G 为终点。真实价值(到达右端 G 的概率):
true = np.array([0, 1/6, 2/6, 3/6, 4/6, 5/6, 0])
V = np.full(7, 0.5); V[0] = V[6] = 0.0   # 非终点初始化 0.5
alpha, gamma = 0.02, 1.0

for episode in range(500):
    s = 3                                 # 从 D 出发
    while s not in (0, 6):
        ns = s + (1 if rng.random() < 0.5 else -1)   # 50/50 左右
        r = 1.0 if ns == 6 else 0.0
        V[s] += alpha * (r + gamma*V[ns] - V[s])      # TD(0) 更新
        s = ns

print("TD(0) 估计 B..F:", np.round(V[1:6], 3))
print("真实价值   B..F:", np.round(true[1:6], 3))
print("-> 完全不知道'50/50'这个规则,只靠走,就估出了每个状态的价值")

## 蒙特卡洛 vs TD:两个极端

同一个随机游走,换成**蒙特卡洛**:等整条走完,用最终结果(到没到 G)去更新沿途**所有**状态。

**拖动下面的「回合数」**,看 TD(0) 与 MC 喂同一批轨迹时、各自的估计如何逼近真值阶梯,以及谁的 RMSE 降得更快——TD 起步就更稳,且多数时候一路领先:

下面把这个对比写成代码,同时跑 TD 和 MC 各多次、比较平均误差(RMSE):

<CodeRunner defaultCode={`
import numpy as np
true = np.array([0, 1/6, 2/6, 3/6, 4/6, 5/6, 0])

def run(seed, method, alpha=0.05, episodes=200):
    rng = np.random.default_rng(seed)
    V = np.full(7, 0.5); V[0] = V[6] = 0.0
    for _ in range(episodes):
        s, traj = 3, []
        while s not in (0, 6):
            ns = s + (1 if rng.random() < 0.5 else -1)
            r = 1.0 if ns == 6 else 0.0
            traj.append((s, r, ns)); s = ns
        if method == "TD":
            for s, r, ns in traj:
                V[s] += alpha * (r + V[ns] - V[s])      # 每步自举
        else:  # MC:用整条回报(终点奖励)更新沿途所有状态
            G = traj[-1][1]
            for s, _, _ in traj:
                V[s] += alpha * (G - V[s])
    return np.sqrt(np.mean((V[1:6] - true[1:6])**2))

for method in ["TD", "MC"]:
    rmse = np.mean([run(sd, method) for sd in range(50)])
    print(f"{method}  平均 RMSE(50 次运行):{rmse:.4f}")
print("-> TD 用'走一步的新信息'持续微调,方差小、收敛快;MC 要等整条回报,噪声大")
`} />

> 💡 **为什么 TD 方差更小?** MC 的目标 $G_t$ 累积了**整条轨迹**上每一步的随机性,无偏但抖得厉害;TD 的目标 $r+\gamma V(s')$ 只含**一步**的随机奖励与转移,方差小得多——代价是引入了偏差(因为 $V(s')$ 是估计值,不是真值)。这正是[策略梯度篇](/tutorials/policy-gradient#常见问题-faq)里 GAE 用 $\lambda$ 调和的**偏差–方差权衡**;TD(0) 和 MC 就是 $\lambda=0$ 与 $\lambda=1$ 的两个端点,中间是 **n 步 TD**。

## TD(0) 预测的收敛性:自举凭什么不跑偏

上面一直在说「TD 收敛更快、方差更小」,但**凭什么相信** $V(s)\leftarrow V(s)+\alpha[r+\gamma V(s')-V(s)]$ 这个「从一个猜测里学另一个猜测」的更新,最终会逼近真值 $v_\pi(s)$,而不是被自举(用不准的 $V(s')$ 当目标)带进沟里?这是 TD 最深的理论问题,Sutton 1988 首次回答 [6],Jaakkola、Tsitsiklis、Singh 1994 把它统一进随机逼近框架 [7]。本节把证明的两层结构讲透——它与[下面 Q-learning 的收敛](#q-learning-为何能收敛到最优)是**同一套机制**(压缩算子 + 随机逼近),只是 Q-learning 多了一个 $\max$。

### 第一层:Bellman 期望算子是 $\gamma$-压缩

固定一个策略 $\pi$,定义 **Bellman 期望算子** $T^\pi$:

$$
(T^\pi V)(s)\;=\;\sum_{a}\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\big[r+\gamma V(s')\big]
$$

它把任意价值函数 $V$ 映射成「按 $\pi$ 走一步、再用 $V$ 估未来」的新价值。关键性质:$T^\pi$ 是**$\gamma$-压缩**——对任意 $V_1,V_2$,

$$
\|T^\pi V_1 - T^\pi V_2\|_\infty \;\le\; \gamma\,\|V_1 - V_2\|_\infty
$$

证明一行:把 $V_1,V_2$ 的差塞进转移核求和,$|\,\cdot\,|$ 与 $\sum$ 换序后 $\sum_{s'}p(\cdot)\gamma|V_1(s')-V_2(s')|\le\gamma\|V_1-V_2\|_\infty$($\sum p=1$),取上确界即得。$\gamma<1$ 意味着**每应用一次 $T^\pi$,任意两个估计之间的距离都被 $\gamma$ 倍压缩**——误差只减不增。由 **Banach 不动点定理**,$T^\pi$ 在有界函数空间上有**唯一不动点** $v_\pi$(满足 $T^\pi v_\pi=v_\pi$,即 Bellman 期望方程),且**确定性迭代** $V_{k+1}=T^\pi V_k$ 几何收敛到 $v_\pi$: $\|V_k-v_\pi\|_\infty\le\gamma^k\|V_0-v_\pi\|_\infty$。

> ⚠️ 注意 $T^\pi$(期望算子,**求和/全期望**)与 Q-learning 收敛定理里的 $T^*$(最优算子,**取 $\max$**)是两个不同的压缩算子。预测问题用 $T^\pi$(固定策略、on-policy),控制问题用 $T^*$(找最优)。两者都是 $\gamma$-压缩,差别只在「期望」还是「最大」——这正是 TD(0) 预测(收敛到 $v_\pi$)与 Q-learning 控制(收敛到 $Q^*$)对应关系的根源,详见[下面 Q-learning 小节](#q-learning-为何能收敛到最优)。

### 第二层:TD(0) 是 $T^\pi$ 的随机逼近

确定性迭代 $V_{k+1}=T^\pi V_k$ 要遍历整个 MDP(每个 $(s,a,s')$ 的转移都查表),实际做不到——只能采到**一个**样本 $s,r,s'$。TD(0) 的更新正是用这个单样本去**估计** $T^\pi V(s)$:

$$
V(s)\;\leftarrow\;V(s)+\alpha\big[\underbrace{r+\gamma V(s')}_{\text{对 }(T^\pi V)(s)\text{ 的单样本估计}}-V(s)\big]
$$

方括号里的 $r+\gamma V(s')-V(s)$ 是 $(T^\pi V)(s)-V(s)$ 的**无偏**估计(在 $V$ 固定时,$\mathbb E[r+\gamma V(s')\mid s]=\sum_a\pi(a\mid s)\sum_{s',r}p[r+\gamma V(s')]=(T^\pi V)(s)$)。所以 TD(0) = 「用随机样本逼近一个压缩算子的不动点」——这正是 [Robbins-Monro 1951 [5]](https://www.jstor.org/stable/2236626) 的随机逼近设定。要把「无偏但有噪声的估计」收敛到真值,学习率 $\alpha_k$ 必须满足 [Robbins-Monro 条件](#q-learning-为何能收敛到最优)(与 Q-learning 同一套):

$$
\sum_{k=1}^{\infty}\alpha_k=\infty,\qquad \sum_{k=1}^{\infty}\alpha_k^2<\infty
$$

第一条保证「学得够」(后期 $\alpha_k$ 不会太早归零),第二条保证「噪声方差可和」(随机抖动不累积发散)。$\alpha_k=1/\sqrt{k}$ 满足两条件;固定 $\alpha$ 违反第二条(残留抖动);$1/k^2$ 违反第一条(没学够就停)。

### 收敛定理与 ODE 直觉

> **TD(0) 预测收敛定理**(Sutton 1988 [6];Jaakkola-Tsitsiklis-Singh 1994 [7]):在有限 MDP、有界奖励($|r|\le r_{\max}$)、on-policy 采样(行为策略 = 目标策略 $\pi$)、Robbins-Monro 学习率($\sum\alpha_k=\infty,\sum\alpha_k^2<\infty$)下,$V_k(s)\xrightarrow{k\to\infty}v_\pi(s)$ **几乎必然**(a.s.)。

**ODE 直觉**(Borkar 2008 [8] 系统化的「随机逼近 = 动力系统」视角):在合适的步长下,随机迭代的**期望轨迹**被一个确定性 ODE $\dot V = \bar T^\pi(V) - V$ 支配(其中 $\bar T^\pi$ 是期望算子 $T^\pi$ 的全期望版本)。这个 ODE 的不动点正是 $v_\pi$,且 $T^\pi$ 的 $\gamma$-压缩性保证了 ODE 在 $v_\pi$ 处**全局渐近稳定**——任意初值都会被「拉回」$v_\pi$。随机噪声则在 $v_\pi$ 附近做幅度 $\propto\sqrt{\alpha_k}$ 的抖动,$\alpha_k\to0$ 时抖动消失。**两层结构**就此清晰:① 压缩算子 $\Rightarrow$ 确定性骨架收敛(ODE 稳定);② Robbins-Monro $\Rightarrow$ 随机噪声被驯服(抖动消失)。

## 资格迹与 TD(λ):在 TD 与 MC 之间连续插值

上面我们把 TD(0) 和 MC 当成两个端点对比,中间只留了一个模糊的「n 步 TD」。但**到底怎么平滑地从一步插值到整条轨迹?** 而且 n 步 TD 要为每个 $n$ 单独存一条回报,**实现上很笨重**——每走一步,$n=1,2,\dots$ 各算各的,内存与计算都翻倍。**资格迹(eligibility traces)** 给出了一个优雅的解法:它用一个**短期记忆向量** $e(s)$,把「该把当前奖励信号分配给哪些过去的状态、各分多少」一并用衰减记录下来,无需为每个 $n$ 单独存数据[1]。它把 TD(0) 与 MC 统一进同一个框架——**TD(λ)**。

### 前向视角:λ-return,离线的「理想目标」

先从**前向视角(forward view)** 想清楚「目标应该是什么」。把 $n$ 步回报 $G_{t:t+n}=r_{t+1}+\gamma r_{t+2}+\cdots+\gamma^{n-1}r_{t+n}+\gamma^n V(s_{t+n})$ 按 $\lambda$ 的几何权重加权平均,就得到 **λ-return**[1]:

$$
G_t^\lambda \;=\; (1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1}\,G_{t:t+n} \;+\; \lambda^{T-t-1}\,G_t
$$

注意**末项 $G_t$ 取全权重 $\lambda^{T-t-1}$** 而不是 $(1-\lambda)\lambda^{T-t-1}$——这是为了让权重之和正好是 1。朴素地写 $(1-\lambda)\sum_{n\ge1}\lambda^{n-1}G_{t:t+n}$ 在 $\lambda<1$ 时没问题,但**在 $\lambda=1$ 时权重和变成 0、目标塌缩到零**(MC 退化失效);末项取全权重正是修正这个边界,使 $\lambda=1$ 严格还原 MC、$\lambda=0$ 严格还原一步 TD(0)。$\lambda$ 在 $(0,1)$ 时,目标就是「近处用短步回报(低方差)、远处用长步回报(渐近无偏)」的几何混合——偏差随 $\lambda$ 增大而减小、方差随之增大。

前向视角是**离线理论**:它要等回合结束才能算 $G_t^\lambda$(因为要看完整条轨迹)。它能说清「TD(λ) 在朝什么目标收敛」,但没法**在线、每一步**地实现。

### λ-return 的几何直觉:n-step 回报的几何加权混合

公式 $G_t^\lambda=(1-\lambda)\sum\lambda^{n-1}G_{t:t+n}+\lambda^{T-t-1}G_t$ 看着抽象,但它说的其实是一句话:**λ-return 是把所有 n 步回报按几何衰减权重「拌」在一起**。把它拆开看:

- **中间项**(n=1 到 $T{-}t{-}1$):每个 n 步回报 $G_{t:t+n}$ 拿到权重 $(1-\lambda)\lambda^{n-1}$——从 n=1 起按 $\lambda$ 的几何级数衰减;
- **末项**(完整回报 $G_t$):拿到权重 $\lambda^{T-t-1}$(注意是**全权重**,不是 $(1-\lambda)\lambda^{T-t-1}$)。

权重之和恒为 1(末项全权重正是补上几何级数尾巴、让 $\lambda=1$ 时不塌缩)。这个「几何混合」的几何直觉,是理解「调 $\lambda$ 如何在 TD(0) 与 MC 之间插值」的钥匙:

- $\lambda=0$:中间项权重 $(1-0)\cdot 0^{n-1}$ 只在 n=1 处等于 1,其余全 0;末项权重 $0^{T-t-1}$=0。**全部权重落在 n=1 这一项**,$G_t^\lambda = G_{t:t+1}$ —— 退化成一步 TD(0)。
- $\lambda=1$:中间项权重 $(1-1)\cdot 1^{n-1}=0$ 全归零;末项权重 $1^{T-t-1}=1$。**全部权重落在末项**,$G_t^\lambda = G_t$ —— 退化成 MC。
- $\lambda$ 居中:权重沿 n 几何衰减,近处(n 小,短步回报,低方差)权重大、远处(n 大,长步回报,渐近无偏)权重小。$\lambda$ 越大,权重分布越往「远处/末项」偏,目标越偏向 MC(偏差↓、方差↑)。

### 后向视角:资格迹,在线的实现

**后向视角(backward view)** 用资格迹把前向目标变成每步可算的在线算法。资格迹 $e_t(s)$ 是一个**随时间衰减的访问记录**:每访问一次 $s$ 它就跳到 1,此后每步按 $\gamma\lambda$ 衰减[1]:

$$
e_t(s) \;=\; \gamma\lambda\, e_{t-1}(s) \;+\; \mathbb 1[S_t=s]
$$

然后**当前这一步的 TD 误差 $\delta_t$ 顺着这条衰减的迹倒推分配**给所有「最近访问过、还没衰减干净」的状态:

$$
V(s) \;\leftarrow\; V(s) \;+\; \alpha\,\delta_t\, e_t(s),\qquad \delta_t = r_{t+1}+\gamma V(s_{t+1})-V(s_t)
$$

直觉:走到 $s_t$、发现比预期好($\delta_t>0$),这个「好」不只奖励 $s_t$,也顺着迹**倒推**给刚走过的 $s_{t-1},s_{t-2},\dots$,但越远分得越少(因为它们的迹已按 $(\gamma\lambda)^k$ 衰减过)。这正是 **信用分配(credit assignment)**——把末步的奖励信号按「多久之前访问过」倒推回去。下面的交互图把这件事画出来:拖 $\lambda$ 看迹衰减快慢如何改变信用分配范围。

### 前向 = 后向:两种视角的等价

前向视角(λ-return 作目标、离线)和后向视角(资格迹、在线)看似在做不同的事,但**两者在每回合结束时对 $V$ 的累计更新量完全相同**——这是资格迹最深刻的结果[1]:后向视角是前向目标的一个**在线、$O(1)$ 内存**的实现。也就是说,资格迹让我们**不必存整条轨迹、不必算多个 $n$ 步回报**,就能等价地朝 λ-return 收敛。这种「用短期记忆向量替代多条回报链」正是它工程上高效的原因。

### 累积迹 vs 替换迹

资格迹的「跳到 1」有两种约定[1]:

- **累积迹(accumulating trace)**:$e_t(s)=\gamma\lambda e_{t-1}(s)+\mathbb 1[S_t=s]$,每次访问就**往上加**。若一个状态在一回合内被**多次访问**,它的迹会越积越大——可能导致更新过大、发散。
- **替换迹(replacing trace)**:$e_t(s)=1$ 若 $S_t=s$(直接重置为 1),否则 $\gamma\lambda e_{t-1}(s)$。多次访问**不累加、只重置**,天然有上限(迹 $\le1$),更稳。

| 维度 | 累积迹 | 替换迹 |
|---|---|---|
| 重访时 | 迹累加($+\!1$) | 迹重置($=1$) |
| 上限 | 无(可能很大) | $\le1$ |
| 稳定性 | 多次重访易过更新 | 更稳 |
| 等价 | 前向 λ-return 严格 | 近似(访问越多权重饱和) |

实践中替换迹在**回合内状态会反复访问**的任务上(如带环的网格世界、回访的迷宫)明显更稳,是 Sarsa(λ) 等算法的常用默认。

### 真在线 TD(λ):前向视角的精确在线等价

前面说「前向(λ-return)与后向(资格迹)等价」,但这里藏着一个**关键技术细节**:ordinary 半梯度 TD(λ) 的等价是**离线**的——即「整个回合跑完、回合末一次性把所有更新累加再作用于 $V$」时,前向 λ-return 的总更新量与后向资格迹的总更新量**完全相同**。可一旦改成**在线**更新(每走一步就立即把 $\alpha\delta_t e_t$ 加到 $V$ 上,$V$ 在回合中途就变了),ordinary TD(λ) 就**不再精确等价**前向视角——因为后续步的 $\delta_t$ 用的是「已经被前面更新改过」的 $V$,而前向 λ-return 公式里的 $V(s_{t+n})$ 是回合开始时的旧值。

**真在线 TD(λ)(true online TD(λ), van Seijen & Sutton 2014 [3])** 补上这个缺口:它在前向视角与在线更新之间建立**精确**等价(不是近似),靠的是加一个**校正项**修正「$V$ 在每步被改写」带来的偏差。表格型(tabular)更新式:

$$
V \;\leftarrow\; V \;+\; \alpha\,\delta_t\, e_t \;+\; \alpha\,\big(V(s_t) - V_{\text{old}}(s_t)\big)\,\big(e_t - x_t\big)
$$

其中 $V_{\text{old}}(s_t)$ 是「上一次处理 $s_t$ 时的旧值」,$x_t$ 是 $s_t$ 的 one-hot 特征向量(故 $e_t - x_t$ 把当前状态的增量剔除、只把校正分配给**其它**有迹的状态)。校正项的直觉:每步更新把 $V(s_t)$ 从 $V_{\text{old}}(s_t)$ 改到新值,这个变化量 $V(s_t)-V_{\text{old}}(s_t)$ 也要顺着迹倒推给「之前访问过、迹还活着」的状态——ordinary TD(λ) 漏了这一笔,所以只在离线时精确;真在线补上它,就**逐步**都精确等价前向 λ-return。

这个差别在表格型、小学习率下数值上很小(下方玩具两者 fixed point 一致),但在**函数逼近 + 大学习率 + 在线**场景(如神经网络 Critic)会累积成可观的偏差——这正是真在线 TD(λ) 在深度 RL 的资格迹实现里被偏爱的原因。下面玩具把两者跑出来对比:

## TD(λ) 预测的收敛性:λ 改变什么、不改变什么

[前面](#td0-预测的收敛性自举凭什么不跑偏)我们回答了「TD(0) 的自举凭什么不跑偏」——核心是 **Bellman 期望算子 $T^\pi$ 是 $\gamma$-压缩**,TD(0) 是对它的随机逼近,故收敛到 $v_\pi$。有了资格迹,自然要问:**把 TD(0) 推广成 TD(λ),λ 这根滑杆改变了收敛性吗?** 答案出人意料地干净:λ **不改变**收敛的终点,只**改变**收敛的路径与代价(偏差–方差、样本效率)。本节把这件事讲透——它与 TD(0) 预测收敛是同一套「压缩算子 + 随机逼近」机制 [7],只是把 $T^\pi$ 换成了更一般的 **λ-return 算子 $T^\lambda$**。

### λ-return 算子 $T^\lambda$:把前向视角写成算子

把[前向视角](#前向视角λ-return离线的理想目标)的 λ-return $G_t^\lambda$ 取**期望**(在策略 $\pi$ 与转移 $p$ 下),就得到一个作用在价值函数上的算子 $T^\lambda$ [1]:

$$
(T^\lambda V)(s) \;=\; \mathbb{E}_\pi\!\left[G_t^\lambda \,\middle|\, S_t=s\right]
\;=\; (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}\,\mathbb{E}_\pi\!\left[G_{t:t+n}\,\middle|\,S_t=s\right]
$$

即「$n$ 步回报期望」按 $\lambda$ 的几何权重加权求和。两个端点立刻可验:

- **λ=0**:$T^0 V$ 只保留 $n=1$ 项 $\Rightarrow (T^0 V)(s)=\mathbb{E}[r+\gamma V(s')]= (T^\pi V)(s)$,退化为一步 Bellman 期望算子。
- **λ=1**:$T^1 V$ 让 $n\to\infty$ 取极限 $\Rightarrow (T^1 V)(s)=\mathbb{E}_\pi[G_t\mid S_t=s]$,退化为本回合的蒙特卡洛回报期望(完整轨迹,无 bootstrap)。

中间的 $\lambda$ 在这两个端点之间插值:每一步既看一点「自举的 $V(s')$」(短视、低方差),也看一点「真实回报」(远视、无偏)。

### 第一层:$T^\lambda$ 的不动点是 $v_\pi$,与 λ 无关

这是最关键、也最反直觉的一点:**无论 $\lambda$ 取 $[0,1]$ 里的哪个值,$T^\lambda$ 的不动点都是同一个 $v_\pi$**。原因是一行推导 [1]:在 $V=v_\pi$ 时,任意 $n$ 步回报的期望都等于 $v_\pi(s)$(因为 $v_\pi$ 本身就是「从 $s$ 出发的期望回报」,无论截几步再 bootstrap,$v_\pi$ 自身满足 $\mathbb{E}[G_{t:t+n}]=v_\pi(s)$),所以它们的任何凸组合也等于 $v_\pi(s)$:

$$
(T^\lambda v_\pi)(s) = (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}\,v_\pi(s) = v_\pi(s)\cdot(1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1} = v_\pi(s)
$$

(几何级数和 $\sum_{n=1}^{\infty}\lambda^{n-1}=1/(1-\lambda)$,与 $(1-\lambda)$ 抵消;λ=1 时取极限,等式仍成立。)也就是说,**λ 不改终点**——TD(0)、TD(0.5)、TD(0.9)、MC(λ=1) 全都收敛到同一个 $v_\pi$。这与[上一节](#td0-预测的收敛性自举凭什么不跑偏)TD(0) 收敛到 $v_\pi$ 是一致的:换 $\lambda$ 没有换不动点。

### 第二层:$T^\lambda$ 是 $\gamma$-压缩($\gamma<1$ 时)

不动点相同,那 λ 改变的是什么?**收敛的路径**。关键是 $T^\lambda$ 仍然是压缩算子 [7]:在折扣 $\gamma<1$ 的 MDP 里,$T^\lambda$ 的压缩常数 $\le\gamma$(与 $T^\pi$ 同阶)——因为 $n$ 步回报里未来部分仍按 $\gamma^n$ 衰减,$\lambda$ 只是在不同的 $n$ 之间重新分配权重,不改变「未来按 $\gamma$ 折扣」这一事实。压缩性保证了:

- **唯一不动点**:由 Banach 不动点定理,$T^\lambda$ 有唯一不动点,而上面已证它就是 $v_\pi$。
- **确定性迭代几何收敛**:反复施 $T^\lambda$,$\|T^\lambda V - v_\pi\|_\infty \le \gamma\,\|V-v_\pi\|_\infty$,与 $T^\pi$ 同样的几何衰减速率。

> ⚠️ **γ=1 的 episodic 情形**:本节玩具是 $\gamma=1$ 的 absorbing 随机游走(两端吸收),此时压缩性来自「吸收结构」而非折扣——$T^\lambda$ 仍收敛(下方段 2 验证误差单调衰减),但严格的 $\gamma$-压缩陈述需 $\gamma<1$。**结论本身在两种情形都成立**:TD(λ) 收敛到 $v_\pi$。

### 第三层:TD(λ) 是 $T^\lambda$ 的随机逼近

与[上一节](#第二层td0-是-t-pi-的随机逼近)TD(0) 完全平行:TD(λ) 的更新 $V\leftarrow V+\alpha\delta_t e_t$ 里,「按资格迹分配的 $\lambda$-回报」是 $(T^\lambda V)(s_t)-V(s_t)$ 的**无偏单样本估计**(在线 ordinary TD(λ) 在回合末精确、逐步近似;真在线 TD(λ) [3] 逐步精确)。所以 TD(λ) = 「用随机样本逼近压缩算子 $T^\lambda$ 的不动点」——又是 Robbins-Monro 随机逼近 [5],学习率条件与 TD(0) / Q-learning 完全一致。

### TD(λ) 预测收敛定理

把三层合并,得到与 TD(0) 收敛定理对仗的 TD(λ) 版本 [6][7]:

> **TD(λ) 预测收敛定理**(Sutton 1988 [6];Jaakkola-Tsitsiklis-Singh 1994 [7]):在有限 MDP、有界奖励($|r|\le r_{\max}$)、on-policy 采样(行为策略 = 目标策略 $\pi$)、Robbins-Monro 学习率($\sum\alpha_k=\infty,\sum\alpha_k^2<\infty$)下,**对任意 $\lambda\in[0,1]$**,$V_k(s)\xrightarrow{k\to\infty}v_\pi(s)$ **几乎必然**(a.s.)。替换迹(replacing trace)在同样条件下亦收敛。

与 TD(0) 定理逐字相同的部分(有限 MDP / 有界奖励 / on-policy / Robbins-Monro / a.s.)说明机制同构;**唯一新增的是「对任意 $\lambda$」**——不动点不变性让它成立,压缩性 + 随机逼近让它收敛。ODE 直觉 [8] 同样适用:确定性骨架 $\dot V=\bar T^\lambda(V)-V$ 在 $v_\pi$ 处全局渐近稳定,噪声 $\propto\sqrt{\alpha_k}$ 抖动随 $\alpha_k\to0$ 消失。

### λ 改变的是路径:偏差–方差权衡

既然终点相同,λ 这根滑杆调节的就是**收敛路径的代价结构** [1]:

| 维度 | λ=0(TD(0)) | 中间 λ | λ=1(MC) |
|---|---|---|---|
| 目标 | $r+\gamma V(s')$(一步 bootstrap) | $n$ 步回报几何混合 | 完整轨迹回报 $G_t$ |
| 偏差 | 有(目标用不准的 $V$) | 中 | 无(回报是真实值的无偏样本) |
| 方差 | 低(只看一步随机) | 中 | 高(整条轨迹的随机都进来) |
| 收敛速度 | 慢(bootstrap 偏差需多次迭代消除) | 通常最快 | 快(单回合信息量大)但抖动大 |

直觉:λ=0 的目标「用一个不准的猜测 $V(s')$ 去更新另一个不准的猜测 $V(s)$」——方差小(只引入一步转移的随机),但有**bootstrap 偏差**(初值 $V$ 的误差要靠迭代慢慢消化);λ=1 的目标是「整条轨迹的真实回报」——无偏,但整条轨迹的所有随机奖励都灌进一个估计,方差大。中间的 λ 同时拿一点 bootstrap 的低方差和 MC 的低偏差,**实践中常比两个端点都快**——这就是资格迹的价值。

## 从预测到控制:TD 家族

上面是**预测**(评估固定策略)。要**控制**(学出好策略),把 $V$ 换成动作价值 $Q(s,a)$ 就得到 TD 控制三兄弟,区别全在 TD 目标那一项:

| 算法 | TD 目标用什么 | 策略性 |
|---|---|---|
| **SARSA** | $Q(s',a')$,$a'$ 是**实际要走**的下一动作 | on-policy |
| **Q-learning** | $\max_{a'}Q(s',a')$,假设下一步走**最优** | off-policy |
| **Expected SARSA** | $\sum_{a'}\pi(a'\mid s')Q(s',a')$,按策略**概率加权** | 两者皆可 |

[入门篇](/tutorials/reinforcement-learning)的网格世界里已经跑过 SARSA 与 Q-learning,它们的差别(贴悬崖 vs 绕远路)正源于这一栏。下面把这三兄弟讲透。

### SARSA:on-policy 的「实事求是」

**SARSA** 的名字来自它更新所用的五元组 $(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})$——状态、动作、奖励、下一状态、**下一动作**。更新式:

$$
Q(S_t,A_t)\;\leftarrow\;Q(S_t,A_t)+\alpha\big[\underbrace{R_{t+1}+\gamma Q(S_{t+1},A_{t+1})}_{\text{TD 目标}}-Q(S_t,A_t)\big]
$$

关键在 TD 目标里的 $A_{t+1}$:它是**智能体在当前行为策略 $\pi$ 下实际采样的下一动作**(如 ε-greedy 以 $1-\epsilon$ 选贪心、$\epsilon$ 随机)。这就是 **on-policy(同策略)**——评估的策略和产生数据的策略是同一个。SARSA 学到的 $Q$ 反映的是「**我边探索边走**会拿到的回报」,把探索的代价**算进了价值估计里**。

> 📜 SARSA 最早由 Rummery & Niranjan (1994) 提出,原名「Modified Connectionist Q-Learning」(MCQ-L);「SARSA」这个名字是 Sutton 在脚注里起的,后来反客为主。

### Q-learning vs SARSA:off-policy 的「理想化」

对比 **Q-learning** 的更新:

$$
Q(S_t,A_t)\;\leftarrow\;Q(S_t,A_t)+\alpha\big[\underbrace{R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')}_{\text{TD 目标}}-Q(S_t,A_t)\big]
$$

TD 目标换成 $\max_{a'}Q(s',a')$——**假设下一步走最优动作**。这是 **off-policy(异策略)**:用行为策略(ε-greedy)采数据,但估的是**贪心/最优策略**的价值,把探索的代价**剥离**了。

一句话区别:**SARSA 估「我(含探索)会拿到多少」,Q-learning 估「最优策略会拿到多少」**。前者实事求是但偏保守,后者理想化但乐观。

### Q-learning 为何能收敛到最优

Q-learning 用 $\max_{a'}Q(s',a')$ 作 TD 目标,这看起来很「贪心」——一步 $\max$ 就把所有未来决策都假设成最优。凭什么相信 $Q_k$ 最终会收敛到真最优 $Q^*$,而不是被这个 $\max$ 带偏?这是 Q-learning 最深的理论问题,Watkins 在 1989 年博士论文里首次回答,Watkins & Dayan 1992 [4] 给出严格证明。

**核心洞察:Q-learning 是随机逼近**。把更新式重写成 $Q_{k+1}(s,a)=Q_k(s,a)+\alpha_k[\text{TD target}-Q_k(s,a)]$,它是对「Bellman 最优性方程 $Q^*(s,a)=\mathbb E[r+\gamma\max_{a'}Q^*(s',a')]$」的**随机逼近求解**——TD target 是 Bellman 最优性算子 $T^*Q$ 在某个转移样本上的无偏估计。关键在于 $T^*$ 是 **$\gamma$-压缩**($\|T^*Q_1-T^*Q_2\|_\infty\le\gamma\|Q_1-Q_2\|_\infty$),所以 $T^*$ 有唯一不动点 $Q^*$,迭代 $T^*$ 几何收敛。Q-learning 的 $\max$ 之所以不破坏收敛,正是因为它对应的是**压缩算子**的不动点,而非任意放大。

但随机逼近要收敛,学习率 $\alpha_k$ 必须满足 **Robbins-Monro 条件**(Robbins & Monro, 1951 [5]):

$$\sum_{k=1}^{\infty}\alpha_k=\infty,\qquad \sum_{k=1}^{\infty}\alpha_k^2<\infty$$

第一条「总和发散」保证学习步数足够多——否则后期 $\alpha_k\to0$ 太快,还没学到就停了;第二条「平方和收敛」保证方差可和——否则随机噪声的累积方差发散,估计永远抖动。$\alpha_k=1/\sqrt{k}$ 是满足两条件的经典选择($\sum 1/\sqrt{k}=\infty$ 发散、$\sum 1/k<\infty$ 收敛);$\alpha_k=1/k$ 也满足。固定 $\alpha$ 违反第二条($\sum\alpha^2=\infty$),在随机环境下会残留抖动、不严格收敛到 $Q^*$。

**Q-learning 收敛定理**(Watkins & Dayan, 1992 [4]):在有限 MDP、有界奖励($|r|\le r_{\max}$)下,若满足:① **GLIE 探索**(每个 $(s,a)$ 无限次访问,见[蒙特卡洛篇](/tutorials/monte-carlo#控制glie无限探索下的贪心收敛)的 GLIE 条件);② **Robbins-Monro 学习率**($\sum\alpha_k=\infty,\sum\alpha_k^2<\infty$),则 $Q_k(s,a)\xrightarrow{k\to\infty}Q^*(s,a)$ **几乎必然**(a.s.)。

> 💡 **与 SARSA 的对照**:Q-learning 收敛到 $Q^*$(最优策略价值),而 on-policy 的 SARSA 在 GLIE 下收敛到 **$\varepsilon$-软策略的最优 $Q^\pi$**(含探索代价,非 $Q^*$)——这就是悬崖行走里 Q-learning 贴崖边(估最优)、SARSA 绕远路(估含探索代价)的理论根源。两者都收敛,但收敛到不同的目标:Q-learning 的 $\max$ 让它跳过探索代价直接瞄 $Q^*$,代价是需要 off-policy 才能学、且 $\max$ 会放大方差(过估计偏差,见 [DQN 篇](/tutorials/dqn)的 Double DQN)。

### 经典对照:悬崖行走(cliff walking)

这个区别最经典的展示是 Sutton & Barto 的悬崖行走 [2]:$4\times12$ 网格,左下角起点、右下角终点,中间一段悬崖(掉下去 -100 并弹回起点),其余每步 -1。

| | 学到的贪心路径 | 平均回报 | 为何 |
|---|---|---|---|
| **Q-learning** | 贴着悬崖边走(最短) | 较低 | 贪心路径是最优的,但 ε-greedy 探索时一抖就掉崖、频繁吃 -100 |
| **SARSA** | 绕到顶行再过去(最安全) | 较高 | 价值估计含探索代价,SARSA「知道」贴崖边会被 ε 抖下去,故学保守路径 |
| **Expected SARSA** | 与 SARSA 相近 | 最高 | 用期望替采样,方差更小,收敛更稳 |

三个算法学到的贪心路径可视化(`S` 起点、`G` 终点、`~` 悬崖、`*` 路径):

```
Q-learning  (贴崖边,最短但 ε 探索易摔)
  ............
  ............
  ************
  S~~~~~~~~~~G

SARSA       (绕到顶行,最安全)
  ***********.
  *.........**
  *..........*
  S~~~~~~~~~~G

Expected SARSA  (走中间行,折中)
  ............
  ************
  *..........*
  S~~~~~~~~~~G
```

妙处在于:**Q-learning 学到的「最优路径」在纸上是最短的,但因为它学的是理想值(假设不摔),部署时 ε 探索会反复摔,实际回报反而低**;SARSA 把「我会摔」算进去,学出绕远路,反而拿得更多。这就是 on-policy 的价值——**当探索有代价时,估含探索的价值更贴近部署实况**。

### Expected SARSA:用期望降方差

**Expected SARSA** 把 SARSA 里的采样 $Q(s',a')$ 换成对策略的**期望**:

$$
\text{TD 目标}=R_{t+1}+\gamma\sum_{a'}\pi(a'\mid s')\,Q(s',a')
$$

不再依赖「这一步恰好采样到哪个 $a'$」,而是按 $\pi$ 的概率加权所有可能动作。好处是**降方差**——采样单个 $a'$ 会引入额外噪声,期望把这个噪声平均掉。代价是每次更新多算一次 $\sum$(动作多时成本上升)。它 on/off-policy 皆可:行为策略 = 目标策略时是 on-policy;若 $\pi$ 是目标策略而行为策略是另一个(如 ε-greedy 采样、估贪心),则 off-policy。实践中 Expected SARSA 常被忽视,却在方差大、探索代价高的任务上比 SARSA 与 Q-learning 都稳 [2]。

### 三兄弟怎么选

- **Q-learning**:想学最优策略、探索代价不大(或后期 ε 递减)时,off-policy 直接逼近 $Q^*$,[DQN](/tutorials/dqn) 就是它的深度版;
- **SARSA**:探索有实际代价(机器人、安全约束)、部署时仍要带探索时,估「我实际会拿到多少」更贴近现实;
- **Expected SARSA**:方差大、想要 SARSA 的 on-policy 优点但更稳时,是常被忽视的好选择。

三者的关系可以串起来:**SARSA 是 Expected SARSA 的「单样本版」(采样替期望),Q-learning 是 Expected SARSA 在 $\pi$ 取贪心时的特例(只对最优动作有权重)**。理解了期望形式,另两个就是它的两个简化。

### Sarsa(λ):把资格迹搬进控制

上面三兄弟都是**一步** TD 控制(目标只看 $r+\gamma Q(s',a')$)。把它和[资格迹](#资格迹与-tdλ在-td-与-mc-之间连续插值)结合,就得到 **Sarsa(λ)**——预测用的 TD(λ) 的控制版:资格迹从「状态向量 $e(s)$」扩成「状态-动作矩阵 $e(s,a)$」,$\delta_t$ 沿 $(s,a)$ 对的迹倒推分配信用。更新式:

$$
Q(s,a) \;\leftarrow\; Q(s,a) + \alpha\,\delta_t\,e_t(s,a),\qquad \delta_t = r_{t+1}+\gamma Q(s_{t+1},a_{t+1})-Q(s_t,a_t)
$$

$$
e_t(s,a) \;=\; \gamma\lambda\, e_{t-1}(s,a) \;+\; \mathbb 1[S_t=s, A_t=a]
$$

每步先把迹衰减 $\gamma\lambda$、再把当前 $(s_t,a_t)$ 的迹 $+1$(累积)或重置为 $1$(替换),然后 $\delta_t$ 乘以整条迹一次性更新所有「最近访问过」的 $(s,a)$。这把「末步的奖励/惩罚」**倒推**给整条轨迹上每个动作——比一步 Sarsa 在**稀疏奖励**任务上快得多(掉坑的 -1 不只更新最后一步,而是沿迹回灌给导致掉坑的整串动作)。实践中 Sarsa(λ) 默认用**替换迹**:回合内同一 $(s,a)$ 反复出现时累积迹会越积越大、易过更新,替换迹重访即重置、有上界 $\le1$、更稳。

|---|---|
| **[Q-learning / DQN](/tutorials/dqn)** | 更新式 $r+\gamma\max_{a'}Q(s',a')-Q(s,a)$ 就是 TD 误差 |
| **[Actor-Critic](/tutorials/policy-gradient)** | Critic 用 TD 误差估优势 $A$,再喂给 Actor |

| **TD-Gammon(1992)** | 用 TD 学出超越人类的西洋双陆棋 AI,深度 RL 的先声 |

> 💡 一句话定位:**TD = model-free(像 MC)+ bootstrapping(像 DP)。** 它是[动态规划](/tutorials/dynamic-programming)(要模型、全期望)和蒙特卡洛(免模型、等回合)之间的桥,也是几乎所有现代价值型 RL(Q-learning、DQN、Actor-Critic 的 Critic)的更新内核。

## 跨学科实证:多巴胺与 TD-Gammon

上面「典型案例」表里点了两个名字——**多巴胺=奖励预测误差**和 **TD-Gammon**——它们不只是「TD 用在了某处」,而是 TD 思想**走出计算机、在生物学和博弈 AI 里被反复印证**的两块里程碑。这一节把它们展开:一个证明 TD 误差就是大脑的信号,一个证明 TD(λ) + 自我博弈足以在复杂博弈里达到世界顶级。

### 多巴胺神经元编码的就是 TD 误差

1997 年,Schultz、Dayan 与 Montague 在猕猴实验里记录了腹侧被盖区(VTA)和黑质致密部(SNc)多巴胺神经元的放电模式[9][10],发现它们编码的正是**奖励预测误差(RPE)**——而非奖励本身:

- **意外获得奖励** → 多巴胺神经元在奖励时刻**相位性激增**(正 RPE,基线以上);
- **预测到奖励**(条件刺激 CS 已学会预示奖励)→ 多巴胺响应从奖励时刻**前移到 CS 时刻**,奖励时刻反而**归零**(已被预测,无误差);
- **预测到奖励却未兑现**(消退试验)→ 多巴胺在奖励该出现时刻**抑制**(负 RPE,基线以下)。

这三类响应恰好对应 TD 误差 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ 的三种取值:正、零、负。更深刻的是「前移」现象——价值沿时间从非条件刺激(US)反传到条件刺激(CS),正是 TD 学习中 $\delta$ **沿资格迹倒推、把信用从 US 回灌给 CS** 的生物学对应。下面的 CodeRunner 用一个最小 Pavlov 条件反射(_CS 在 $t{=}1$ 出现,US 在 $t{=}3$ 出现_)复现这三类响应:训练前 RPE 集中在 US 时刻,训练 200 轮后 RPE 转移到 CS 时刻、US 时刻归零,消退试验则在该有 US 的时刻出现负 RPE。

### TD-Gammon:自我博弈 + 价值函数的先声

TD-Gammon 是 Tesauro 在 1992 年[11]/1995 年[12]用 TD(λ) 学西洋双陆棋(backgammon)策略的工作,是 RL 第一次在**真实复杂博弈**(约 $10^{20}$ 状态)上达到世界顶级水准——比 DQN(Atari, 2015)早 22 年,比 AlphaZero(2017)早 25 年。它的三大要素日后成了深度 RL 的模板:

1. **价值函数而非策略**:网络输入棋盘特征,输出的是**赢棋概率** $P(\text{win})$(一个标量价值),而非直接输出落子策略。这让学习目标变成回归,信号稠密、稳定。
2. **自我博弈产生数据**:不依赖人类棋谱,程序自己和自己下,对称对弈。后期版本加 1-ply / 2-ply minimax 搜索 + 神经网络评估,已经是 AlphaZero「搜索 + 神经网络」思想的雏形。
3. **TD(λ) 更新**:终局 reward(赢=1/输=0)沿资格迹倒灌给沿途状态,中间步靠 bootstrapping 自举——正是上节资格迹机制在控制里的落地。

下面这个 CodeRunner 用一个极简「赛跑博弈」(两玩家轮流选「保守」或「激进」前进,先到终点胜)复现这三大要素:对称自我博弈(两玩家共用一张 Q 表)+ ε-greedy 探索 + TD(λ) 资格迹更新。训练后让贪心策略与纯随机策略对弈(各先手半局消除先手优势),可看到胜率从训练前的 ~0.10(Q=0.5 时贪心=乱选、激进高方差易输)飙升到训练后的 ~0.72——自我博弈确实学出了有效策略。

## 常见问题 FAQ

**Q:TD 误差 $\delta = r+\gamma V(s') - V(s)$ 到底在说什么?**
它是「走了一步后获得的新信息」与「原本的预期」之差:若 $\delta>0$,说明这一步比预期好,该调高 $V(s)$;反之调低。整个 TD 学习就是不断用 $\delta$ 把估计往真值推。

**Q:TD 一定比 MC 好吗?**
多数马尔可夫环境里 TD 收敛更快、方差更小(如上面的随机游走)。但 TD 有偏(自举依赖不准的估计),在**非马尔可夫**或函数逼近场景下,偏差可能放大甚至发散(见 [DQN 的致命三元组](/tutorials/dqn))。MC 无偏、实现简单,回合短时也很好用。至于「TD 凭什么收敛」的形式化保证,见[上一节](#td0-预测的收敛性自举凭什么不跑偏)。

**Q:为什么说「Q-learning 是 TD 方法」?**
Q-learning 的更新 $Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]$ 里,方括号就是一个 TD 误差——只不过目标用了 $\max$。所以它是「TD + 离策略 + 控制」的组合。

**Q:n 步 TD 和 TD(λ) 是什么?**
TD(0) 只看一步,MC 看到底。**n 步 TD** 看 n 步再自举,是二者之间的连续谱;**TD(λ)** 用一个 $\lambda$ 把所有 n 步回报加权平均(配合资格迹高效实现),$\lambda=0$ 即 TD(0)、$\lambda=1$ 即 MC——详见上面[资格迹与 TD(λ)](#资格迹与-tdλ在-td-与-mc-之间连续插值)小节。

**Q:资格迹为什么能替代「为每个 n 单独存一条回报」?**
关键在 λ-return 是各 n 步回报的**几何加权**。资格迹 $e_t(s)=\gamma\lambda e_{t-1}(s)+\mathbb 1[S_t=s]$ 是一个随时间衰减的访问记录,当前 TD 误差 $\delta_t$ 乘以 $e_t$ 后,**自动**按 $(\gamma\lambda)^k$ 的权重倒推分配给 $k$ 步前访问的状态——这恰好等价于「同时朝所有 n 步回报的目标更新」。一个向量、一次 `V += αδe`,就把 $n=1\ldots T$ 的回报全揉进去了。

**Q:累积迹和替换迹怎么选?**
回合内状态**会反复访问**(带环的网格、迷宫回访)时,累积迹越积越大、易过更新发散,选**替换迹**(重访即重置为 1,有上界 $\le1$);状态基本不重访的简单链上,两者相近。Sarsa(λ) 等算法默认用替换迹。

## 小结

| 概念 | 含义 |
|---|---|
| 时序差分 TD | model-free + bootstrapping,边走边学 |
| TD(0) 更新 | $V(s)\leftarrow V(s)+\alpha[r+\gamma V(s')-V(s)]$ |
| TD 误差 $\delta$ | $r+\gamma V(s')-V(s)$,新信息与旧估计之差 |
| TD vs MC | TD 低方差有偏、收敛快;MC 无偏高方差、需整条回合 |
| TD 控制 | SARSA / Q-learning / Expected SARSA,区别在 TD 目标 |
| λ-return $G_t^\lambda$ | 各 n 步回报的几何加权,末项取全权重保证 $\lambda{=}1$ 还原 MC |
| 资格迹 $e_t(s)$ | $\gamma\lambda e_{t-1}(s)+\mathbb 1[S_t=s]$,访问的衰减记录 |
| TD(λ) 更新 | $V\leftarrow V+\alpha\delta_t e_t$,$\delta_t$ 沿迹倒推分配信用 |
| 累积迹 vs 替换迹 | 重访时累加($+\!1$) vs 重置($=1$);替换迹有上界、更稳 |
| 真在线 TD(λ) | 加校正项 $\alpha(V(s_t)-V_{\text{old}}(s_t))(e_t-x_t)$,在线逐步精确等价前向(van Seijen & Sutton 2014) |
| Sarsa(λ) | TD(λ) 的控制版:迹扩成 $e(s,a)$,$\delta_t$ 沿 $(s,a)$ 迹倒推,稀疏奖励下比一步 Sarsa 快 |

> 🎯 一句话记住:**TD = 用「下一步的猜测」修正「这一步的猜测」,不要模型、不等回合、走一步学一步——它是动态规划与蒙特卡洛的私生子,也是 [Q-learning](/tutorials/reinforcement-learning)、[DQN](/tutorials/dqn)、[Actor-Critic](/tutorials/policy-gradient) 共同的心脏。** 而**资格迹 + TD(λ)** 把这个私生子与蒙特卡洛正式统一:用一条衰减的短期记忆向量,把「一步 TD」与「整条 MC」之间的所有折中点一并用 $O(1)$ 内存在线实现——$\lambda=0$ 是 TD(0)、$\lambda=1$ 是 MC,中间任意插值。

9. Schultz, W., Dayan, P., & Montague, P. R. (1997). *A Neural Substrate of Prediction and Reward*. Science, 275(5306), 1593-1599. [DOI: 10.1126/science.275.5306.1593](https://doi.org/10.1126/science.275.5306.1593). —— 多巴胺神经元编码奖励预测误差(RPE)的经典实验:猕猴 VTA/SNc 多巴胺神经元在意外奖励时激增(正 RPE)、预测到奖励时响应前移到条件刺激(CS)、奖励未兑现时抑制(负 RPE),三类响应恰好对应 TD 误差 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$ 的正/零/负。价值从 US 反传到 CS 的「前移」现象,正是 TD 学习中 $\delta$ 沿资格迹倒推信用分配的生物学对应。本文是「跨学科实证」一节多巴胺部分的直接来源。
