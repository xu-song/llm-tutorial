# 🐼 Pandas 数据处理

[上一篇](/tutorials/python-numpy-basics)的 NumPy 擅长**纯数值**计算,但真实世界的数据长得像 Excel 表格:有列名、有文字、有缺失值。**Pandas** 就是处理这种**表格数据**的利器,几乎所有机器学习项目的第一步——读取、清洗、探索数据——都靠它。

> NumPy 的数组是「一块数字」,Pandas 的 DataFrame 是「带标签的表格」。做 ML,80% 的时间花在用 Pandas 把数据整理干净。

## DataFrame:核心数据结构

**DataFrame** 就是一张二维表(行=样本,列=特征)。最常用的创建方式是从字典:

<CodeRunner
  packages={["pandas"]}
  defaultCode={`
import pandas as pd

# 每个键是一列
df = pd.DataFrame({
    "姓名": ["小明", "小红", "小刚", "小美"],
    "年龄": [23, 35, 28, 42],
    "城市": ["北京", "上海", "北京", "深圳"],
    "月薪": [15000, 28000, 19000, 35000],
})

print(df)
print("\\n形状(行, 列):", df.shape)
print("列名:", list(df.columns))
`} />

## 查看与选择数据

拿到一份数据,先用这几个方法「摸底」:

## 筛选:按条件挑出行

和 NumPy 的布尔索引一脉相承,Pandas 用条件表达式筛选行:

<CodeRunner
  packages={["pandas"]}
  defaultCode={`
import pandas as pd

df = pd.DataFrame({
    "姓名": ["小明", "小红", "小刚", "小美"],
    "年龄": [23, 35, 28, 42],
    "城市": ["北京", "上海", "北京", "深圳"],
    "月薪": [15000, 28000, 19000, 35000],
})

# 月薪 > 18000 的人
print("高薪人群:\\n", df[df["月薪"] > 18000])

# 多条件:北京 且 年龄 < 30(注意用 & 和括号)
print("\\n北京的年轻人:\\n", df[(df["城市"] == "北京") & (df["年龄"] < 30)])

# 新增一列:税后月薪(向量化,无需循环)
df["税后"] = (df["月薪"] * 0.85).round(0)
print("\\n加一列后:\\n", df)
`} />

## 分组聚合:groupby

**`groupby`** 是 Pandas 最强大的功能——「分组 → 聚合」,一行回答「每个城市的平均月薪是多少」这类问题:

<CodeRunner
  packages={["pandas"]}
  defaultCode={`
import pandas as pd

df = pd.DataFrame({
    "城市": ["北京", "上海", "北京", "深圳", "上海", "北京"],
    "部门": ["研发", "研发", "销售", "研发", "销售", "销售"],
    "月薪": [15000, 28000, 19000, 35000, 22000, 18000],
})

# 按城市分组求平均月薪
print("各城市平均月薪:\\n", df.groupby("城市")["月薪"].mean().round(0))

# 多重聚合:每个城市的人数 + 月薪总和
print("\\n各城市人数与总薪:\\n",
      df.groupby("城市")["月薪"].agg(["count", "sum"]))

# 按两个维度交叉分组
print("\\n城市 × 部门 平均月薪:\\n",
      df.groupby(["城市", "部门"])["月薪"].mean().round(0))
`} />

## 处理缺失值

真实数据几乎总有缺失(`NaN`)。Pandas 提供了优雅的检测与填补方法——这是 ML 预处理的关键一步:

<CodeRunner
  packages={["pandas"]}
  defaultCode={`
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "姓名": ["小明", "小红", "小刚", "小美"],
    "年龄": [23, np.nan, 28, 42],
    "月薪": [15000, 28000, np.nan, 35000],
})

print("每列缺失值个数:\\n", df.isnull().sum())

# 方法一:用均值填补缺失(数值列常用)
df_filled = df.copy()
df_filled["年龄"] = df_filled["年龄"].fillna(df_filled["年龄"].mean().round(0))
df_filled["月薪"] = df_filled["月薪"].fillna(df_filled["月薪"].median())
print("\\n均值/中位数填补后:\\n", df_filled)

# 方法二:直接丢弃含缺失的行
print("\\n丢弃缺失行后剩:", df.dropna().shape[0], "行")
`} />

## 从模型角度:Pandas → NumPy → 模型

机器学习模型(scikit-learn)吃的是 NumPy 数组。典型流程是:**用 Pandas 整理 → 取出特征矩阵 X 和标签 y → 喂给模型**:

<CodeRunner
  packages={["pandas", "scikit-learn"]}
  defaultCode={`
import pandas as pd
from sklearn.linear_model import LinearRegression

# 用 Pandas 准备数据
df = pd.DataFrame({
    "面积": [50, 70, 90, 110, 130],
    "卧室": [1, 2, 2, 3, 3],
    "房价": [150, 210, 265, 330, 380],
})

X = df[["面积", "卧室"]]   # 特征(DataFrame 可直接喂给 sklearn)
y = df["房价"]             # 标签

model = LinearRegression().fit(X, y)
print("面积系数:", round(model.coef_[0], 2))
print("预测 [100㎡, 3卧]:", round(model.predict([[100, 3]])[0], 1), "万")
`} />

## 典型应用场景

- **数据加载**:`pd.read_csv()` / `read_excel()` 读取真实数据集
- **探索性数据分析(EDA)**:`describe()`、`value_counts()`、`groupby()` 快速理解数据
- **特征工程**:造新列、分箱、独热编码(`pd.get_dummies`)
- **数据清洗**:处理缺失值、去重(`drop_duplicates`)、改类型
- **时间序列**:Pandas 对日期/时间的处理极其强大(`pd.to_datetime`、重采样)

## 常见问题 FAQ

**Q:Series 和 DataFrame 什么区别?**
DataFrame 的**一列**就是一个 Series(带索引的一维数据)。`df["年龄"]` 返回 Series,`df[["年龄"]]`(双括号)返回单列 DataFrame。

**Q:`loc` 和 `iloc` 怎么区分?**
`loc` 按**标签**选(行索引名、列名),`iloc` 按**整数位置**选(第几行第几列)。例:`df.loc[0, "年龄"]` vs `df.iloc[0, 1]`。

**Q:筛选时为什么不能用 `and` / `or`?**
多条件要用 `&`、`|`、`~`,且每个条件加括号:`df[(A) & (B)]`。Python 的 `and`/`or` 作用于单个布尔值,无法对整列向量化。

**Q:`SettingWithCopyWarning` 是什么?**
对切片再赋值时的常见警告,提示你可能在副本而非原表上修改。规范做法:先 `.copy()`,或用 `df.loc[行, 列] = 值` 明确赋值。

**Q:Pandas 和 NumPy 该用哪个?**
有列名、混合类型、需要清洗/分组的**表格数据**用 Pandas;纯数值矩阵运算、喂给模型时转成 NumPy。两者无缝互转:`df.values` / `df.to_numpy()`。

## 小结

| 操作 | 方法 |
|---|---|
| 创建 / 查看 | `pd.DataFrame()`、`head()`、`describe()`、`shape` |
| 选择 | `df["列"]`、`df[["多列"]]`、`loc` / `iloc` |
| 筛选 | `df[条件]`,多条件用 `&` `\|` `~` + 括号 |
| 分组聚合 | `groupby("列")[...].mean()/agg()` |
| 缺失值 | `isnull()`、`fillna()`、`dropna()` |
| 转 NumPy | `df.values` / `to_numpy()`,喂给 sklearn |
