# 📧 朴素贝叶斯

还记得[概率论基础](/tutorials/probability-basics)里的**贝叶斯定理**吗?**朴素贝叶斯**就是把它直接用作分类器:给定一封邮件的词,算「它是垃圾邮件的概率」。它简单、快、在文本分类上出奇地好用 —— 曾是垃圾邮件过滤器的标配。

> 「看到『免费』『中奖』这些词,这封邮件多半是垃圾」—— 朴素贝叶斯就是把这种直觉变成了概率计算。

## 从贝叶斯定理到分类器

要判断邮件属于哪一类,就比较**后验概率**:$P(\text{垃圾} \mid \text{词})$ vs $P(\text{正常} \mid \text{词})$,哪个大就判哪类。由贝叶斯定理:

$$
P(C \mid x_1, \dots, x_n) \propto P(C) \prod_{i=1}^{n} P(x_i \mid C)
$$

- $P(C)$ 是**先验**(某类邮件本身有多常见)
- $P(x_i \mid C)$ 是**似然**(某类里出现这个词的概率)
- 把它们连乘,就得到(未归一化的)后验

## 「朴素」在哪?

那个连乘 $\prod P(x_i \mid C)$ 藏着一个大胆假设:**所有特征相互条件独立**。现实中「免费」和「中奖」显然常一起出现,并不独立 —— 所以这个假设「很朴素(naive)」。神奇的是:**即便假设不成立,分类效果往往依然很好**,因为我们只需要比大小,不需要概率绝对精确。

「怎么表示一封邮件」其实有多种建模方式,**多项式事件模型**(multinomial:用词频)和**伯努利事件模型**(multi-variate Bernoulli:用词出现与否)是文本分类里最经典的两种。McCallum & Nigam 1998 年的论文系统对比了这两种事件模型 —— 下图是它们在不同词汇表大小下的分类准确率:两种模型各有胜负,且都随词典规模变化:

## 用 scikit-learn 实现

`sklearn` 提供几种朴素贝叶斯。文本用 `MultinomialNB`,连续特征用 `GaussianNB`。下面做一个真实文本分类:

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

# 训练文本(垃圾=1,正常=0)
texts = [
    "免费 中奖 点击 领取", "限时 免费 优惠 点击",
    "中奖 通知 领取 奖金", "明天 会议 几点 开始",
    "项目 进度 会议 讨论", "午饭 一起 吃 吗",
]
labels = [1, 1, 1, 0, 0, 0]

vec = CountVectorizer()
X = vec.fit_transform(texts)
clf = MultinomialNB().fit(X, labels)

# 预测新邮件
for msg in ["免费 领取 奖金", "会议 讨论 项目"]:
    p = clf.predict_proba(vec.transform([msg]))[0]
    tag = "垃圾" if clf.predict(vec.transform([msg]))[0] else "正常"
    print(f"「{msg}」→ {tag}(垃圾概率 {p[1]:.1%})")
`} />

## 高斯朴素贝叶斯:连续特征

特征是连续值(如身高、体重)时,用 `GaussianNB`,它假设每个特征在每类下服从[正态分布](/tutorials/probability-basics):

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.naive_bayes import GaussianNB
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=0)

clf = GaussianNB().fit(Xtr, ytr)
print("测试准确率:", round(clf.score(Xte, yte), 3))
print("每类的先验概率:", clf.class_prior_.round(3))
`} />

> 💡 就这么简单几行,朴素贝叶斯在鸢尾花上就能到 90%+ —— 训练几乎瞬间完成,这是它的一大优势。

## 拉普拉斯平滑:避免「零概率陷阱」

如果某个词在训练集的某类里**从没出现过**,它的似然就是 0,连乘后整个后验被清零 —— 一个没见过的词就否决了一切。解决办法是**拉普拉斯平滑(加一平滑)**:给每个计数都加一个小常数,保证概率永不为 0。`sklearn` 用参数 `alpha` 控制(默认 1.0)。

## 典型应用场景

- **垃圾邮件 / 垃圾短信过滤**:朴素贝叶斯的成名之作
- **文本分类 / 情感分析**:新闻分类、评论正负面判断
- **实时预测**:训练和预测都极快,适合高吞吐场景
- **基线模型**:简单到几乎零成本,常用作衡量复杂模型是否值得的基准

## 常见问题 FAQ

**Q:「朴素」到底朴素在哪?**
在于假设**所有特征相互条件独立**(给定类别后)。现实中特征常相关,这个假设几乎总不成立,但分类效果依然常常不错——因为决策只看后验大小的排序,不要求概率精确。

**Q:效果好为什么还说它假设错了?**
即便概率估计有偏,只要**正确类的后验仍然最大**,分类就对。朴素贝叶斯常常「概率不准但排序对」,所以分类准、概率别太当真。

**Q:MultinomialNB、GaussianNB、BernoulliNB 怎么选?**
`MultinomialNB` 用于计数特征(词频,文本);`GaussianNB` 用于连续特征(假设正态);`BernoulliNB` 用于二元特征(词出现与否)。按特征类型选。

**Q:为什么要拉普拉斯平滑?**
防止「零概率陷阱」:训练中没出现过的词会让似然为 0,连乘后清零整个概率。加一平滑保证每个概率都 > 0。

**Q:朴素贝叶斯和逻辑回归什么关系?**
两者都可做概率分类,常被拿来对比:朴素贝叶斯是**生成式**(建模 $P(x\mid C)$),逻辑回归是**判别式**(直接建模 $P(C\mid x)$)。小数据下朴素贝叶斯常更稳,数据多时逻辑回归通常更准。

## 小结

| 要点 | 说明 |
|---|---|
| 原理 | 贝叶斯定理:后验 ∝ 先验 × ∏ 似然 |
| 「朴素」 | 假设特征间条件独立(常不成立却好用) |
| 变体 | Multinomial(计数)/ Gaussian(连续)/ Bernoulli(二元) |
| 平滑 | 拉普拉斯(加一)平滑避免零概率 |
| 优点 | 极快、需数据少、文本分类强、可作基线 |
| 局限 | 独立假设、概率估计不够精确 |

> 🎯 一句话:**朴素贝叶斯把贝叶斯定理 + 一个「大胆的独立假设」变成了又快又好用的分类器。** 它是[概率论](/tutorials/probability-basics)在机器学习里最直接、最经典的落地。
