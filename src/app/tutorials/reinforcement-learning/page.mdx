# 🕹️ 强化学习入门

前面所有教程都属于**监督学习**——有输入、有标准答案（标签），模型照着答案学。但很多问题**没有标准答案**：下棋没人告诉你「这一步的正确落子」，只有终局的输赢；机器人走迷宫没人标注每一步，只有到达终点的奖励。这就是**强化学习（Reinforcement Learning, RL）** 的舞台：**智能体（agent）在环境里试错，靠奖励信号自己摸索出好策略。**

## 三要素：状态、动作、奖励

强化学习的世界由一个循环构成：

- **状态 $s$（state）**：智能体当前的处境（棋盘布局、迷宫里的位置）.
- **动作 $a$（action）**：它能做的选择（落子、上下左右移动）.
- **奖励 $r$（reward）**：环境给的反馈信号（赢 +1、掉坑 −1、每走一步 −0.02）.

智能体在状态 $s$ 选动作 $a$，环境转移到新状态 $s'$ 并给出奖励 $r$，如此往复。目标不是最大化**眼前**的奖励，而是最大化**长期累积**的奖励（**回报**）：

$$
G_t = r_t + \gamma\, r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^{\infty}\gamma^k r_{t+k}
$$

其中**折扣因子** $\gamma\in[0,1)$ 让「近处的奖励比远处的值钱」——既符合直觉，也保证无穷级数收敛。

**拖动 $\gamma$**，看未来每一步的奖励折算到现在还剩多少权重（$\gamma^k$），以及「有效视界」$1/(1-\gamma)$ 落在第几步——它直观地告诉你智能体大致「能看多远」：

<DiscountFactorViz />

> 📚 这套「状态→动作→奖励→新状态」的框架，数学上叫**马尔可夫决策过程（MDP）**。「马尔可夫」的意思是：下一步只取决于当前状态，与怎么走到这儿的历史无关。

## 策略与价值：两个核心概念

- **策略 $\pi(a\mid s)$（policy）**：智能体的「行为准则」——在状态 $s$ 下选各动作的概率.学习的最终产物就是一个好策略.
- **价值 $V(s)$ / $Q(s,a)$(value)**：对「长期回报」的预估.
  - **状态价值** $V(s)$：从 $s$ 出发，按策略走下去平均能拿多少回报。
  - **动作价值** $Q(s,a)$：在 $s$ 先做动作 $a$、之后按策略走，平均回报多少。

有了 $Q$，策略就现成了：**每步选 $Q$ 最大的动作**。所以很多算法的目标就是「学准 $Q$」。

## Q-learning：从试错中学出 Q 表

**Q-learning** 是最经典的 RL 算法。它维护一张 $Q(s,a)$ 表，每次交互后用**贝尔曼方程**做一步更新：

$$
Q(s,a) \leftarrow Q(s,a) + \alpha\Big[\underbrace{r + \gamma\max_{a'}Q(s',a')}_{\text{新的估计(TD 目标)}} - \underbrace{Q(s,a)}_{\text{旧估计}}\Big]
$$

直觉：用「即时奖励 $r$ + 下一状态最好动作的价值」来修正当前估计，一点点逼近真值。$\alpha$ 是学习率。

还有个关键权衡——**探索 vs 利用（exploration vs exploitation）**：一直选当前最优（利用）可能错过更好的路；偶尔随机乱走（探索）才能发现新大陆。常用 **ε-贪心**：以概率 $\varepsilon$ 随机、否则贪心，并让 $\varepsilon$ 随训练衰减。

**多臂老虎机（bandit）** 是最精简的 RL：没有「状态转移」，只有一个决策——面前 4 台老虎机，中奖率未知，每次拉一台。它把**探索 vs 利用**这个核心矛盾单独拎出来：只拉当前最好的（利用）可能错过真正的好机器，得偶尔试试没拉过的（探索）。

> 📚 bandit 自带一整片天地——后悔值、增量更新、UCB 的「乐观面对不确定性」、Thompson 的后验采样、梯度老虎机、上下文 bandit，都藏在[多臂老虎机:探索与利用](/tutorials/multi-armed-bandit)专篇里。本篇先用它当「探索-利用」的最小例子；想深挖请读专篇。

**拖动「拉动次数」**，看估计中奖率（彩色柱）如何逼近真实值（虚线）、选择如何集中到最优臂：

下面是它的完整实现，可改真实中奖率 `true` 或探索率重跑：

<CodeRunner defaultCode={`
import numpy as np
rng = np.random.default_rng(0)

true = np.array([0.2, 0.5, 0.75, 0.4])   # 4 台机器的真实中奖率(智能体不知道)
Q = np.zeros(4)                            # 对每台机器中奖率的估计
Nsel = np.zeros(4)                         # 每台被拉过的次数

for t in range(2000):
    eps = max(0.02, 1.0 - t/500)           # 探索率:先多探索,后期收敛到利用
    a = rng.integers(4) if rng.random() < eps else int(Q.argmax())
    r = 1.0 if rng.random() < true[a] else 0.0   # 拉这台,按真实中奖率掷一次
    Nsel[a] += 1
    Q[a] += (r - Q[a]) / Nsel[a]           # 增量式更新平均中奖率

print("估计中奖率:", np.round(Q, 3))
print("真实中奖率:", true)
print(f"真正最好的是第 {true.argmax()} 台;智能体拉得最多的是第 {int(Nsel.argmax())} 台")
print("-> 靠试错,它找出了中奖率最高的机器")
`} />

**ε-贪心的探索是「盲目」的**——随机挑一台，不管这台是「没试够、还拿不准」还是「已知很差」。**UCB（上置信界）** 换个思路：**乐观面对不确定性**，给每台机器的估计值加一个「不确定性奖励」，专挑那些**没试够**的机器去探索：

$$
a_t = \arg\max_a\Big[\underbrace{Q(a)}_{\text{利用:目前多好}} + \underbrace{c\sqrt{\tfrac{\ln t}{N(a)}}}_{\text{探索:多久没试了}}\Big]
$$

拉得越少的臂，第二项越大、越会被「照顾」到；随着 $N(a)$ 增大，这项自动缩小。于是探索是**定向的**，而非 ε-贪心那样均匀撒随机：

<CodeRunner defaultCode={`
import numpy as np
rng = np.random.default_rng(0)

true = np.array([0.2, 0.5, 0.75, 0.4])
Q = np.zeros(4); N = np.zeros(4)
c = 2.0                                    # 探索强度

for a in range(4):                         # 先把每台都拉一次(否则 ln t / 0 无定义)
    r = 1.0 if rng.random() < true[a] else 0.0
    N[a] += 1; Q[a] += (r - Q[a]) / N[a]

for t in range(4, 2000):
    ucb = Q + c * np.sqrt(np.log(t) / N)   # 估计 + 不确定性奖励
    a = int(ucb.argmax())                  # 没有随机!全靠这个上置信界
    r = 1.0 if rng.random() < true[a] else 0.0
    N[a] += 1; Q[a] += (r - Q[a]) / N[a]

print("估计中奖率:", np.round(Q, 3))
print("各臂拉动次数:", N.astype(int))
print(f"UCB 把绝大多数尝试集中到第 {int(N.argmax())} 台(真实最好: {int(true.argmax())})")
print("-> 不靠随机,而是靠'越没把握越想试'把最优臂找出来")
`} />

**Thompson sampling（汤普森采样）** 是第三条路，干脆**贝叶斯**到底：给每台机器的未知中奖率 $\theta_k$ 维护一个**后验分布**，每步从各臂后验里**各采一个样本**，选采样值最大的那台。对 0/1 奖励，最自然的是 **Beta 分布**作先验（与伯努利似然共轭，更新极简）：

$$
\theta_k \sim \mathrm{Beta}(\alpha_k,\beta_k),\qquad \alpha_k\leftarrow\alpha_k+r,\quad \beta_k\leftarrow\beta_k+(1-r)
$$

中奖就 $\alpha$ 加 1、没中就 $\beta$ 加 1（初始 $\alpha=\beta=1$ 即均匀先验）。妙处在于这是**概率匹配（probability matching）**：某臂被选中的概率，正好等于它「是真正最优」的后验概率。估计高（均值大）的臂常被选——这是利用；但**后验越宽（数据越少）的臂也越可能采出大值**而中选——这是探索。无需任何探索参数，不确定性自动驱动探索，数据多了后验收窄、探索自然消退：

<CodeRunner defaultCode={`
import numpy as np
rng = np.random.default_rng(42)

true = np.array([0.2, 0.5, 0.75, 0.4])
alpha = np.ones(4)                       # Beta(1,1) = 均匀先验
beta  = np.ones(4)
N = np.zeros(4); Q = np.zeros(4)

for t in range(2000):
    samples = rng.beta(alpha, beta)      # 从每个臂的后验各采一个样本
    a = int(samples.argmax())            # 选采样值最大的臂
    r = 1.0 if rng.random() < true[a] else 0.0
    N[a] += 1; Q[a] += (r - Q[a]) / N[a]
    if r: alpha[a] += 1                  # 中奖:α+1
    else:  beta[a]  += 1                 # 未中:β+1

print("真实中奖率:", true)
print("估计中奖率:", np.round(Q, 3))
print("各臂拉动次数:", N.astype(int))
print(f"Thompson 把绝大多数尝试集中到第 {int(N.argmax())} 台(真实最好: {int(true.argmax())})")
print("-> 无需探索参数,靠'从后验采样'自动在试新与用旧间权衡")
`} />

> 💡 **三种探索策略对照**：ε-贪心靠**盲目随机**（均匀撒网，会浪费在已知很差的臂上）；UCB 靠**乐观上界**（确定性，「越没把握越想试」）；Thompson 靠**后验采样**（随机，「概率匹配」）。三者 regret 都是 $O(\sqrt{KT\ln T})$ 同阶，但 Thompson 无需调参、且天然延伸到上下文/连续分布，实战中常是首选——这也是它在推荐系统、A/B 测试里比 UCB 更流行的原因。

### 超越 bandit：稀疏奖励下的好奇心探索

上面三种策略都假设「每步都有奖励」。但真实环境常常**奖励极度稀疏**——比如 Montezuma's Revenge 里，智能体可能随机走上千步都碰不到一个奖励信号，ε-贪心的盲目随机几乎注定永远找不到。这时需要**内在动机（intrinsic motivation）**：不依赖环境奖励，自己造一个**好奇心驱动的密集信号** $r_t = r^e_t + \beta\, r^i_t$。ICM、RND、noisy-TV 陷阱的完整讲法见下文「内在奖励与好奇心探索」专节。

**Q-learning（价值法 · off-policy）** 是最经典的 RL：在 4×4 网格里维护一张 $Q(s,a)$ 表，用贝尔曼方程迭代。它更新时用 $\max_{a'}Q(s',a')$——**假设下一步一定走最优**，所以是 off-policy（学的策略 ≠ 探索时的行为）。这就是上面网格世界背后的算法。

<CodeRunner defaultCode={`
import numpy as np

N, GOAL, PIT, START = 4, 15, 9, 0
A = [(0,-1),(1,0),(0,1),(-1,0)]   # 上 右 下 左

def step(s, a):
    r, c = divmod(s, N); dc, dr = A[a]
    nr, nc = r + dr, c + dc
    return nr*N + nc if (0 <= nr < N and 0 <= nc < N) else s

def reward(s):
    return 1.0 if s == GOAL else -1.0 if s == PIT else -0.02

Q = np.zeros((N*N, 4))
rng = np.random.default_rng(0)
alpha, gamma = 0.5, 0.9

for ep in range(400):
    s = START
    eps = max(0.05, 0.5 - ep/800)          # 探索率逐步衰减
    for _ in range(60):
        if s in (GOAL, PIT): break
        a = rng.integers(4) if rng.random() < eps else int(Q[s].argmax())
        ns = step(s, a); r = reward(ns); done = ns in (GOAL, PIT)
        # 贝尔曼更新:用"下一步最优" max Q(s',·)
        Q[s, a] += alpha * (r + (0 if done else gamma*Q[ns].max()) - Q[s, a])
        s = ns

s, path = START, [0]
for _ in range(20):
    if s in (GOAL, PIT): break
    s = step(s, int(Q[s].argmax())); path.append(s)

print("学到的路径(格子编号):", path)
print("是否到达目标 🏁 :", path[-1] == GOAL)
print("绕开陷阱 🕳️(格9)了吗:", PIT not in path)
`} />

**SARSA（价值法 · on-policy）** 和 Q-learning 几乎一样，只有一处不同：更新时用**实际走的下一个动作** $Q(s',a')$，而不是 $\max$。因为它评估的是「自己带探索的真实策略」，所以更**保守**——在有陷阱时倾向选一条离坑更远的安全路。

import numpy as np

N, GOAL, PIT, START = 4, 15, 9, 0
A = [(0,-1),(1,0),(0,1),(-1,0)]

def step(s, a):
    r, c = divmod(s, N); dc, dr = A[a]
    nr, nc = r + dr, c + dc
    return nr*N + nc if (0 <= nr < N and 0 <= nc < N) else s

def reward(s):
    return 1.0 if s == GOAL else -1.0 if s == PIT else -0.02

rng = np.random.default_rng(0)
def egreedy(Q, s, eps):
    return rng.integers(4) if rng.random() < eps else int(Q[s].argmax())

Q = np.zeros((N*N, 4))
alpha, gamma = 0.5, 0.9

for ep in range(400):
    s = START; eps = max(0.05, 0.5 - ep/800)
    a = egreedy(Q, s, eps)                  # 先选好第一个动作
    for _ in range(60):
        if s in (GOAL, PIT): break
        ns = step(s, a); r = reward(ns); done = ns in (GOAL, PIT)
        na = egreedy(Q, ns, eps)            # 关键:实际要走的下一个动作
        # 更新用 Q(s',a') 而非 max —— 这就是 SARSA(State-Action-Reward-State-Action)
        Q[s, a] += alpha * (r + (0 if done else gamma*Q[ns, na]) - Q[s, a])
        s, a = ns, na

s, path = START, [0]
for _ in range(20):
    if s in (GOAL, PIT): break
    s = step(s, int(Q[s].argmax())); path.append(s)

print("SARSA 学到的路径:", path)
print("(和 Q-learning 对比:SARSA 常选一条离陷阱 🕳️ 更远的保守路线)")

<CodeRunner defaultCode={`
import numpy as np
rng = np.random.default_rng(0)

true = np.array([0.2, 0.5, 0.75, 0.4])   # 真实中奖率
theta = np.zeros(4)                        # 策略参数(每个动作一个偏好分)
lr, baseline = 0.1, 0.5

def softmax(z):
    z = z - z.max(); e = np.exp(z); return e / e.sum()

for t in range(3000):
    p = softmax(theta)                     # 当前策略:各臂的选取概率
    a = rng.choice(4, p=p)                 # 按策略采样一个动作
    r = 1.0 if rng.random() < true[a] else 0.0
    grad = -p; grad[a] += 1                # ∂logπ(a)/∂θ
    theta += lr * (r - baseline) * grad    # 回报高于基线 -> 提高该动作概率

print("最终策略概率:", np.round(softmax(theta), 3))
print(f"策略把绝大部分概率押在了第 {int(softmax(theta).argmax())} 台(真实最好: {true.argmax()})")
print("-> 没学价值表,直接把'好动作'的概率推高了")

## On-policy 与 off-policy：一条主线

上面 Q-learning 和 SARSA 只差更新目标里一项，却分属两大阵营——这个区别贯穿整个强化学习，理解它就拿到了看懂 DQN、PPO、offline RL 的钥匙。

关键是分清两个策略：

- **行为策略（behavior policy）**：真正拿去**和环境交互、采集数据**的策略——通常带探索（如 ε-贪心）,会做些「次优但为了试探」的动作.
- **目标策略（target policy）**：我们真正**想学好、最终要用**的策略.

**两者是否同一个，就划出了 on / off:**

| | on-policy（同策略） | off-policy（异策略） |
|---|---|---|
| 行为策略 vs 目标策略 | **同一个** | **可以不同** |
| 用什么数据学 | 只能用当前策略**刚跑出来**的数据 | 可复用**旧策略/别人**产生的数据 |
| 旧数据 | 策略一更新就作废 | 存进缓冲区反复用 |
| 样本效率 | 较低 | 较高 |
| 稳定性 / 贴合度 | 更稳，直接评估「真实在跑的策略」 | 需技巧防发散（见[致命三元组](/tutorials/dqn)） |
| 代表算法 | SARSA、[PPO](/tutorials/policy-gradient) | Q-learning、[DQN](/tutorials/dqn) |

**为什么 Q-learning 是 off-policy？** 它更新时用 $\max_{a'}Q(s',a')$——**假设下一步一定走最优**（目标策略是贪心的），可它实际探索时却在 ε-贪心地乱走（行为策略带探索）。学的和跑的不是一个策略，所以 off。而 SARSA 用**实际走的**那个 $a'$ 更新，学的就是「自己带探索地在跑的策略」，所以 on。

**这个区别有什么实际后果？**

- **能不能用经验回放**：off-policy 才能把历史转移存进缓冲区反复抽——[DQN](/tutorials/dqn) 的样本效率正来自于此;PPO 这类 on-policy 方法每次更新后旧数据就得扔,只能不停采新的.
- **保守还是激进**：上面悬崖行走图里,on-policy 的 SARSA 知道「自己偶尔会探索失足」,于是绕开悬崖走保守路;off-policy 的 Q-learning 只认那个不探索的最优目标策略,敢贴着悬崖走最短路.
- **推向极致就是 offline RL**：连采样都不做,纯用一堆**固定的历史数据**学策略——这是 off-policy 思想的终点,也是把 RL 用到医疗、自动驾驶等「不能在真实环境试错」场景的关键方向（详见[离线强化学习](/tutorials/offline-rl)篇）.

> 💡 一句话记：**off-policy 能翻旧账、样本效率高但要防发散；on-policy 只认新数据、更稳更贴合真实策略。** RLHF 里用 [PPO](/tutorials/rlhf)（on-policy）就是图它稳——对齐大模型时，训练的稳定性比样本效率金贵得多。

## 内在奖励与好奇心探索

上面 bandit 标签里提到「稀疏奖励下要靠好奇心造内在奖励」，这里把它讲透。问题的起点是**稀疏奖励 + 高维状态**：像 Montezuma's Revenge 这种 Atari 游戏，只有拿到钥匙、开门才有奖励，智能体随机游走上千步都碰不到一个信号；ε-贪心、UCB 这类**面向奖励**的探索全部失灵——没有奖励梯度，就没有方向。解决思路是**把「找信息」变成「最大化奖励」这个智能体本来就会的问题**：给它一个**内在奖励 $r^i_t$**，奖励的不是「拿了多少分」，而是「**学到了多少新东西**」。总奖励变成两项之和：

$$
r_t \;=\; r^e_t \;+\; \beta\, r^i_t
$$

$r^e_t$ 是环境给的外在奖励（extrinsic），$r^i_t$ 是智能体自造的内在探索奖励（intrinsic），$\beta$ 是权衡系数。剩下的问题就一个：**怎么衡量「新东西」？**

### 思路一：基于计数——少见即新奇

最朴素的办法直接搬 UCB 的思路：给**少见的状态**发奖金。维护一个状态访问计数 $N(s)$，内在奖励取

$$
r^i_t \;\propto\; \frac{1}{\sqrt{N(s_t)}}
$$

状态越没见过，$N$ 越小，奖金越高；去过了，$N$ 增大，奖金自动衰减——探索是**定向**的，而非 ε-贪心那样均匀撒随机。这在表格世界里完美，但深度 RL 的状态是高维像素（210×160 的画面），**几乎不可能两次见到完全相同的帧**，$N(s)$ 永远是 1，bonus 永远拉满，等于没探索。于是要靠**伪计数（pseudo-count）** $\hat N(s)$：不直接数「这一帧出现过几次」（永远是 0 或 1），而是用一个**密度模型**估计「这个状态在训练集里出现的概率密度」，再从概率反推一个等效计数 [10]。<Cite n={10} />

下面这个交互先在**表格世界**里把「定向 vs 盲目」的差距演示清楚：同一张 7×7 稀疏奖励网格（奖励只在右下角），左边跑 ε-贪心的盲目随机游走，右边跑基于计数的新奇性探索（总往访问最少的邻格走，即 $r^i\propto 1/\sqrt{N(s)}$）。拖动滑块看两者足迹热力的分道扬镳：

#### 伪计数：从密度模型反推等效计数

Bellemare et al. 2016 [10] 的关键观察：一个**学习正（learning-positive）**的密度模型——多见到一次状态 $x$，它对 $x$ 的预测概率就**上升**——本身就编码了「$x$ 见过几次」的信息。<Cite n={10} />设密度模型在见过 $n$ 个样本后对状态 $x$ 的预测概率为 $\rho_n(x)$（prediction probability），再喂一个 $x$ 后重训，概率变成 $\rho'_n(x)$（recoding probability）。学习正保证 $\rho_n(x)\le\rho'_n(x)$。把这两个概率和一个真实计数模型类比：

$$
\rho_n(x)=\frac{\hat N_n(x)}{\hat n},\qquad \rho'_n(x)=\frac{\hat N_n(x)+1}{\hat n+1}
$$

解这个二元一次方程，就得到**伪计数**与总样本数的估计：

$$
\boxed{\;\hat N_n(x)=\frac{\rho_n(x)\big(1-\rho'_n(x)\big)}{\rho'_n(x)-\rho_n(x)}\;,\qquad \hat n=\frac{1-\rho'_n(x)}{\rho'_n(x)-\rho_n(x)}\;}
$$

只要密度模型学习正，$\hat N_n(x)$ 就是一个合法的「等效访问次数」：常见状态 $\rho_n$ 大、$\rho'_n\approx\rho_n$，$\hat N$ 大；少见状态 $\rho_n$ 小、$\rho'_n$ 显著大于 $\rho_n$，$\hat N$ 小。内在奖励照搬 UCB 形式：

$$
r^i_t=\frac{1}{\sqrt{\hat N_n(s_t)+0.01}}
$$

（分母加 $0.01$ 是为 $\hat N=0$ 时数值稳定）。**妙处在于**：密度模型是在**连续概率空间**上工作的，它能对「没见过但相似」的状态给出合理概率，从而把 count-based 探索从表格世界推广到高维像素——两个相近的帧不要求完全相同，只要密度模型认为它们概率接近，pseudo-count 就接近。

> 💡 **与 prediction gain 的关系**：伪计数还能用一个更易算的量近似。定义**预测增益** $\mathrm{PG}_n(x)=\log\rho'_n(x)-\log\rho_n(x)$（喂入 $x$ 后密度模型对 $x$ 的对数概率提升量），则 $\hat N_n(x)\approx\big(e^{\mathrm{PG}_n(x)}-1\big)^{-1}$。预测增益大（模型进步快）= 见得少 = $\hat N$ 小 = bonus 高。这把 count-based 探索和「学习进度 / 压缩进展」information-theoretic 视角统一了起来 [10]。

#### 密度模型的演进：CTS → PixelCNN

伪计数本身不限定密度模型选哪种，只要学习正即可。Bellemare et al. 2016 [10] 用一个轻量的 **CTS(Context Tree Switching)**密度模型——按像素位置独立地用 L 形滤波器乘积估计整帧概率——在 Atari 原始像素上算 $\rho_n$，$\hat N$ 驱动的内在奖励在**Montezuma's Revenge**（ notoriously 难探索、随机游走几乎拿不到分）上首次取得进展。Ostrovski et al. 2017 [11] 把 CTS 换成更强的 **PixelCNN** 神经密度模型，大幅提升概率估计质量，在多个 hard-exploration Atari 游戏上刷新纪录。<Cite n={11} />后续还有用高斯混合模型（Zhao & Tresp 2018）等变体——**密度模型越准，pseudo-count 越接近真实计数，探索越定向**。

#### 另一条路：Hash 降维再数

不学密度模型，也可以先把高维状态**哈希到低维桶**再朴素地数。Tang et al. 2017 [12] 用 SimHash（或 autoencoder 编码后哈希）把每帧映射到一个低维二进制码，相同码的状态视为「同类」，对桶计数 $N(\text{bucket})$ 驱动 bonus。比密度模型简单（无需训练生成模型），但**哈希冲突**会把 genuinely 不同的状态混到一桶，粒度不如 pseudo-count 细。<Cite n={12} />两条路同源：都是把「高维状态空间里数不过来」降维成「低维空间里数得清」。

> ⚠️ **count-based 的局限**：pseudo-count 依赖密度模型对状态分布建模准。高维连续状态（机器人关节、自动驾驶点云）上，密度模型本身难训、估计不稳；且 count-based 本质是**局部探索**（去没见过的相邻状态），对「先去 A 房拿钥匙、再回 B 房开门」这类**长程协调**仍无能为力——这与下面 ICM/RND 的 noisy-TV 陷阱同源，是好奇心探索共同的开放前沿。

### 思路二：ICM——预测误差当好奇心，但只学「能控制的」部分

**ICM(Intrinsic Curiosity Module, Pathak et al. 2017)**[2] 换了个更巧妙的衡量：训一个**前向动力学模型（forward model）**，给定当前状态和动作，预测下一步状态；**预测不准 = 没见过 = 好奇**。<Cite n={2} />但直接在原始像素上预测会掉进 noisy-TV 陷阱（下文详述），所以 ICM 先用一个**逆向动力学模型（inverse model）**学一个**特征空间** $\phi(s)$：

- **逆向模型** $g_\phi$：输入相邻两帧 $(s_t, s_{t+1})$，预测中间采取的动作 $\hat a_t = g(s_t, s_{t+1})$。要预测动作，它**必须学到那些「受动作影响」的特征**——动作改变不了的东西（背景墙、噪点电视）对预测动作没帮助，自然被特征 $\phi$ 丢弃。
- **前向模型** $f_\psi$：在学到的特征空间里预测下一帧特征 $\hat\phi_{t+1} = f(\phi(s_t), a_t)$。
- **内在奖励**：前向模型的预测误差

$$
r^i_t \;=\; \tfrac{1}{2}\big\|\hat\phi(s_{t+1}) - \phi(s_{t+1})\big\|^2
$$

逆模型的妙处在于它是**特征过滤器**：只把「智能体能影响的变化」编码进 $\phi$，不可控的噪声（那台一直放雪花的电视）进不了特征，前向模型也就不会为它产生永不衰减的预测误差。ICM 在 Mario、Doom 等环境里让智能体在没有外在奖励时也能探索得很远，甚至学会「绕远路打怪」这类为后续得分铺路的行为[2]。<Cite n={2} />

ICM 的三个部件（编码器 + 逆模型 + 前向模型）是**联合训练**的，核心逻辑就这几行：

```
# ICM 内在好奇心 伪代码 (Pathak et al. 2017)
# 每步转移 (s, a, s') 都做:
φ, φ_next = encoder(s), encoder(s')       # 编码到特征空间

# --- 逆模型:由前后特征反推动作 → 逼编码器只保留"可控"特征 ---
â = 逆模型(φ, φ_next)
loss_inv = 交叉熵(â, a)                    # (连续动作用 MSE)

# --- 前向模型:在特征空间预测下一帧特征 ---
φ̂_next = 前向模型(φ, a)
loss_fwd = ½ ‖φ̂_next - φ_next‖²

# --- 内在奖励 = 前向预测误差(预测不准 = 新奇 = 好奇)---
r_i = loss_fwd                            # 喂给 RL: r = r_外在 + β·r_i

# 联合更新 编码器 + 逆模型 + 前向模型
loss = (1-λ)·loss_inv + λ·loss_fwd
minimize(loss)
```

关键在于逆模型和前向模型**共享同一个编码器**：逆模型的梯度逼着编码器只保留「动作能影响」的特征，噪声电视进不了 $\phi$，前向模型也就不会对它一直报高误差——这就是 ICM 绕开 noisy-TV 的机制。

### 思路三：RND——简单到离谱的随机网络蒸馏

**RND(Random Network Distillation, Burda et al. 2018)**[3] 把「预测误差」思路推到极简：固定一个**随机初始化、永不更新**的目标网络 $\phi: \mathcal S \to \mathbb R^k$，再训一个**预测器** $\hat\phi_\psi$ 去拟合它的输出：

$$
\text{内在奖励}\quad r^i_t \;=\; \big\|\hat\phi_\psi(s_t) - \phi(s_t)\big\|^2
$$

预测器在见过的状态上拟合得好、误差小；在新状态上没拟合过、误差大——于是误差就成了**新状态的度量**。<Cite n={3} />固定随机目标保证了「真理」不会漂移（不像 ICM 的前向模型和特征一起学，可能协同崩塌），简单稳定。Burda et al. 2018 用纯 RND 内在奖励（完全不给环境分）在 Montezuma's Revenge 上找到了**过半房间**——这是当时**首个无需人类示范即超越人类表现**的方法之一[3]，论文还发布了大规模纯内在奖励探索的 benchmark。<Cite n={3} />

#### RND 的工程细节：为什么单靠预测误差还不够

上面那个 $r^i=\|\hat\phi_\psi(s)-\phi(s)\|^2$ 看起来「简单到离谱」，但真要让它**在 Montezuma's Revenge 这种极稀疏长程任务上 work**，光有这个公式远远不够——Burda et al. 2018 [3] 在 ar5iv 全文里给出了四个关键工程细节，它们才是 RND 攻克 Montezuma 的真正功臣。

**① 非情景内在回报（non-episodic intrinsic return）。** 这是最反直觉的一点。标准 RL 里，回合结束（智能体死亡）就把回报截断、return 归零——这叫 **episodic** return。若把 intrinsic reward 也按 episodic 处理，智能体会学到一种「**怕死**」的行为：死亡会清零它辛苦累积的内在回报，于是它宁愿停在一个「已经见过但还能反复蹭点 $r^i$」的局部区域，也不敢深入新区域去探索（因为路上可能死掉，累积的 intrinsic 分全没了）。这与上面「朴素 shaping 陷阱」里智能体在 $s_0/s_1$ 间来回蹭是**同一个病**——optimization pressure 钻了奖励设计的空子。RND 的解法：把 intrinsic return 当 **non-episodic**——死亡**不截断** intrinsic 的 bootstrap，$\gamma_I$ 继续累积。换句话说，智能体「死后的内在回报」仍算数，这样它就不怕死了。

**② 单策略 + 双价值头 $V=V_E+V_I$。** 因为 extrinsic 是 episodic（死亡截断）、intrinsic 是 non-episodic（死亡不截断），两套 return 的**性质根本不同**，不能塞进同一个价值函数。RND 用**一个策略**配**两个价值头**：$V_E$ 拟合 episodic extrinsic return、$V_I$ 拟合 non-episodic intrinsic return，合并 $V=V_E+V_I$。优势也对应相加 $A=A_E+A_I$，PPO 用这个合并优势更新那唯一的策略。两个价值头分别拟合各自的 return，但策略只有一个——这是「**返回报性质不同时，分头估价值、合头用优势**」的通用模式（后面 [SAC 篇](/tutorials/policy-gradient) 会看到最大熵 RL 里也有类似的「两项相加」结构）。原文最佳配置用 $\gamma_E=0.99$、$\gamma_I=0.999$（intrinsic 更长视，鼓励长程探索），extrinsic 系数 2、intrinsic 系数 1。<Cite n={3} />

**③ 内在奖励归一化（除以 running std）。** intrinsic reward 的量级会随训练**大幅下降**——预测器越拟合，见过的状态误差越小，$r^i$ 整体往下掉。若不归一化，后期 $r^i\to 0$，探索信号**熄灭**，智能体又变回「没动力探索」。RND 用一个 **running estimate of the standard deviation of the intrinsic returns** 来除当前 intrinsic reward，把它拉回 $O(1)$ 量级。关键：running std 是**跟踪当前量级**的移动估计（不是全历史的标准差），所以 raw reward 暴跌时 std 跟着降，归一化后信号保持稳定——预测器拟合得越好，raw $r^i$ 越小，但归一化后的探索驱动不衰减。

**④ 观测归一化（固定 normalizer）。** predictor 和 target 网络的输入观测要 whitening:$x\mapsto\mathrm{CLIP}((x-\mu)/\sigma,[-5,5])$，其中 $\mu,\sigma$ 是训练前用**随机游走采几帧**估计后**固定**的（之后不再更新）。固定是为了保证 target 网络输出不漂移——若 normalizer 在线更新，target 会变，$r^i$ 的「真理」就漂了。注意：policy 网络用另一套预处理（$x/255$ + 4 帧堆叠），predictor/target 用归一化的 1 帧——**两套网络两套预处理**。

> 💡 **一句话**：RND 的 $r^i$ 公式简单，但「**non-episodic intrinsic + 双价值头 + running std 归一化 + 固定观测 normalizer**」这四件工程外套才是它真能攻克 Montezuma 的原因。核心洞见是「**intrinsic 不能怕死**」——把探索回报从回合制里解放出来，智能体才敢深入未知区域。这也解释了为什么 R16 的 ICM/RND 都被点名为「只擅长局部探索」：没有这四件工程（尤其 non-episodic），纯预测误差驱动的好奇心确实容易卡在局部新奇区。

> ⚠️ **Noisy-TV 陷阱**：前向预测类方法（ICM 的前向模型、甚至 RND）最怕**不可控随机**。设想环境里有台一直放随机雪花噪点的电视：下一帧的雪花和这一帧完全无关、又无法从当前状态+动作预测，于是前向模型**永远预测不准**、内在好奇奖**永远拉满**，智能体就瘫在电视前当「沙发土豆」再也不走。ICM 靠逆模型特征过滤部分缓解（电视进不了 $\phi$），RND 靠固定随机目标在**已见状态**上误差会收敛来缓解。但两者都只擅长**局部探索**（走到相邻的新奇区域）；需要长程协调决策的**全局探索**（比如「先去 A 房拿钥匙、再回 B 房开门」这种跨远距离的依赖）仍超出能力——这是好奇心探索至今的开放前沿。

### 内在奖励 vs 奖励塑造：两种「加密奖励」的本质分野

对比上面「奖励塑造」小节，两者都在给稀疏奖励**加密集信号**，但方向截然相反：

| | 奖励塑造（potential-based） | 内在奖励 / 好奇心 |
|---|---|---|
| 信号来源 | **外部**：工程师用领域知识手写 $\phi(s)$ | **内部**：智能体从自身预测误差自造 |
| 改不变最优策略 | **保证不变**（telescoping） | **会变**（内在奖励改变了总目标） |
| 谁决定探索方向 | 工程师（势函数指向目标） | 智能体（哪里预测不准去哪） |
| 适用 | 知道目标在哪、给引导 | 不知道目标、要靠探索发现 |
| 失败模式 | $\phi$ 选错→学得慢但不改最优 | noisy TV→瘫在不可控随机前 |

关键区别：**shaping 是外部引导（工程师指路，保证不破坏最优策略）**,**好奇心是内部驱动（智能体按信息量自己走，可能偏离外在最优）**。实战中两者常**叠加**：用 shaping 给个大致方向、再用好奇心填充稀疏区域的长程探索。一个有理论保证但不 scalable，一个 scalable 但没策略不变性保证——各补各的短。

def rollout(intrinsic_fn, steps=200):

    visits = np.zeros(NS)
    # 预测误差法的前向模型:对每个 (状态,动作) 在线估计"下一状态",用 seen 计次数
    pred_sa = np.zeros((NS, 2))   # 对 (s,a) 预测的下一状态

> 💡 **一句话**：稀疏奖励下，ε-greedy/UCB 这类面向奖励的探索失灵；**好奇心探索**用预测误差或计数把「找新东西」变成可最大化的内在奖励，让智能体在没有环境分时也能探索得很远。ICM 用逆模型过滤不可控噪声、RND 用固定随机目标求简，但**全局长程探索**仍是开放难题。它与奖励塑造同属「加密奖励」，却是一外一内、一保策略一改策略的两条路。

## 奖励塑造：给稀疏奖励加引导（且不破坏最优策略）

上面好奇心那节解决稀疏奖励靠的是**加内在奖励**——智能体自己造探索信号。还有一条更直接的路：**工程师手动改奖励函数**，给中间步骤加「辅助奖励」引导智能体往对的方向走。这叫**奖励塑造（reward shaping）**。比如网格世界里目标在右下角，你可以给「向右/向下走」每步加 +0.1 辅助奖励，让智能体不用等到撞到目标才拿到信号。

### 朴素 shaping 的陷阱：好心办坏事

但随手加辅助奖励**危险**——它会**改变最优策略**。设想一条 3 状态链 $s_0 \to s_1 \to s_2$，$s_2$ 是目标（+1 终止），其余奖励为 0。最优策略显然是「一路向右尽快到达 $s_2$」。可如果你给「到达 $s_1$」加 +0.5 辅助奖励想「鼓励它往中间走」，智能体可能学会**在 $s_1$ 和 $s_0$ 之间来回蹭**反复拿那 0.5、永远不去 $s_2$——辅助奖励反而成了新目标。这正是 [RLHF](/tutorials/rlhf) 篇里 **reward hacking**（古德哈特定律）的雏形：优化压力一大，代理奖励就会被钻空子。

### Potential-based shaping：差分形式保策略不变

那有没有一种 shaping **既给引导、又不改变最优策略**?**Ng, Harada, Russell(1999)**[1] 给出了答案：让辅助奖励取**差分形式**

$$
F(s,s') \;=\; \gamma\,\phi(s') \;-\; \phi(s)
$$

其中 $\phi(s)$ 是任意一个**只依赖状态**的「势函数（potential）」。把 $F$ 加到每步真实奖励上，$r'_t = r_t + F(s_t,s_{t+1})$，得到**塑造后的 MDP**。神奇的是：**它的最优策略和原 MDP 完全一样**。<Cite n={1} />

**证明靠 telescoping（伸缩求和）**。把塑造后的回报展开：

$$
G'_t \;=\; \sum_{k=t}^{T-1}\gamma^{k-t}\big[r_k + \gamma\phi(s_{k+1})-\phi(s_k)\big] \;=\; G_t \;+\; \underbrace{\sum_{k=t}^{T-1}\big[\gamma^{k-t+1}\phi(s_{k+1})-\gamma^{k-t}\phi(s_k)\big]}_{\text{中间项全部抵消}}
$$

后一项是**伸缩和**：正项 $\gamma^{k-t+1}\phi(s_{k+1})$ 与下一 $k$ 的负项 $-\gamma^{k-t}\phi(s_k)$ 逐一抵消，只剩两端：

$$
G'_t \;=\; G_t \;+\; \gamma^{T-t}\phi(s_T) \;-\; \phi(s_t)
$$

对回合制任务、终止态设 $\phi(s_T)=0$（目标达成，势能归零），则 $G'_t = G_t - \phi(s_t)$。关键来了：$\phi(s_t)$ **只依赖当前状态 $s_t$，与动作 $a$ 无关**——在 $\arg\max_a Q'(s_t,a)$ 里它是个常数，被消掉。所以 $\arg\max_a Q'(s_t,a)=\arg\max_a Q(s_t,a)$，**最优策略纹丝不动**[1]。

> 💡 **直觉**：把 $\phi(s)$ 想成「海拔」，shaping 奖励 $F=\gamma\phi(s')-\phi(s)$ 就是「下坡」（海拔降）的即时反馈。但整条路的总 shaping 只由**起点终点海拔差**决定（telescoping），中间怎么绕都不影响「该往哪个方向走才能最大化真实回报」——引导给了，最优策略没动。

### 与 reward hacking 的关系：安全的 reward engineering

potential-based shaping 是**「安全」的 reward engineering**：它给了密集引导（加速学习）却**保证不改最优策略**，因此不会引入新的 hacking 风险。而 [RLHF](/tutorials/rlhf) 篇讲的 reward hacking 是「**不安全**」的——学习型奖励模型是人类偏好的不完美代理，优化压力一大就被钻空子（啰嗦、谄媚、蒙对），改变了真实想要的策略。两者的分野就在于：**shaping 项是否取 potential-based 差分形式**——是，则 telescoping 兜底、策略不变；否，则可能好心办坏事。

> ⚠️ 实践中 $\phi(s)$ 的**选择**仍是门艺术：它决定引导方向，选错了（如 $\phi$ 与到目标距离负相关）会把智能体引向错误方向——只是不会改变「最终最优策略是什么」，但会让**学习过程**变慢甚至卡在局部。常见做法是用启发式估值：到目标的距离（网格世界）、学到的价值函数近似 $V(s)$、或 subgoal 的可达性。Wiewiora（2003）把 potential 扩展到依赖动作 $\phi(s,a)$，telescoping 推广到 Q 值，等价于给 Q 表一个「先验偏置」初始值 $Q_0(s,a)=\phi(s,a)$。

> 💡 一句话：**potential-based shaping = 给奖励函数加一个「状态势能差」的引导项，靠 telescoping 保证最优策略不变**。它是 reward engineering 里少数有理论保证的安全手段，也是理解 RLHF reward hacking「为何危险、如何安全」的对照基石。

## 信用分配：奖励该归功给谁

前面所有机制——折扣回报、Q 值、TD 更新、奖励塑造——归根结底都在解同一个根本难题：**信用分配问题（credit assignment problem）**。这一节把它单独拎出来讲透，因为它贯穿 RL 的每一篇。

### 问题的两个维度：结构性 vs 时序性

Minsky(1961)[4] 在 *Steps Toward Artificial Intelligence* 里最早提出信用分配问题，原指**结构性（structural）**：一个由很多部件组成的系统做对了一件事，该给哪个部件记功？神经网络里就是「哪些连接权重该为正确输出被加强」。这对 RL 同样存在——联合动作、多智能体、并行选项里，「这一步的成功」该归功于哪个子动作/哪个智能体。<Cite n={4} />

但 RL 还多一层 Minsky 没特别强调的维度：**时序性（temporal）**。Sutton(1984)[5] 在博士论文 *Temporal Credit Assignment in Reinforcement Learning* 里把这层挑明——下棋赢了，奖励在终局才出现，可胜负是**几十步共同**决定的，**该给哪一步记功？** 时序信用分配要回答：一个延迟到达的奖励，怎么分配回沿途各步动作/状态。<Cite n={5} />

> 💡 **一句话区分**:**结构性**问「**哪个**部件/动作该被归因」（空间维度）；**时序性**问「**哪一步**动作该被归因」（时间维度）。RL 里两者都棘手，但时序性是 RL 独有的、且更普遍——因为 RL 的奖励几乎总是延迟的。

### 时序信用分配：折扣与 return 是天然的传播机制

最朴素的时序分配靠**折扣回报** $G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k+1}$：离奖励越近的动作，分到的折扣权重越大（$\gamma^0=1$ 紧邻，$\gamma^k$ 越远越小）。$Q$ 值 $Q(s,a)=\mathbb E[G_t\mid s,a]$ 就是把这个传播机制固化进状态-动作价值。**折扣因子 $\gamma$ 本质上是时序信用分配的衰减系数**——它隐含了一个先验：功劳随时间距离指数衰减。

但朴素 return 有两个毛病：**① 要等整条轨迹结束（MC）才能算**，延迟奖励要等一整回合；**② 方差大**（长回报是很多随机步的叠加）。这正是 TD 学习出场的动机。

### 解法谱系：从单步 TD 到资格迹到 GAE

TD 用 **bootstrapping（自举）** 解决「等不起」的问题：不等回合结束，用「下一步的估计值」当当前的目标，$V(s_t)\leftarrow V(s_t)+\alpha[r_{t+1}+\gamma V(s_{t+1})-V(s_t)]$。但单步 TD（0） 走向了另一个极端——**奖励一次只传一步**：终局的 $+1$ 要经过 $O(1/(1-\gamma))$ 回合才能慢传到起点。这就引出了在「单步（快但浅）」与「整条回报（深但慢）」之间插值的谱系：

| 方法 | 信用分配范围 | 偏差 | 方差 | 更新时机 |
|---|---|---|---|---|
| 单步 TD(0) | 紧邻一步 | 大（bootstrap） | 小 | 每步 |
| n-step TD | 后 $n$ 步 | 中 | 中 | 延迟 $n$ 步 |
| TD（λ） 资格迹 | 整条轨迹（按 $\lambda$ 衰减） | 可调 | 可调 | 每步（在线） |
| 蒙特卡洛 MC | 整条轨迹（等权） | 0 | 大 | 回合结束 |

**资格迹（eligibility traces）**[6] 是这个谱系的枢纽：给每个近期到访的状态留一道**随时间衰减的痕迹** $E_t(s)$，TD 误差 $\delta_t$ 一来就**按痕迹强度一次性回灌**给沿途所有状态——<Cite n={6} />

$$
E_t(s) = \gamma\lambda\, E_{t-1}(s) + \mathbb 1[s=s_t], \qquad V(s) \leftarrow V(s) + \alpha\,\delta_t\, E_t(s)
$$

$\lambda=0$ 退化成单步 TD（只有 $s_t$ 有痕迹）；$\lambda=1$ 退化成 MC（所有到访状态等权留痕）。**$\lambda$ 就是时序信用分配的「视野」旋钮**：越大，功劳传得越远越均匀；越小，越集中在近邻。同一根 $\lambda$ 旋钮在策略梯度里以 **GAE（广义优势估计，Schulman et al.， 2016）** 的面貌重现——GAE 用 $(\gamma\lambda)^l$ 加权 n-step 优势，把回报的信用按时间衰减分配给各步动作，是现代 PPO/Actor-Critic 的事实标准（详见 [策略梯度篇 GAE 小节](/tutorials/policy-gradient) 与 [时序差分篇资格迹小节](/tutorials/temporal-difference)）。

### 结构性信用分配：多动作/多智能体里谁该被归因

时序信用分配解决了「哪一步」，结构性信用分配解决「哪一个」。当一步决策由多个子动作共同构成（联合动作 $\mathbf a=(a_1,\dots,a_N)$），或一个选项内部跑了很多原语动作，终局奖励到了，**哪个子动作该被加强**？经典思路：

- **差分信用分配**：用**反事实（counterfactual）**——「若这个子动作换成别的,回报会差多少?」COMA（反事实基线,见 [多智能体篇](/tutorials/multi-agent-rl)）与 advantage-weighted 方法（AWAC/AWR,见 [离线 RL 篇](/tutorials/offline-rl)）都用这个思想;
- **价值分解**：把总回报 $Q_{\text{tot}}$ 分解成各子单元的 $Q_i$ 之和（VDN）或单调组合（QMIX）,让每个子单元拿到自己的那份信用（见 [多智能体篇](/tutorials/multi-agent-rl)）;
- **选项层归因**：HRL 里高层选项拿到终局奖励后,再由 option-critic 的梯度定理把它分配回选项内部策略 $\pi_o$ 与终止函数 $\beta_o$（见 [分层 RL 篇](/tutorials/hierarchical-rl)）.

结构性与时序性 credit assignment 常同时出现——多智能体长回合任务既要「哪步」又要「哪个智能体」——这是 RL 最难的场景之一，也是 HRL + MARL 交叉处的前沿。

> 📌 **信用分配是 RL 的「元难题」**：探索-利用决定「怎么试」，信用分配决定「试完怎么归因」。折扣/return/Q 值给了最朴素的时序分配（指数衰减），TD/资格迹/GAE 给了偏差-方差可调的解法谱系，反事实/价值分解给了结构性的解法。凡是「奖励延迟或来源多个动作」的任务，都在解信用分配——这贯穿价值法、策略法、HRL、MARL、RLHF 每一篇，理解它就理解了 RL 为何比监督学习难。

| | 监督学习 | 强化学习 |
|---|---|---|
| 学习信号 | 每个样本的**正确标签** | 稀疏、延迟的**奖励** |
| 数据来源 | 固定数据集 | 智能体**自己与环境交互**产生 |
| 目标 | 拟合标签 | 最大化长期累积奖励 |
| 典型难点 | 过拟合 | 探索 vs 利用、奖励稀疏、**信用分配** |

## 控制即推断：RL 的概率统一视角

前面几节把 RL 讲成「最大化累积奖励」的优化问题。Levine (2018)[8] 给出另一个等价视角：**控制就是概率推断**——把「智能体最优地行动」当成一个**观测事实**来反推动作。这个视角不改变任何算法的答案，却把奖励、策略、价值、探索统一进一个概率图模型，并直接解释了为什么 [SAC](/tutorials/continuous-control) 的最大熵目标和 [DIAYN](/tutorials/hierarchical-rl) 的互信息目标长那样。<Cite n={8} />

### 最优性变量：把奖励变成对数似然

引入一个二值**最优性变量（optimal variable）** $O_t\in\{0,1\}$，在每个时刻 $t$ 问「这一步是不是最优的」。把它和状态、动作用一条边连起来：

$$
\log P(O_t=1\mid s_t,a_t) \;=\; r(s_t,a_t) \quad\Longleftrightarrow\quad P(O_t=1\mid s_t,a_t)\;\propto\;\exp(r(s_t,a_t))
$$

即**奖励就是对数最优似然**——奖励越高，「这一步最优」的概率越大。控制问题「最大化 $\sum_t r_t$」被改写成推断问题「给定所有 $O_t=1$（每步都最优），动作序列的后验 $p(a_{0:T}\mid O_{1:T}=1, s_{0:T})$ 是什么？」。

### soft Bellman：后验的递归 = 配分函数

对动作后验做变分推断（策略 $\pi(a\mid s)$ 当变分分布，近似「最优动作的后验」），消息传递给出**软贝尔曼方程**——和 [SAC](/tutorials/continuous-control) 那个最大熵 soft Bellman 是同一个：<Cite n={8} />

$$
V(s) \;=\; \alpha\,\log\int_a \exp\!\Big(\tfrac{1}{\alpha}Q(s,a)\Big)\,da \;=\; \alpha\,\text{logsumexp}_a\!\big(Q(s,a)/\alpha\big)
$$

$$
\pi(a\mid s) \;=\; \exp\!\Big(\tfrac{Q(s,a)-V(s)}{\alpha}\Big) \;=\; \mathrm{softmax}_a\!\big(Q(s,a)/\alpha\big)
$$

这里 $\alpha$ 是温度：它本是变分推断里熵正则的权重，扮演「探索-利用恒温器」。**关键观察**：$\text{logsumexp}\ge\max$，故 soft $V$ **大于等于**硬 $V=\max_a Q$——多出来的部分是「多个好动作都贡献概率质量」的**乐观增量**。$\alpha\to0$ 时 softmax 变尖、soft $V\to\max Q$（退化为标准硬 RL）；$\alpha$ 大时 softmax 变平、soft $V$ 远超 $\max Q$（策略趋向均匀、充分探索）。

### 三个算法，一个推断框架

变分推断的标准套路是**期望最大化（EM）**：E 步算后验，M 步让变分分布贴近后验。Levine 2018 [8] 指出主流 RL 算法恰好对应 EM 的两步：

| 算法 | 推断框架里的角色 | 做的事 |
|---|---|---|
| **soft Q-learning**（E 步） | 后验推断 | 反向传消息、算 soft $Q$/$V$（Bellman backup = 消息传递） |
| **策略梯度 / REINFORCE** | 最小化 $\mathrm{KL}(\pi\|p^*)$ | 让变分策略 $\pi$ 贴近「最优动作的后验」$p^*(a\mid s)\propto\exp(Q/\alpha)$ |
| **actor-critic**（EM 交替） | E + M 交替 | critic 算 soft $Q$（E 步），actor 更新 $\pi$ 贴近 $Q$（M 步） |

策略梯度的「最大似然 + 优势加权」、Q-learning 的「Bellman 残差最小化」、actor-critic 的「评估 + 改进」交替——三个看似不同的范式，在这个框架下都是**同一个变分推断问题的不同求解器**。

### 为何这个视角有用

它不只是好看，而是催生了一族算法：

- **[SAC](/tutorials/continuous-control)**：最大熵 RL = 确定性动力学下的精确推断,$\alpha$ 自动调温 = 对偶变量.本篇前面讲的 soft Bellman 就是这里的方程.
- **[DIAYN](/tutorials/hierarchical-rl)**：把「技能可区分」写成互信息 $I(S;Z)$,本质是「用推断框架学技能」——技能 $z$ 是隐变量,状态 $s$ 是观测,最大化互信息 = 变分推断最大化 ELBO.
- **[RLHF/DPO](/tutorials/rlhf)**：奖励 $\,r=\beta\log(\pi/\pi_{\text{ref}})+\beta\log Z$ 的闭式解,正是「把 KL 约束的最优策略反解成奖励」——和这里「最优性变量 + 变分推断」是同一套对偶.
- **概率规划与部分可观测**：把控制写成概率图模型后,可直接套用变分消息传递、粒子滤波等推断工具,处理 POMDP、多智能体信念推断等硬场景.

> 📌 **一句话视角**：标准 RL 把控制看成「在 MDP 上最大化奖励」；控制即推断把同一个问题看成「给定智能体最优，反推动作后验」——奖励是对数最优似然，soft Bellman 是后验的配分函数，策略是后验本身，$\alpha$ 是熵正则权重。它不改变答案，却让 SAC 的最大熵、DIAYN 的互信息、DPO 的闭式奖励在同一个概率图模型下各就各位——这是 RL 理论的「统一场论」。

## 课程学习：从易到难的教学法

前面三节给了「给稀疏奖励加引导」的三条腿里的两条——[奖励塑造](#奖励塑造给稀疏奖励加引导且不破坏最优策略)改**奖励信号**、[好奇心探索](#内在奖励与好奇心探索)加**内在奖励**。还有第三条腿：不改奖励，改**任务本身的出现顺序**。这就是**课程学习（curriculum learning）**——让智能体先学简单的变体，再逐步过渡到难的目标，像学生从易到难做题一样。它和奖励塑造、好奇心一样，都是治稀疏奖励下「随机起态很难碰到奖励、V 值迟迟学不动」的样本效率病。

### Bengio 2009：易→难顺序为何有效

课程学习的现代形式化来自 [Bengio et al.， 2009][7] 的 ICML 论文 *Curriculum Learning*。核心想法：训练样本不一次性全给，而按**难度递增**的顺序呈现。直觉是「先在简单变体上把低层特征/基本动作学好，再让高层能力在难的变体上精修」，从动物训练的 shaping 与人类教育里得到启发，溯源 Elman 1993「starting small」——先训短句子再训长句子的神经网络学得更好。Bengio 把它形式化成三要素：<Cite n={7} />

1. **定义难度（difficulty）**：谁来判一个样本「难不难」？可以靠人标（短句=易）、靠外部启发式（图像复杂度），或靠另一个模型（预测准确率高的=易）。
2. **节奏（pacing）**：难度是 steady 上升还是分阶段跳？按确定性时间表，还是按概率分布？要不要加多样性约束防止过表示相似的易例？
3. **推进准则（advancement）**：何时进入下一难度？固定步数（「前一半迭代用易例，后一半用全部」），还是 self-paced（按当前模型性能推进——学会了才加难）？

Bengio 把课程学习视为一种**正则化**——它隐含一个先验「易变体上学到的表征能泛化到难变体」，本质是一种**迁移学习**（易→难是源域→目标域）。值得注意的是，**anti-curriculum**（反过来先学最难的）在某些域反而更好——并非「从易到难」永远占优，关键是**难度顺序要与任务的归纳结构匹配**。

### RL 语境：自动课程生成

监督学习里课程改的是「样本采样分布」，RL 里课程改的是「**起态分布 / 目标分布 / 任务参数分布**」。RL 的稀疏奖励难题尤其需要课程：智能体从随机起态出发，长链任务里几乎碰不到终端奖励，V 值bootstrap 信号传不回来——上一节信用分配讲过，TD（0） 要 $O(1/(1-\gamma))$ 回合才把奖励慢传到起点。如果起态集中在近终端区，奖励立刻可见，V 值快速收敛后再后退起态，bootstrap 信号就能沿已收敛的近终端区一路传到起点。

这就是 RL 里**自动课程生成（automatic curriculum generation）**的动机。三大范式：

- **Teacher-Student**：一个 teacher 网络负责「给学生挑它现在学得动、又有学习信号的任务」,student 学策略;teacher 的目标常是 student 的学习进度（价值损失下降量 / 成功率变化）,挑「刚好在学生能力边界」的任务——太难学不动（没进度）、太易已会（没进度）,边界上进步最快.
- **Self-play**：对手即课程.AlphaGo/AlphaZero 的 self-play（[model-based-rl 篇](/tutorials/model-based-rl)已讲）让策略始终对抗与自己同水平的对手,「能赢当前对手」就是难度恰好的任务;[多智能体篇](/tutorials/multi-agent-rl)的自博弈与 PSRO 把对手池扩展成历史策略族群,autocurriculum 在捉迷藏等域涌现复杂行为.
- **Goal relabeling(HER)**：不主动设计课程,而是把失败 episode 的 goal 重标为**实际达到的 state**——失败变成功、implicit curriculum. hindsight experience replay（Andrychowicz et al., 2017）在 [DQN 篇](/tutorials/dqn)已详述,是机器人操作任务的事实标准.

进阶的还有**环境设计（environment design）**：POET（开放进化环境）、PAIRED（对抗生成 minimax regret 环境）、ALP-GMM（绝对学习进度采样）、PLR（基于 regret 优先采样关卡）——核心都是「让环境难度自适应贴在智能体能力边界」，把课程从「人为分阶段」升级为「自动寻边界」。

### 三条腿对照：改奖励、加内在奖励、改任务顺序

把治稀疏奖励的三条腿放一起对照：

| 手段 | 改什么 | 代表方法 | 何时合适 |
|---|---|---|---|
| 奖励 shaping | 奖励信号（加势能差分） | potential-based $F=\gamma\phi(s')-\phi(s)$ | 有领域知识能设计好势能 $\phi$ |
| 内在奖励 | 奖励（加探索 bonus） | ICM/RND/count-based | 奖励极稀疏、需主动探索 novelty |
| **课程学习** | **任务分布（起态/目标）** | **teacher-student / self-play / HER** | **有任务参数可调、能定义难度** |

三者不互斥，常组合：AlphaGo 同时用 self-play（课程）+ 内在探索（树搜索）；机器人操作常 HER（课程）+ 好奇心（探索）。**核心都是「让奖励信号更快被智能体看见」——shaping 把奖励加密进每步，curiosity 把奖励加到状态本身，curriculum 把智能体搬到离奖励更近的起点。**

- **uniform**：每回合从 s0..s13 均匀随机起态;
- **curriculum**：分 14 阶段,每阶段 1/14 的回合数,起态从 s13（紧邻终端）逐步后退到 s0.

## 部分可观测：当状态看不全（POMDP）

前面所有内容都建立在一个假设上：**智能体能直接观测到真实状态 $s$**（棋盘布局、迷宫位置、Atari 像素帧）。这套「状态→动作→奖励→新状态」的框架叫**马尔可夫决策过程（MDP）**，其核心是**马尔可夫性**——下一步只取决于当前状态，与历史无关。但现实里，智能体常常**看不全真实状态**：

- **扑克牌**：你只看到自己的手牌,对手的手牌是隐藏的——真实状态（全部手牌）观测不到.
- **自动驾驶**：雾天摄像头有噪声、激光雷达有盲区,「真实世界状态」永远测不准.
- **医疗诊断**：医生只看到症状（观测）,病人的真实病理（状态）要推断.
- **机器人定位**：传感器有噪声,机器人在迷宫里不知道自己**精确**在哪（这就是经典的 *gridworld localization*）.

这时状态 $s$ 不再可直接观测，智能体只能拿到一个**观测 $o$**（observation），它是真实状态 $s$ 的带噪投影。这叫**部分可观测马尔可夫决策过程（Partially Observable MDP, POMDP）**[9]。<Cite n={9} />

### POMDP 的形式：多了一个观测函数

MDP 是 $(\mathcal S, \mathcal A, P, r, \gamma)$ 五元组（状态、动作、转移、奖励、折扣）。<Cite n={9} />POMDP 在此基础上**多两个东西**：

$$\text{POMDP} = (\mathcal S, \mathcal A, \mathcal O, P, Z, r, \gamma)$$

- $\mathcal O$：**观测空间**（智能体能看到的信号，如传感器读数、像素帧）；
- $Z(o\mid s',a)$：**观测函数**——在真实状态为 $s'$、刚执行了动作 $a$ 的条件下，观测到 $o$ 的概率。

关键区别：**MDP 里 $\mathcal O = \mathcal S$、$Z(o\mid s',a)=\mathbb 1[o=s']$（观测即状态，确定无误）；POMDP 里观测是状态的带噪投影，同一状态可能产生不同观测，同一观测也可能来自不同状态**。MDP 是 POMDP 的特例（观测无噪声）。

### 信念状态：把历史压缩成一个分布

既然看不到真实状态 $s$，智能体只能基于**历史** $h_t=(o_0,a_0,o_1,\dots,a_{t-1},o_t)$ 推断「我大概在哪个状态」。但历史越攒越长，直接拿来当策略输入不现实。幸好有个优雅的结论：**历史的**充分统计量**是一个状态分布 $b_t(s)=P(s_t=s\mid h_t)$，叫**信念状态（belief state）****——它记录「我认为真实状态是 $s$ 的概率」，且只需递推更新，不必存整条历史。<Cite n={9} />

**信念更新公式**（Bayes 滤波）：执行动作 $a$、观测到 $o$ 后，

$$b'(s') = \eta\, Z(o\mid s',a)\sum_{s\in\mathcal S} P(s'\mid s,a)\, b(s)$$

读法：新信念 $b'(s')$ = （归一化常数 $\eta$） × （在这个新状态下观测到 $o$ 的似然 $Z$） × （按转移模型从旧信念推一步的前瞻 $\sum_s P(s'|s,a)b(s)$）。这正是贝叶斯滤波——用观测的似然 $Z$ 修正转移模型的预测。

**信念状态保留了马尔可夫性**：虽然真实状态 $s$ 看不到，但信念 $b$ 本身是马尔可夫的——$b'$ 只依赖 $(b,a,o)$，不依赖更早的历史。于是 POMDP 被重构成一个**信念 MDP**：状态是信念 $b$、动作是 $a$、转移是信念更新 $\tau$、奖励是 $r(b,a)=\sum_s b(s)\,r(s,a)$。**所有 MDP 的算法（Q-learning、策略梯度……）都能搬到信念空间上**，只是状态从 $s$ 换成了分布 $b$。

print()
print("=== 信念的马尔可夫性: b' 只依赖 (b, o), 不依赖历史 ===")
b1 = {'TL': 0.9, 'TR': 0.1}  # 路径 A 到达 0.9
b2 = {'TL': 0.9, 'TR': 0.1}  # 路径 B 到达 0.9
r1 = belief_update(b1, 'HL')
r2 = belief_update(b2, 'HL')
print(f"路径 A 信念 (0.9,0.1) + 听 HL -> ({r1['TL']:.4f}, {r1['TR']:.4f})")
print(f"路径 B 信念 (0.9,0.1) + 听 HL -> ({r2['TL']:.4f}, {r2['TR']:.4f})")
print("两条历史不同, 只要信念相同, 更新后完全一致 -> 信念是历史的充分统计量 (马尔可夫)")
`} title="POMDP 信念更新: Tiger 问题, 听三次定位老虎" />

**看图（数）要点**：

- **信念单调收敛**：初始 0.5/0.5（完全不知道）,听一次 HL→0.85/0.15,两次→0.97/0.03,三次→0.995/0.005.每次一致的观测都把信念往一个方向推,矛盾的观测会拉回——这就是贝叶斯滤波的「证据积累」.
- **信念驱动决策**：听三次后 OPEN-R 期望 +9.40 vs OPEN-L 期望 -99.40,差距悬殊——**信念把不确定性折算进期望收益**,让智能体在「该听还是该开门」之间理性权衡（信息价值 vs 行动收益）.继续听代价 -1 但信念已 0.995,再听收益递减——这就是「何时停止探索」的 POMDP 核心难题.
- **信念的马尔可夫性**：两条不同历史只要到达同一信念,未来完全一样——所以信念是历史的充分统计量,POMDP 可重构成「信念 MDP」用全套 MDP 算法求解.

### 深度 RL 怎么应对部分可观测：把历史喂给网络

表格 POMDP 把信念 $b$ 显式算出来（如上），但高维观测（像素）下显式信念更新不可行。深度 RL 的做法更直接：**用循环网络（LSTM/GRU/Transformer）把历史 $h_t$ 隐式压缩成一个隐状态**，让策略 $\pi(a_t\mid h_t)$ 依赖隐状态而非单帧观测。

- **DRQN(Deep Recurrent Q-Network, Hausknecht et al. 2015)**：DQN 接 LSTM,处理 Atari 帧缺失（frame-skipping + 部分观测）.
- **R2D2(Recurrent Replay Distributed DQN, Kapturowski et al. 2019)**：LSTM + 分布式 actor + recurrent experience replay,Atari 上的里程碑.
- **Dreamer / RSSM**（[基于模型的 RL 篇](/tutorials/model-based-rl)讲过）：显式学一个潜状态空间模型，在潜空间里 belief 推断 + 想象训练。

> 💡 **一句话**：MDP 假设「看得全状态」，POMDP 承认「只能看带噪观测 $o$」。关键工具是**信念状态 $b(s)$=历史的后验分布**，它把任意长的历史压成一个马尔可夫的分布，让 POMDP 重构成信念 MDP；深度 RL 则用循环网络隐式做这件事。扑克、自动驾驶、医疗诊断这些「真实状态藏起来」的场景，POMDP 是必经之路。

## ❓ 常见问题 FAQ

**Q：Q-learning 和深度强化学习（DQN）什么关系？**
Q-learning 用一张表存 $Q(s,a)$，状态一多就存不下（围棋有 $10^{170}$ 种局面）。**DQN** 用一个神经网络去**近似** $Q(s,a)$，输入状态、输出各动作的 Q 值——这就是 2015 年 DeepMind 用来玩 Atari 的方法。表格版是理解一切的基础；[DQN:用神经网络逼近 Q 表](/tutorials/dqn) 会把经验回放、目标网络讲透。

**Q：策略梯度（Policy Gradient）又是什么？**
Q-learning 是「学价值、再导出策略」（value-based）。策略梯度**直接**优化策略 $\pi_\theta(a\mid s)$ 的参数（policy-based），用梯度上升最大化期望回报——上面「🎯 策略梯度」标签就是最小的 REINFORCE 例子。下一篇 [策略梯度:直接学策略](/tutorials/policy-gradient) 会把 REINFORCE、Actor-Critic、PPO 讲透；PPO 及 RLHF 都属于这一类。

**Q：Q-learning 和 SARSA 到底差在哪？**
只差更新目标里那一项：Q-learning 用 $\max_{a'}Q(s',a')$（假设下一步走最优，**off-policy**），SARSA 用实际走的 $Q(s',a')$（评估自己带探索的真实策略，**on-policy**）。后果是 SARSA 更**保守**——在悬崖/陷阱旁会主动选离危险更远的路，而 Q-learning 敢贴着最优边界走。上面两个标签跑出的路径能看出这个差别。

**Q：on-policy 和 off-policy 到底是什么区别？**
一句话：看**行为策略（拿去跑数据的）和目标策略（想学好的）是不是同一个**——同则 on-policy(SARSA、PPO)，异则 off-policy(Q-learning、DQN)。完整对比表、后果与 offline RL 的关系见上文[《On-policy 与 off-policy:一条主线》](#on-policy-与-off-policy一条主线)。

**Q：model-free 和 model-based 又是另一种分类？**
是的，这是与 on/off-policy **正交的另一根轴**——看智能体**是否学一个「环境模型」**（给定状态、动作，预测下一状态与奖励）：

- **model-free（无模型）**：不预测环境,纯靠试错直接学价值或策略.本教程讲的 Q-learning、SARSA、DQN、策略梯度**全属此类**——简单稳健,但样本效率低（要海量交互）.
- **model-based（有模型）**：先学一个环境模型,再用它**在「脑内」模拟、规划**,不必事事真去试.样本效率可高出几个量级,代价是模型学不准时误差会累积、甚至把规划带偏.

经典的 model-based 系统：**AlphaZero / MuZero**（用蒙特卡洛树搜索在模型里向前推演）、**Dreamer**（学一个「世界模型」在想象中训练）。二者也常**混合**——Dyna 架构用学到的模型生成合成经验，喂给 model-free 的更新。**样本贵**（机器人、自动驾驶）时倾向 model-based；**数据便宜、环境太复杂难建模**时倾向 model-free。

**Q：AlphaZero 靠「自我博弈」变强，为什么这么有效？**
**自我博弈（self-play）** 让智能体**和稍旧版本的自己对弈**来学习。它的魔力在于制造了一条**自动课程（autocurriculum）**：对手强度随自己水平**同步上涨**，永远给出「不太难也不太易」的恰当挑战——不像固定对手那样一旦学会就再无长进。

三个关键点让它转起来：

- **无需人类数据、突破人类天花板**：AlphaGo 还要先学人类棋谱,AlphaZero **纯从零自我对弈**,反而下出人类想不到的新棋.
- **搜索当「策略提升算子」**：每步用 MCTS 基于当前网络向前推演,搜出的走法**比网络原始直觉更强**;再训练网络去逼近 MCTS 的结果,网络变强→下轮 MCTS 更强,形成**自我提升的循环**（和 [DQN](/tutorials/dqn) 一样也用了经验回放缓冲区）.
- **数据无限**：自我对弈能源源不断造训练数据,不靠标注.

> ⚠️ 但自我博弈至今**难迁移到两人零和博弈之外**。大模型没有天然的「对称对手」——怎么让一个 LLM 自动出题、另一个 LLM 学着解、且难度自动爬升，是当前开放前沿；所以 [RLHF](/tutorials/rlhf) 仍依赖人类偏好而非纯自我博弈。

**Q：折扣因子 $\gamma$ 怎么选？**
$\gamma$ 接近 1 表示「有远见」（重视长期），接近 0 表示「短视」（只顾眼前）。一个好用的直觉是**有效视界（effective horizon）** $\approx \dfrac{1}{1-\gamma}$——它约等于智能体「能看多远」的步数：

| $\gamma$ | $1/(1-\gamma)$ | 大致含义 |
|---|---|---|
| 0.5 | ~2 步 | 极度短视，只顾眼前一两步 |
| 0.9 | ~10 步 | 常用起点 |
| 0.99 | ~100 步 | 有远见，适合长回合任务 |

太大（接近 1）会让回报方差大、训练不稳且慢；太小则目光短浅、错过延迟奖励。常用 0.9~0.99；回合越长、奖励越靠后，就该把 $\gamma$ 调得越高。

## ✏️ 动手作业

1. **改陷阱位置**：把代码里 `PIT` 换成别的格子，重新训练，看学到的路径怎么绕开它。
2. **调折扣**：把 `gamma` 从 0.9 改到 0.5，观察智能体是否变得「短视」（更愿意走近路即使风险高）。
3. **关掉探索**：把 `eps` 固定成 0（纯贪心），看它是否会卡在次优路径里出不来——体会探索的必要性。
4. **加大网格**：把 `N` 改成 6，目标放右下角，看需要多少回合才学会。
5. **玩好奇心**：在内在奖励演示里把出发点改成 0、把 `steps` 加到 500，看基于计数和预测误差两种策略的覆盖状态数谁先到 10；思考为什么纯 greedy 会卡在局部（noisy-TV 的影子）。
6. **改课程节奏**：在课程学习演示里把 `curriculum_start` 的阶段数从 `N-1=14` 改成 `2`（只分「近终端 / 远终端」两段），看 V(s0) 100 回合时是变好还是变坏；再把 `n_eps` 调到 50，看 curriculum 在极少回合下相对 uniform 的优势是否更明显。

## 🔭 讨论与展望

RL 是「没有标准答案、只有奖励」的学习范式——它最接近「智能体在环境里自己摸索」的直觉，也因此最难训。十年里 RL 从 Atari 走到 AlphaGo 再走到 RLHF 对齐大模型，但通用 RL 仍未解决。

### ⚠️ 当前方法的局限

- **样本效率低，要千万步交互才学会一个任务**.RL 靠试错，往往要千万步交互才学会一个任务；相比之下人类几次示范就能上手。根本原因：奖励稀疏（整局一个反馈）、信噪比低，大量采样花在「确认某个动作不好」上。
- **奖励设计是黑艺术，模型只会优化你给的奖励**.RL 只会优化你给的奖励，不会做你想让它做的事——reward hacking、规格化错误（specification gaming）层出不穷（「让机器人不摔倒」→ 它学会一直躺着）。潜在型奖励塑造保最优策略，但设计势函数本身仍需领域知识。
- **探索仍是开放问题，没有一招通杀的解**。ε-贪心盲目、UCB 在表格里有效但高维下计数失效、好奇心（ICM/RND）会被 noisy-TV 拖住；hard-exploration 任务（Montezuma's Revenge）至今没有一招通杀的解。
- **信用分配难，长时序稀疏奖励下尤其 noisy**。延迟到达的奖励要分配回沿途各步，TD(λ)/GAE 在偏差-方差间折中，但长时序、稀疏奖励下仍 noisy；结构性信用分配（多部件系统里该记谁的功）更远未解决。
- **泛化差，换环境就崩**.RL 在一个环境训出的策略，换个稍微不同的环境就崩；迁移、多任务、元学习都有进展但远不如监督学习的泛化稳健。
- **仿真到现实有 gap，真实世界跑不起千万步**。游戏/仿真器里能随便跑千万步，真实世界（机器人、自动驾驶）不行；sim-to-real 的 domain randomization 等技巧仍是部分解。

### 🚀 前沿进展

1. **离线 / 离线到在线 RL**。从固定数据集学（CQL、IQL、Decision Transformer），不再在线试错——把 RL 拉到接近监督学习的数据效率，代价是受数据集分布约束。这是 RL 走向真实部署的关键。
2. **RLHF / RLAIF 对齐大模型**。把「人类/模型偏好」转成奖励，用 PPO/DPO 训练——RL 从「打游戏」变成「对齐千亿参数模型」，是过去两年最大的应用跃迁。详见 [RLHF 教程](/tutorials/rlhf).
3. **基于模型的 RL + 世界模型**。学一个环境模型在里面规划（Dyna、Dreamer、世界模型），减少真实交互；最近 Sora 类视频生成模型也被视作「学到的世界模型」的候选。
4. **目标条件 + 课程自动生成**.HER（把失败轨迹的「达成状态」当目标）、teacher-student 课程、self-play 自动造课程——让 RL 不再依赖人工设计的任务序列。
5. **大模型当策略 / 当世界模型**。用 LLM 做策略的先验（在它能描述的任务上 Few-shot 学会）、或用 LLM 当可推演的世界模型——把语言模型的常识注入 RL，绕过纯从零试错。

### 🤔 反思

1. **RL 是「智能体」最完整的骨架吗？** 它有一个其他范式没有的性质：**显式建模「在环境里行动、获得反馈、改进策略」的闭环**——这最接近「智能体」的定义。Sutton 把 RL 视作「AI 的第一性原理」并非偶然：监督学习是开环的（给标签学映射），而智能本质上是有目标的、与环境交互的。这套闭环，真的是智能不可替代的那一面吗？

2. **奖励从哪来？** 这是纯 RL 走向 AGI 的最大障碍。游戏有明确分数，真实世界没有；人类偏好能训出对齐的模型，但「对齐」≠「智能」。奖励塑造、内在奖励、RLHF 都是在绕这个问题——但「什么是真正该优化的目标」，我们有原理性答案吗？

3. **AGI 是 RL 独霸，还是融合图景？** 更可能的路径是三件套合体：大模型（监督/自监督学的世界知识）+ RL（在环境里试错学的策略与目标）+ 检索/工具（接进真实世界）。RL 那块「目标导向的闭环学习」不可替代——这也是为什么这套教程用了 13 篇讲 RL：它不只是又一个算法，而是「智能体怎么学」这件事最完整的骨架。但骨架之上，血肉是谁的？

> 🎯 **一句话**：RL 最接近「智能体在环境里摸索」的直觉，也最难训——样本效率、奖励设计、探索、泛化、sim-to-real 五道坎都没完全过；但它显式建模「目标导向的闭环」，这恰是智能不可替代的那一面。

## 📌 小结

| 概念 | 含义 |
|---|---|
| 状态 / 动作 / 奖励 | RL 三要素：处境、选择、反馈 |
| 折扣回报 $G_t$ | $\sum_k \gamma^k r_{t+k}$，长期累积奖励 |
| 策略 $\pi(a\mid s)$ | 行为准则，学习的最终产物 |
| 价值 $Q(s,a)$ | 长期回报的估计，贝尔曼方程迭代逼近 |
| 探索 vs 利用 | ε-贪心（盲目随机）/ UCB（定向上界）/ Thompson（后验采样）平衡「试新」与「用旧」 |
| 内在奖励 / 好奇心 | 稀疏奖励下用预测误差（ICM）或随机网络蒸馏（RND）自造探索信号；与奖励塑造一内一外 |
| 信用分配 | 延迟奖励怎么分配回各步动作/状态：折扣/return 是天然指数衰减、TD(λ)/GAE 调偏差-方差、反事实调结构性 |
| 控制即推断 | 把「最大化奖励」改写成概率推断：引入最优性变量 $O_t$，$\log P(O_t=1\mid s,a)=r(s,a)$;soft Bellman $V=\alpha\,\text{logsumexp}(Q/\alpha)$ 是后验配分函数，统一 SAC/DIAYN/DPO 的理论根基 |
| 课程学习 | 按易→难顺序呈现任务（改起态/目标分布），让 bootstrap 链路先就位；teacher-student / self-play / HER 三范式 |
| 部分可观测（POMDP） | 状态看不全，只有带噪观测 $o$；信念状态 $b(s)=P(s\mid\text{历史})$ 是历史的充分统计量，Bayes 滤波递推 $b'(s')=\eta\,Z(o\mid s',a)\sum_s P(s'\mid s,a)b(s)$；信念保马尔可夫性→POMDP 重构成信念 MDP；深度 RL 用 LSTM/GRU 隐式做 |

> 🎯 一句话记住：**强化学习 = 没有标准答案，只有奖励；靠试错学出「在什么状态该做什么」的策略。** 下一篇换个视角：如果环境规则**已知**，就能用[动态规划](/tutorials/dynamic-programming)不试错、直接精确算出最优策略——那正是 Q-learning 在暗中近似的东西。

6. Sutton, R. S. (1988). *Learning to Predict by the Methods of Temporal Differences*. Machine Learning, 3(1):9–44. —— TD（λ） 与资格迹的奠基论文：用随时间衰减的痕迹把 TD 误差一次性回灌给近期到访状态，在单步 TD 与蒙特卡洛之间以 $\lambda$ 连续插值，是时序信用分配的经典解法。
7. Bengio, Louradour, Collobert, Weston (2009). *Curriculum Learning*. [ICML 2009](https://dl.acm.org/doi/10.1145/1553374.1553380). —— 课程学习的现代形式化：训练样本按易→难顺序呈现可更快收敛或收敛到更好局部最优；形式化三要素（定义难度 / 节奏 / 推进准则）；视为正则化与迁移学习（易→难是源域→目标域）；溯源 Elman 1993「starting small」；指出 anti-curriculum 在某些域反更好。是「从易到难教学法」在机器学习里的奠基出处，RL 里的自动课程生成（self-play / teacher-student / HER）皆为其在交互式设定下的特化。
8. Levine, S. (2018). *Reinforcement Learning and Control as Probabilistic Inference: A Tutorial and Review*. [arXiv:1805.00909](https://arxiv.org/abs/1805.00909). —— 控制即推断：引入二值最优性变量 $O_t$，把奖励重解释为对数最优似然 $\log P(O_t=1\mid s,a)=r(s,a)$，把「最大化累积奖励」改写成「给定每步最优，反推动作序列后验」的概率推断问题；消息传递给出 soft Bellman $V=\alpha\,\text{logsumexp}(Q/\alpha)$ 与 softmax 策略 $\pi=\mathrm{softmax}(Q/\alpha)$；确定性动力学下等价于精确推断、随机动力学下等价于变分推断（策略 $\pi$ 作变分分布，ELBO 分解为价值最大化 + 熵正则）；soft Q-learning=E 步后验推断、策略梯度=最小化 $\mathrm{KL}(\pi\|p^*)$、actor-critic=EM 交替。是 SAC 最大熵、DIAYN 互信息、DPO 闭式奖励的统一概率图模型根源。
9. Kaelbling, L. P., Littman, M. L., & Cassandra, A. R. (1998). *Planning and Acting in Partially Observable Stochastic Domains*. [Artificial Intelligence 101](https://www.sciencedirect.com/science/article/pii/S000437029800023X). —— POMDP 的经典综述：形式化 POMDP 元组 $(\mathcal S,\mathcal A,\mathcal O,P,Z,r,\gamma)$、**信念状态** $b(s)=P(s\mid h)$ 作为历史的充分统计量、信念更新 $b'(s')=\eta\,Z(o\mid s',a)\sum_s P(s'\mid s,a)b(s)$（Bayes 滤波）、信念 MDP 重构（信念作马尔可夫状态，MDP 全套算法可搬）、有限时域下值函数 piecewise-linear & convex 性质。文中 Tiger 问题（两门一虎一金币，LISTEN 有代价有噪声）是 POMDP 信念更新与「信息价值 vs 行动收益」权衡的经典教学示例。是「真实状态不可直接观测」场景（扑克、自动驾驶、医疗诊断、机器人定位）的理论根基。
10. Bellemare, Srinivasan, Ostrovski, Schaul, Saxton, Munos (2016). *Unifying Count-Based Exploration and Intrinsic Motivation*. [NeurIPS 2016 / arXiv:1606.01868](https://arxiv.org/abs/1606.01868). —— 伪计数（pseudo-count）奠基论文：从任意**学习正**密度模型导出等效访问计数 $\hat N_n(x)=\rho_n(x)(1-\rho'_n(x))/(\rho'_n(x)-\rho_n(x))$（$\rho_n$ 预测概率、$\rho'_n$ 重编码概率），把 count-based 探索从表格推广到高维非表格 RL；内在奖励 $r^i=(\hat N+0.01)^{-1/2}$；与 prediction gain 关系 $\hat N\approx(e^{\mathrm{PG}}-1)^{-1}$ 统一 count-based 与信息论 intrinsic motivation;CTS 密度模型在 Atari 像素上跑通，Montezuma's Revenge 取得进展。
11. Ostrovski, Bellemare, van den Oord, Munos (2017). *Count-Based Exploration with Neural Density Models*. [ICML 2017 / arXiv:1703.01310](https://arxiv.org/abs/1703.01310). —— 把 Bellemare 2016 的 CTS 密度模型换成更强的 **PixelCNN** 神经密度模型供给伪计数，处理原方法在密度模型假设被违反时的困难，提出更通用实用的算法；在多个 hard-exploration Atari 游戏上大幅刷新 SOTA。
12. Tang, Houthooft, Foote, Stooke, Chen, Duan, Schulman, De Turck, Abbeel (2017). *#Exploration: A Study of Count-Based Exploration for Deep Reinforcement Learning*. [NeurIPS 2017 / arXiv:1611.04717](https://arxiv.org/abs/1611.04717). —— hash-based 路线：用 SimHash（或 autoencoder 编码后哈希）把高维状态映射到低维桶，对桶计数驱动 bonus，无需训练生成式密度模型；比 pseudo-count 简单但受哈希冲突粒度限制；系统对比了 count-based 探索在 deep RL 多种设定下的效果。
