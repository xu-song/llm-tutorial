# 📊 熵与信息

信息论由香农（Claude Shannon）在 1948 年创立，它回答了一个看似哲学的问题：**「信息」能不能被量化？** 答案是能。这套理论是现代机器学习中**交叉熵损失函数**的来源——但在谈损失之前，我们要先打好地基：什么是信息、什么是熵。

> 📚 这是「信息论」板块的第一篇。本篇讲**度量单个/多个变量的不确定性**；下一篇[交叉熵与 KL 散度](/tutorials/cross-entropy-kl)讲**两个分布之间的差距**；第三篇[实战损失](/tutorials/ml-losses)落到真实模型。

## 自信息：一件事有多「意外」？

直觉上，**越不可能发生的事，一旦发生，带来的信息量越大**。

- 「明天太阳从东边升起」——几乎必然，毫无信息量
- 「明天本市发生地震」——极小概率，信息量巨大

香农用这个公式量化一个概率为 $p$ 的事件所含的**自信息**：

$$
I(x) = -\log_2 p(x)
$$

以 2 为底时，单位是 **比特（bit）**。概率越小，$-\log_2 p$ 越大，信息量越大。

上图的**霍夫曼树**是自信息最古老的应用：五个符号，概率越小的被放到树越深的位置、分到越长的码字（如 `1010`），概率越大的码字越短（如 `0`）——码字长度正是 $-\log_2 p$ 的整数近似。**熵就是这棵树上平均的码字长度**：概率分布越不均匀，「短码配常客、长码配稀客」的编码方案省下的比特越多。今天 ZIP、JPEG、乃至语言模型的算术编码，都是这个思想的徒子徒孙。

## 熵：平均信息量 = 不确定性

**熵（Entropy）** 是一个概率分布的**平均自信息**，衡量这个分布整体的「不确定性」（概率分布、期望的概念见[概率论基础](/tutorials/probability-basics)）：

$$
H(X) = -\sum_{i} p(x_i) \log_2 p(x_i)
$$

考虑一枚硬币，正面概率为 $p$。当 $p=0$ 或 $p=1$ 时结果完全确定，熵为 0；当 $p=0.5$ 时最难预测，熵达到最大值 1 bit。**拖动下面的滑块**亲自验证这条钟形曲线：

<EntropyExplorer />

> 💡 直觉：熵就是「平均要问多少个是/否问题才能确定结果」。结果越随机，要问的问题越多。

下面用代码计算任意离散分布的熵：

<CodeRunner defaultCode={`
import numpy as np

def entropy(probs):
    probs = np.array(probs)
    probs = probs[probs > 0]  # 忽略 0 概率项
    return -np.sum(probs * np.log2(probs))

print("均匀骰子 [1/6]*6 :", round(entropy([1/6]*6), 3), "bit")
print("公平硬币 [0.5,0.5]:", round(entropy([0.5, 0.5]), 3), "bit")
print("作弊硬币 [0.9,0.1]:", round(entropy([0.9, 0.1]), 3), "bit")
print("必然事件 [1.0]    :", round(entropy([1.0]), 3), "bit")
`} />

## 熵家族：从一个变量到两个变量

前面都是单个变量。现在引入**两个**随机变量 $X, Y$（比如「今天天气」和「我带不带伞」），就能定义更丰富的量：

| 名称 | 记号 | 直觉 | 对称性 |
|---|---|---|---|
| **熵** | $H(X)$ | $X$ 单独的不确定性 | —（单变量） |
| **联合熵** | $H(X,Y)$ | 同时看 $X$ 和 $Y$ 的总不确定性 | ✅ 对称 |
| **条件熵** | $H(Y\mid X)$ | 已知 $X$ 后，$Y$ 还剩多少不确定性 | ❌ 不对称 |
| **互信息** | $I(X;Y)$ | 知道 $X$ 能消除 $Y$ 多少不确定性（两者共享的信息） | ✅ 对称 |

它们由这组关系串起来（**链式法则**）：

$$
H(X,Y) = H(X) + H(Y\mid X), \qquad I(X;Y) = H(Y) - H(Y\mid X) = H(X)+H(Y)-H(X,Y)
$$

一句话记住它们的层次：**条件熵是「减法」（知道一个变量后剩下的不确定性），互信息是「交集」（两个变量共享的信息），联合熵是「并集」（两者合起来的总信息）。** 当 $X, Y$ 相互独立时，知道谁都帮不上忙，$I(X;Y)=0$，此时 $H(X,Y)=H(X)+H(Y)$。

## 一张图看懂它们的关系

这五个量的关系，用一张**区间图**最直观：把联合熵 $H(X,Y)$ 摊成一条横条，它正好切成三段——

$$
\underbrace{H(X,Y)}_{\text{整条}} = \underbrace{H(X\mid Y)}_{\text{只 }X\text{ 独有}} + \underbrace{I(X;Y)}_{\text{两者共享}} + \underbrace{H(Y\mid X)}_{\text{只 }Y\text{ 独有}}
$$

上方括号 $H(X)$ 罩住「$X$ 独有 + 共享」两段，下方括号 $H(Y)$ 罩住「共享 + $Y$ 独有」两段——它们**重叠的那一段就是互信息** $I(X;Y)$。这也就是经典的信息论「维恩图」被拉直后的样子。**拖动滑块**看各段如何伸缩：

## 互信息其实是一个 KL 散度

上图里「独立时互信息为 0」不是巧合——它藏着一个漂亮的等式。互信息**恰好等于**「真实联合分布 $P(X,Y)$」与「假装两者独立的分布 $P(X)P(Y)$」之间的 **KL 散度**：

$$
I(X;Y) = D_{\mathrm{KL}}\big(P(X,Y)\;\big\|\;P(X)\,P(Y)\big) = \sum_{x,y} P(x,y)\log\frac{P(x,y)}{P(x)P(y)}
$$

这个视角一下子把互信息讲透了：

- **它衡量「真实分布离‘独立’有多远」**。$X,Y$ 越相关，联合分布越偏离 $P(X)P(Y)$，KL 越大。
- **它天然非负**（$D_{\mathrm{KL}}\ge 0$），所以 $I(X;Y)\ge 0$——这解释了为什么互信息永远不会是负的。
- **独立 $\iff$ 互信息为 0**：当 $P(X,Y)=P(X)P(Y)$ 时 KL 为 0,正好对应上图里绿色段消失.

下面用代码验证「两种算法算出的互信息完全一致」：

<CodeRunner defaultCode={`
import numpy as np

# 天气/带伞的联合分布(相关强度 0.8)
Pxy = np.array([[0.4, 0.1],
                [0.1, 0.4]])
Px = Pxy.sum(axis=1)   # 边缘 P(X)
Py = Pxy.sum(axis=0)   # 边缘 P(Y)

def H(p):
    p = np.array(p); p = p[p > 0]
    return -np.sum(p * np.log2(p))

# 方法一:用熵  I = H(X) + H(Y) - H(X,Y)
I_entropy = H(Px) + H(Py) - H(Pxy.flatten())

# 方法二:用 KL  I = D_KL( P(X,Y) || P(X)P(Y) )
outer = np.outer(Px, Py)          # 假装独立的分布 P(X)P(Y)
mask = Pxy > 0
I_kl = np.sum(Pxy[mask] * np.log2(Pxy[mask] / outer[mask]))

print(f"方法一(熵之差)  I = {I_entropy:.4f} bit")
print(f"方法二(KL 散度)  I = {I_kl:.4f} bit")
print(f"两者一致: {np.isclose(I_entropy, I_kl)}")
print()
print("独立分布(相关强度 0.5)时:")
Pind = np.array([[0.25,0.25],[0.25,0.25]])
Px2, Py2 = Pind.sum(1), Pind.sum(0)
I2 = np.sum(Pind * np.log2(Pind / np.outer(Px2, Py2)))
print(f"  I = D_KL(P(X,Y) || P(X)P(Y)) = {I2:.4f} bit  (独立 → 0)")
`} />

> 🔗 这条等式是[交叉熵与 KL 散度](/tutorials/cross-entropy-kl)的第一个「预告」：KL 散度衡量「用一个分布近似另一个分布的代价」。这里被近似的真相是「真实联合分布」，而近似它的是「假装独立」——差多少，就是两个变量共享了多少信息。

<CodeRunner defaultCode={`
import numpy as np

# 联合分布 P(X,Y):行=X(晴/雨),列=Y(不带伞/带伞)
# 天气和带伞明显相关:晴天多半不带,雨天多半带
Pxy = np.array([[0.4, 0.1],
                [0.1, 0.4]])

Px = Pxy.sum(axis=1)   # 边缘分布 P(X)
Py = Pxy.sum(axis=0)   # 边缘分布 P(Y)

def H(p):
    p = np.array(p); p = p[p > 0]
    return -np.sum(p * np.log2(p))

HX  = H(Px)
HY  = H(Py)
HXY = -np.sum(Pxy[Pxy > 0] * np.log2(Pxy[Pxy > 0]))  # 联合熵
HY_given_X = HXY - HX          # 条件熵 H(Y|X) = H(X,Y) - H(X)
MI = HX + HY - HXY             # 互信息 I(X;Y)

print(f"H(X) 天气的不确定性      = {HX:.3f} bit")
print(f"H(Y) 带伞的不确定性      = {HY:.3f} bit")
print(f"H(X,Y) 联合熵           = {HXY:.3f} bit")
print(f"H(Y|X) 知道天气后仍不确定 = {HY_given_X:.3f} bit")
print(f"I(X;Y) 天气透露的带伞信息 = {MI:.3f} bit")
print(f"验证 I = H(Y) - H(Y|X)  = {HY - HY_given_X:.3f} bit  ✓")
`} />

> 💡 **互信息**是特征选择、聚类评估（如调整互信息 AMI）、乃至表示学习（InfoNCE、对比学习）的理论基础——它衡量「两个变量到底有多相关」，且不像相关系数那样只能捕捉线性关系。

## 常见问题 FAQ

**Q：熵的单位为什么有时是 bit，有时是 nat?**
取决于对数的底。以 2 为底单位是 **bit**，以 $e$ 为底是 **nat**（自然单位），以 10 为底是 dit。机器学习里常用自然对数（nat），因为求导方便；换底只差一个常数因子，不影响优化。

**Q：为什么熵在均匀分布时最大？**
因为均匀分布最「难猜」——每个结果概率相等，没有任何倾向可利用。任何偏向（如作弊硬币）都会降低不确定性，从而降低熵。$n$ 个等可能结果的熵是 $\log_2 n$。

**Q：互信息和相关系数有什么区别？**
相关系数只能捕捉**线性**关系，两个变量若是非线性相关（如 $y=x^2$）相关系数可能为 0。互信息 $I(X;Y)$ 衡量任意形式的统计依赖，只要不独立就 $>0$，因此更通用，但估计连续变量的互信息更难。

**Q：条件熵为什么不对称？**
$H(Y\mid X)$ 问「知道天气后，带伞还有多少悬念」，$H(X\mid Y)$ 问「知道带没带伞后，天气还有多少悬念」——这是两个不同的问题，一般不相等。而互信息 $I(X;Y)$ 衡量「共享的信息」，对调 $X,Y$ 不变，所以对称。

## 动手作业

1. **验证熵的极值**：修改熵的代码，遍历二元分布 $[p, 1-p]$ 中 $p$ 从 0 到 1，确认熵在 $p=0.5$ 处取最大值 1 bit.
2. **换底练习**：把熵函数从 `log2` 改成 `log`（自然对数），计算同一分布的熵，验证 $H_{\text{nat}} = H_{\text{bit}} \times \ln 2$（即 nat 值 ÷ bit 值 $= \ln 2 \approx 0.693$）。反过来 bit 值 ÷ nat 值就是 $1/\ln 2 \approx 1.443$——别记反了。
3. **互信息与独立**：构造一个 $X,Y$ 相互独立的联合分布（即 $P(x,y)=P(x)P(y)$），用代码算出 $I(X;Y)=0$；再改成相关的分布，看互信息变大。
4. **信息增益**：给定一个二分类数据集，计算按某特征划分前后的熵差（信息增益），这正是[决策树](/tutorials/decision-tree)选特征的依据。

## 小结

| 概念 | 公式 | 含义 |
|---|---|---|
| 自信息 | $-\log_2 p$ | 单个事件的「意外程度」 |
| 熵 $H(X)$ | $-\sum p\log_2 p$ | 一个分布的平均不确定性 |
| 联合熵 $H(X,Y)$ | $-\sum P(x,y)\log_2 P(x,y)$ | 两个变量合起来的总不确定性 |
| 条件熵 $H(Y\mid X)$ | $H(X,Y)-H(X)$ | 已知 $X$ 后 $Y$ 剩下的不确定性 |
| 互信息 $I(X;Y)$ | $H(X)+H(Y)-H(X,Y)$ | 两个变量共享的信息量，$\geq 0$ |

> 🎯 一句话记住：**熵度量「一个分布有多不确定」，互信息度量「两个变量有多相关」。** 下一篇我们引入模型的预测分布 $Q$，看**用错误的分布去编码真相**要付多大代价——那就是[交叉熵与 KL 散度](/tutorials/cross-entropy-kl)。
