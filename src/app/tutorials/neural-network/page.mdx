# 🧠 神经网络入门

还记得[逻辑回归](/tutorials/logistic-regression)吗？它把输入做线性组合，再过一个 Sigmoid 得到概率。**神经网络的核心思想简单到惊人：把这样的「神经元」堆成很多层。** 单个逻辑回归只能画一条直线分界，但把它们层层叠加，就能拟合几乎任意复杂的函数 —— 这正是深度学习席卷一切的起点。

> 一个神经元 = 一个逻辑回归。一群神经元分层连接 = 神经网络。深度学习的「深」，就是层数多。

## 一个神经元在做什么

每个神经元干两件事：**线性组合**输入，再过一个**激活函数**（非线性）：

$$
a = \sigma\!\left( \sum_i w_i x_i + b \right)
$$

这和逻辑回归一模一样。关键在于**激活函数必须非线性** —— 否则无论堆多少层，合起来还是一条直线（线性的复合仍是线性）。常见激活函数：

| 激活函数 | 公式 | 特点 |
|---|---|---|
| Sigmoid | $\frac{1}{1+e^{-z}}$ | 输出 （0,1），早期常用，易梯度消失 |
| Tanh | $\frac{e^z-e^{-z}}{e^z+e^{-z}}$ | 输出 （-1,1），中心化 |
| **ReLU** | $\max(0, z)$ | 简单、不易梯度消失，**深度学习默认** |

## 为什么需要「隐藏层」：XOR 难题

有些问题**一条直线分不开**。经典例子是 **XOR（异或）**：输入 （0,0）→0，（1,1）→0，但 （0,1）→1，（1,0）→1。正类和负类交叉分布，**任何直线都无法分开** —— 逻辑回归在这里彻底失败。

但只要加一层**隐藏层**，网络就能把数据「掰弯」成线性可分。下面是一个训练好的 2-2-1 网络。**点击 x₁、x₂ 节点**切换 0/1，观察激活值如何逐层传播，最终正确算出 XOR:

试遍 4 种输入组合，你会发现网络全部答对。隐藏层的 h₁ 学成了「OR」、h₂ 学成了「AND」，输出层再把它们组合成 XOR —— **隐藏层自动学会了有用的中间特征**，这就是神经网络的魔力。

## 前向传播：用代码算一遍

「前向传播」就是输入逐层计算到输出的过程。下面用 NumPy 手写上面那个 XOR 网络，你会发现核心就是**矩阵乘法 + 激活函数**：

<CodeRunner defaultCode={`
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 训练好的权重(2→2→1)
W1 = np.array([[20, 20], [20, 20]])   # 输入→隐藏
b1 = np.array([-10, -30])
W2 = np.array([20, -20])              # 隐藏→输出
b2 = -10

def forward(x):
    h = sigmoid(W1 @ x + b1)          # 隐藏层
    y = sigmoid(W2 @ h + b2)          # 输出层
    return y

print("XOR 真值表:")
for x in [[0,0], [0,1], [1,0], [1,1]]:
    out = forward(np.array(x))
    print(f"  {x} → {out:.3f} → 判为 {int(out >= 0.5)}")
`} />

## 训练：反向传播 + 梯度下降

网络的权重不是手工设的，而是**学**出来的。训练用的正是前面学过的两件武器：

1. **损失函数**：分类用[交叉熵](/tutorials/cross-entropy-kl)，衡量预测与真实的差距
2. **梯度下降**：[沿梯度反方向](/tutorials/gradient-descent)更新每个权重

唯一的新东西是**反向传播（Backpropagation）**——它用链式法则，高效地把输出层的误差「倒推」回每一层，算出每个权重该怎么调。前向传播上面已经用 NumPy 写过了，训练无非是在它外面套一个循环：前向算预测和损失，反向把误差层层回传成梯度，再各自更新一步。核心逻辑就这几行：

```
# 神经网络训练 伪代码(前向 + 反向传播 + 梯度下降)
for epoch in range(轮数):
    # --- 前向:逐层算激活,缓存中间值供反向用 ---
    a = x
    for 层 in 网络:            # z = W·a + b;  a = 激活(z)
        缓存(a, z);  a = 激活(W @ a + b)
    loss = 交叉熵(a, y)         # 输出层预测 vs 真实标签

    # --- 反向:从输出层往输入层,用链式法则逐层求梯度 ---
    δ = a - y                  # 输出层误差(CE + softmax 的漂亮结果)
    for 层 in 反向(网络):
        grad_W = δ @ a_prev.T   # 该层权重的梯度
        grad_b = δ
        δ = (W.T @ δ) * 激活导数(z_prev)   # 误差传到前一层
        W -= lr * grad_W;  b -= lr * grad_b   # 梯度下降更新
```

下面用 scikit-learn 的 `MLPClassifier` 真正训练一个网络解 XOR（`fit()` 内部做的正是上面这套循环）:

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.neural_network import MLPClassifier

X = np.array([[0,0], [0,1], [1,0], [1,1]])
y = np.array([0, 1, 1, 0])   # XOR

# 一个隐藏层、4 个神经元,足以解 XOR
net = MLPClassifier(hidden_layer_sizes=(4,), activation='relu',
                    max_iter=5000, random_state=1)
net.fit(X, y)

print("准确率:", net.score(X, y))
for x in X:
    print(f"  {x} → 预测 {net.predict([x])[0]}")
print("\\n隐藏层权重形状:", net.coefs_[0].shape, "(2 输入 × 4 神经元)")
`} />

> 💡 试着把 `hidden_layer_sizes` 改成 `()`（无隐藏层，退化成逻辑回归），你会看到准确率掉到 0.5 —— 再次印证：**没有隐藏层就解不了 XOR**。

## 看见「曲线」：神经网络的决策边界

[决策树](/tutorials/decision-tree)的边界是横平竖直的阶梯；神经网络因为有非线性激活，能画出**平滑弯曲**的边界。用同样的 `make_moons` 数据训练一个 MLP，把边界画出来对比 —— **图形直接显示在下方**：

<CodeRunner

  defaultCode={`
import numpy as np
import matplotlib.pyplot as plt
from sklearn.neural_network import MLPClassifier
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=200, noise=0.25, random_state=0)
clf = MLPClassifier(hidden_layer_sizes=(16, 16), activation='relu',
                    max_iter=2000, random_state=0).fit(X, y)

xx, yy = np.meshgrid(np.linspace(X[:,0].min()-0.5, X[:,0].max()+0.5, 300),
                     np.linspace(X[:,1].min()-0.5, X[:,1].max()+0.5, 300))
Z = clf.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)

plt.figure(figsize=(6, 4.5))
plt.contourf(xx, yy, Z, alpha=0.3, cmap="coolwarm")
plt.scatter(X[:,0], X[:,1], c=y, cmap="coolwarm", edgecolors="k", s=25)

plt.show()

> 💡 和决策树的阶梯边界并排看：神经网络的边界是**顺滑的曲线**，能自然贴合两个月牙的弧形 —— 这就是非线性激活 + 隐藏层带来的表达力。

## 典型应用场景

把这个简单结构放大、加深，就是现代 AI 的基础：

- **图像识别**：卷积神经网络（CNN）识别物体、人脸、医学影像
- **自然语言处理**：Transformer（GPT、Claude 的底层）做翻译、对话、写代码
- **语音识别 / 合成**：把声音波形转成文字,或反过来
- **推荐系统**：深度网络学习用户与物品的复杂交互
- **强化学习**：AlphaGo、自动驾驶里的决策网络

> 🔗 你现在看到的这个 2-2-1 网络，和拥有上千亿参数的大语言模型，**结构原理是同一个**：线性组合 + 非线性激活，层层堆叠，用梯度下降训练。

这条路的现代终点是 **Transformer** —— 它同样由「线性组合 + 非线性」的层堆叠而成，只是把神经元组织成了带注意力的结构。下图是 *Attention Is All You Need* 里的经典架构图，你可以对照着找熟悉的元素：前馈网络（Feed Forward，就是两层全连接）、残差连接、LayerNorm:

## ❓ 常见问题 FAQ

**Q：神经网络和逻辑回归到底什么关系？**
单个神经元（用 Sigmoid）就是一个逻辑回归。神经网络 = 很多神经元分层连接。所以逻辑回归可看作「没有隐藏层的神经网络」。

**Q：为什么激活函数必须是非线性的？**
若激活是线性的，多层叠加在数学上等价于单层（线性的复合还是线性），再深也只能学线性边界。非线性激活才让网络能逼近任意复杂函数（万能逼近定理）。

**Q：隐藏层越多越好吗？**
不是。层数/神经元越多，表达力越强，但也更容易过拟合、更难训练（梯度消失/爆炸）、更耗算力。要在容量和数据量之间权衡，配合正则化、Dropout 等技巧（见[过拟合与正则化](/tutorials/overfitting-regularization)）。

**Q：反向传播很难理解，必须掌握吗？**
直觉上它就是「链式法则 + 梯度下降」的高效实现：从输出误差倒推每个权重的梯度。入门阶段理解「它在自动算梯度」即可，框架（PyTorch/TensorFlow）会自动完成。

**Q：为什么现在多用 ReLU 而不是 Sigmoid?**
Sigmoid 在输入很大/很小时梯度趋近 0（梯度消失），深层网络难以训练。ReLU($\max(0,z)$)在正区间梯度恒为 1，计算也更快，成了默认选择。

## 🔭 讨论与展望

一个 XOR 玩具网络，藏着今天所有大模型的影子：堆层、加非线性、梯度下降端到端训练。但「堆深加宽」这条路走到 Transformer 和千亿参数后，瓶颈也变了。

### ⚠️ 当前方法的局限

- **算力与数据壁垒：这条路正变得只有少数玩家走得动**。「加宽加深」的现代版本就是堆参数和堆数据；但训练一个前沿大模型的算力已进入千万美元量级，高质量数据开始触及「数据墙」——这条最直接的提分路径，正变得只有少数玩家走得动。
- **反向传播的信用分配脆弱，深网训练仍是门艺术**。梯度通过深层链式传播，远端信号易消失/爆炸；即便有残差连接、LayerNorm、Adam，深网训练仍是脆弱的艺术——超参敏感、初始化挑剔、易塌缩。
- **可解释性差，关键领域难以审计**。几亿参数拟合出的决策边界，人类难以审计；「为什么模型这么答」在关键领域（医疗、司法、自动驾驶）是硬需求，但目前的解释方法（注意力可视化、探针、归因）都只给局部暗示，难下严格结论。
- **泛化与记忆的边界模糊，无法在参数里分开**。大模型既能在训练分布外泛化，也会死记训练数据（隐私泄漏）；两者共享同一套权重，我们至今没有干净的方法把「泛化能力」和「记忆」在参数里分开。
- **静态权重追不上动态世界**。训练完权重就冻结，但世界在变（知识更新、分布漂移）；微调/继续学习又易引发灾难性遗忘——网络缺少「持续学习」的天然机制。

### 🚀 前沿进展

1. **架构创新**.Transformer 之后：Mamba 等 state-space 模型把注意力平方开销降为线性；MoE（混合专家）用稀疏激活在不增推理算力下扩参数；两者都在挑战「堆稠密 Transformer」的默认。
2. **机理可解释性**。不再只看注意力图，而是去网络里找**可解释电路**——诱导头（induction heads）、in-context learning 回路；目标是把「黑盒」拆成可命名、可审计的部件。
3. **参数高效适配**.LoRA、prefix tuning 等让一个底座模型用极少额外参数适配千百个下游任务——「训一个大网」正变成「训一个底座 + 一堆小适配器」。
4. **持续学习与记忆**。把外部记忆（检索、episodic buffer）接进网络，或用 replay buffer + 稀疏更新对抗遗忘，让模型在部署后还能学新东西而不忘旧的。
5. **缩放之外**。社区开始反思「只靠缩放能走多远」：数据质量、训练课程、合成数据、强化学习反馈正在成为比单纯加参数更重要的提分杠杆。

### 🤔 反思

1. **神经网络是智能的全部形态吗？** 神经网络赢了过去十年，但它本质上还是「用梯度下降拟合可微函数」——一个极强的**函数逼近器**。符号推理、因果建模、概率编程这些范式处理「组合泛化」「干预推理」时，仍比深网更自然。「能拟合」和「能推理」是一回事吗？

2. **缩放定律能一直走下去吗？** 过去十年的提分主因是堆参数 + 堆数据，但数据墙已在眼前、算力门槛进入千万美元量级。仅靠缩放是否还能持续涨点，还是必须靠数据质量、训练课程、强化学习反馈这些「非缩放杠杆」？

3. **下一代架构会取代 Transformer 吗？** Mamba 等状态空间模型把注意力平方开销降为线性、MoE 用稀疏激活扩参数——它们在某些维度已超过稠密 Transformer，但还没全面取代。你学的「层 + 非线性 + 反向传播」是这些架构的共同底座，即便 Transformer 被替代，这套基础会过时吗？

4. **神经网络会一直独霸，还是沦为团队一员？** 更可能的未来是**融合**：神经网络负责感知与模式识别，符号/概率系统负责推理与因果，检索负责把知识接进来——LLM + 工具调用 + 检索增强已是这个方向的雏形。神经网络会更像一个**组件**，还是整个系统？

> 🎯 **一句话**：神经网络把「堆层 + 非线性 + 梯度下降」做到了极致，成了过去十年 AI 的发动机；但缩放的天花板、可解释性、持续学习正逼着它从「单打冠军」走向「团队一员」。

## 📌 小结

| 要点 | 说明 |
|---|---|
| 神经元 | 线性组合 + 非线性激活，即一个逻辑回归 |
| 隐藏层 | 自动学习中间特征，让线性不可分问题变可分（如 XOR） |
| 激活函数 | 必须非线性；现代默认 **ReLU** |
| 训练 | **交叉熵损失 + 反向传播 + 梯度下降** |
| 威力 | 加深加宽即现代深度学习（CNN/Transformer/大模型） |

> 🎯 一句话：**神经网络就是把逻辑回归堆成层，用梯度下降端到端训练。** 你在这套教程里学的每一块 —— Sigmoid、交叉熵、梯度下降 —— 在这里汇成了一条河。
