# 🎯 K 近邻分类（KNN）

KNN 可能是最容易理解的机器学习算法：**要判断一个新样本属于哪一类，就看离它最近的 K 个邻居都是什么类，少数服从多数。**

> 「物以类聚，人以群分」—— 如果你周围的朋友大多喜欢篮球，那你大概率也喜欢篮球。

## 算法步骤

给定一个待分类的点，KNN 做三件事：

1. 计算它到**所有**训练样本的距离（通常用欧氏距离）
2. 选出距离最近的 **K** 个邻居
3. 这 K 个邻居里哪一类最多，就把新点判为哪一类

欧氏距离的公式：

$$
d(p, q) = \sqrt{(p_x - q_x)^2 + (p_y - q_y)^2}
$$

把查询点放在两类**中间地带**，然后改变 K，你会发现：

- **K=1**：只看最近的 1 个邻居,容易被噪声点影响（过拟合）
- **K 较大**：决策更平滑、更稳健,但太大会忽略局部结构
- **K 一般取奇数**，避免投票平局

近邻的「投票方式」也有讲究：可以让 K 个邻居**等权投票**（uniform），也可以让**越近的邻居票越重**（距离倒数加权）。下图对比了两种权重下 3-NN 的预测函数 —— 距离加权时，离哪个样本越近，就越容易被它的标签主导：

## 用 scikit-learn 实现

真实代码里，KNN 同样只需几行。修改 `n_neighbors` 看预测如何变化：

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.neighbors import KNeighborsClassifier

# 训练数据:两个特征 + 类别标签
X = np.array([
    [1.5, 2], [2, 3], [1, 3.5], [2.5, 1.5],   # A 类 (0)
    [6, 6], [6.5, 5], [7, 6.5], [5.5, 7],      # B 类 (1)
])
y = np.array([0, 0, 0, 0, 1, 1, 1, 1])

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X, y)

# 预测几个新点
tests = np.array([[4, 4], [2, 2], [6.5, 6]])
preds = model.predict(tests)
for pt, p in zip(tests, preds):
    print(f"点 {pt} -> {'A 类' if p == 0 else 'B 类'}")
`} />

## 量纲的陷阱：标准化前后对比

KNN 完全依赖「距离」，而距离会被**大数值特征**主导。下面用「年龄 + 收入」预测人群分类，看标准化前后预测结果如何反转：

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler

# 特征:年龄(20-60)、年收入(单位:元,数值巨大)
X = np.array([
    [25, 30000], [30, 35000], [28, 32000],   # 群体 0:年轻中低收入
    [50, 90000], [55, 95000], [52, 88000],    # 群体 1:年长高收入
])
y = np.array([0, 0, 0, 1, 1, 1])
new = np.array([[27, 91000]])  # 年轻但高收入

# 不标准化:收入(差几万)碾压年龄(差几十)
raw = KNeighborsClassifier(n_neighbors=3).fit(X, y).predict(new)

# 标准化后:两个特征同等重要
Xs = StandardScaler().fit_transform(X)
news = StandardScaler().fit(X).transform(new)
scaled = KNeighborsClassifier(n_neighbors=3).fit(Xs, y).predict(news)

print("不标准化的预测:", "群体", raw[0], "  (几乎只看收入)")
print("标准化后的预测:", "群体", scaled[0])
`} />

## 典型应用场景

- **推荐系统**：找「和你最相似的 K 个用户」,推荐他们喜欢的内容（协同过滤）
- **图像识别（小规模）**：手写数字 MNIST 上 KNN 也能到 ~97% 准确率
- **异常检测**：到最近邻的距离过大,可判定为离群点
- **缺失值填补**：用最近邻样本的均值填补缺失字段（KNNImputer）

## 常见问题 FAQ

**Q：K 该怎么选？**
常用经验值是 $\sqrt{n}$（n 为样本数），并取奇数避免平局。更稳妥的做法是用**交叉验证**遍历多个 K，选验证集准确率最高的。

**Q：K=1 一定过拟合吗？**
K=1 时决策边界极不平滑，对噪声敏感、容易过拟合；但在数据干净、类别分得很开时，K=1 也能很准。

**Q：为什么说 KNN「没有训练过程」？**
它属于**惰性学习 / 基于实例的学习**：`fit` 只是把数据存下来，真正的计算全在预测时发生。所以训练快、预测慢。

**Q：特征很多时 KNN 还好用吗？**
会遭遇**维度灾难** —— 高维空间里所有点的距离都趋于相近，「最近邻」失去意义。高维场景建议先降维（PCA）或换模型。

**Q：KNN 能做回归吗？**
能。`KNeighborsRegressor` 取 K 个邻居目标值的平均作为预测，思路完全一样。

## 小结

- KNN 是**惰性学习**：它不「训练」模型，只是把数据存起来，预测时才计算
- 优点：简单、无需训练、天然支持多分类
- 缺点：预测慢（要算到所有点的距离）、对特征尺度敏感（记得先标准化！）
- **K 是关键超参数**：小则敏感,大则平滑

> ⚠️ KNN 对特征的**量纲**很敏感。如果一个特征是「年龄（0-100）」，另一个是「收入（0-100000）」，距离会被收入主导。实际使用前务必做特征标准化。
