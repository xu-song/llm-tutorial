# 📐 动态规划：已知模型时精确求解

[强化学习入门](/tutorials/reinforcement-learning)里的 Q-learning 是**靠试错**一点点摸出好策略的。但如果我们**已经完全知道环境的规则**——在状态 $s$ 做动作 $a$ 会以多大概率转移到哪、拿多少奖励——还需要试错吗？不需要：可以直接用**动态规划（Dynamic Programming, DP）** 把最优策略**精确算出来**。<Cite n={[1,5]} />

DP 是整个强化学习的理论地基。Q-learning、DQN 本质上都是「在**不知道**模型时，用采样去近似 DP 的精确计算」。先看懂精确版，才能真正理解那些近似版在做什么。

## 前提：一个已知的 MDP

动态规划要求环境的两样东西**完全已知**：

- **转移概率** $P(s'\mid s,a)$：在 $s$ 做 $a$，落到各个 $s'$ 的概率；
- **奖励函数** $r(s,a,s')$：这一步拿多少奖励。

有了它们，就不必真去环境里走——每一步都能**在纸上（或内存里）把所有可能的后继状态加权求和**。这正是 DP 与 Q-learning 的分水岭：DP 需要模型、做全空间精确扫描；Q-learning 不需要模型、用采样的 $(s,a,r,s')$ 近似这个求和。

## Bellman 方程：价值的自洽条件

一切从**贝尔曼方程**出发。它说的是一件朴素的事：**一个状态的价值 = 立刻拿到的奖励 + 后继状态价值的折扣**。

固定一个策略 $\pi$ 时，它的价值满足**贝尔曼期望方程**：

$$
V^\pi(s) = \sum_{s'} P(s'\mid s,\pi(s))\big[r + \gamma\,V^\pi(s')\big]
$$

而**最优**价值满足**贝尔曼最优方程**——把「按 π 走」换成「取最好的动作」：

$$
V^*(s) = \max_a \sum_{s'} P(s'\mid s,a)\big[r + \gamma\,V^*(s')\big]
$$

两者只差一个 $\max$：期望方程**评估**一个给定策略，最优方程**寻找**最优策略。动态规划的两大算法，正是分别围绕这两个方程展开。<Cite n={[1,5]} />

## 价值迭代（Value Iteration）

最直接的想法：把贝尔曼最优方程当**更新规则**反复套用，让价值自己收敛到 $V^*$：

$$
V_{k+1}(s) \leftarrow \max_a \sum_{s'} P(s'\mid s,a)\big[r + \gamma\,V_k(s')\big]
$$

一轮扫过所有状态叫一次「sweep」。当两次 sweep 的最大变化小于阈值 $\theta$ 就停，再对最终的 $V^*$ **贪心**一次抽出最优策略 $\pi^*(s)=\arg\max_a Q^*(s,a)$。<Cite n={1} />

**拖动下面的「sweep」滑块**，亲眼看价值如何从目标 🏁 出发、**每轮向外扩散一圈**地「倒灌」回起点——第 $k$ 次 sweep 后，只有距目标 $k$ 步以内的格子才「知道」该往哪走：

import numpy as np

N, GOAL, PIT, START = 4, 15, 9, 0
A = [(0,-1),(1,0),(0,1),(-1,0)]   # 上 右 下 左
gamma = 0.9
TERM = {GOAL, PIT}

def nxt(s, a):                     # 已知模型:确定性转移
    r, c = divmod(s, N); dc, dr = A[a]
    nr, nc = r + dr, c + dc
    return nr*N + nc if (0 <= nr < N and 0 <= nc < N) else s

def reward(s):
    return 1.0 if s == GOAL else -1.0 if s == PIT else -0.02

V = np.zeros(N*N)
for sweep in range(1000):
    delta = 0.0
    for s in range(N*N):
        if s in TERM: continue
        old = V[s]
        # 贝尔曼最优备份:对所有动作取 max(这里转移确定,求和只剩一项)
        V[s] = max(reward(nxt(s,a)) + (0 if nxt(s,a) in TERM else gamma*V[nxt(s,a)])
                   for a in range(4))
        delta = max(delta, abs(old - V[s]))
    if delta < 1e-6:
        break

# 从 V* 贪心抽取最优策略
pi = [int(np.argmax([reward(nxt(s,a)) + (0 if nxt(s,a) in TERM else gamma*V[nxt(s,a)])
                     for a in range(4)])) for s in range(N*N)]

s, path = START, [START]
for _ in range(20):
    if s in TERM: break
    s = nxt(s, pi[s]); path.append(s)

print(f"价值迭代在 {sweep} 次 sweep 后收敛")
print("最优路径:", path, "| 到达 🏁:", path[-1]==GOAL, "| 避开 🕳️:", PIT not in path)
print("-> 完全没试错,直接算出了和 Q-learning 一样的最优策略")

## 策略迭代（Policy Iteration）

另一条路不去逼近价值，而是**直接在策略上迭代**，两步交替：

1. **策略评估（policy evaluation）**：固定当前策略 $\pi$，用贝尔曼**期望**方程反复更新，算准它的 $V^\pi$；
2. **策略改进（policy improvement）**：对刚算出的 $V^\pi$ **贪心**，得到一个不差于原策略的新策略。

只要策略还在变就继续，直到**策略稳定不再改变**——此时它必然最优。<Cite n={2} />下面在同一网格上跑策略迭代，它通常只需**极少几轮**就锁定最优策略：

<CodeRunner defaultCode={`
import numpy as np

N, GOAL, PIT, START = 4, 15, 9, 0
A = [(0,-1),(1,0),(0,1),(-1,0)]
gamma = 0.9
TERM = {GOAL, PIT}

def nxt(s, a):
    r, c = divmod(s, N); dc, dr = A[a]
    nr, nc = r + dr, c + dc
    return nr*N + nc if (0 <= nr < N and 0 <= nc < N) else s

def reward(s):
    return 1.0 if s == GOAL else -1.0 if s == PIT else -0.02

def q(s, a, V):
    ns = nxt(s, a)
    return reward(ns) + (0 if ns in TERM else gamma*V[ns])

pi = [0]*(N*N)                     # 初始策略:全「上」
for rounds in range(100):
    # 1) 策略评估:把当前策略的 V^pi 算准
    V = np.zeros(N*N)
    while True:
        d = 0.0
        for s in range(N*N):
            if s in TERM: continue
            old = V[s]; V[s] = q(s, pi[s], V)
            d = max(d, abs(old - V[s]))
        if d < 1e-9: break
    # 2) 策略改进:对 V^pi 贪心
    stable = True
    for s in range(N*N):
        if s in TERM: continue
        best = int(np.argmax([q(s, a, V) for a in range(4)]))
        if best != pi[s]:
            pi[s] = best; stable = False
    if stable:
        break

s, path = START, [START]
for _ in range(20):
    if s in TERM: break
    s = nxt(s, pi[s]); path.append(s)

print(f"策略迭代在 {rounds+1} 轮后策略稳定")
print("最优路径:", path, "| 到达 🏁:", path[-1]==GOAL, "| 避开 🕳️:", PIT not in path)

## 两者对比

| | 价值迭代 | 策略迭代 |
|---|---|---|
| 迭代对象 | 价值函数 $V$ | 策略 $\pi$ |
| 内层备份 | $\max_a$（最优方程） | 固定 $\pi$（期望方程） |
| 停止条件 | $V$ 收敛（变化 $<\theta$） | 策略不再改变 |
| 单轮开销 | 便宜（一次扫描） | 较贵（内含完整评估） |
| 迭代次数 | 可能较多 | 极少（策略数有限，必然有限步收敛） |

两者都在**折扣 $\gamma<1$** 的有限 MDP 上**保证收敛到最优**（贝尔曼算子是压缩映射）。<Cite n={[1,2,5]} />实践中价值迭代实现简单，策略迭代往往用更少轮数就锁定策略——很多现代算法（如 [Actor-Critic](/tutorials/policy-gradient)）本质上就是「广义策略迭代」：评估与改进交替进行的思想。

## 收敛理论：为什么 DP 一定收敛到最优

上面一句话带过「贝尔曼算子是压缩映射」，这一节把这个**整个 DP 理论的心脏**完整展开——它回答一个根本问题：**凭什么反复套用贝尔曼备份，就一定逼近唯一的最优价值 $V^*$，而不会震荡或发散？** 答案是**压缩映射定理（Contraction Mapping Theorem，又称 Banach 不动点定理）**。下面把定义、证明、误差界、有限步收敛逐条讲清楚。

### 贝尔曼算子：把「一次备份」当成函数

把值迭代的一次全空间扫描看成**算子** $T^*$ 作用在价值函数上（Bellman 1957）：

$$
(T^*V)(s) \;=\; \max_a \sum_{s'} P(s'\mid s,a)\big[r(s,a,s') + \gamma\,V(s')\big]
$$

$T^*$ 吃一个价值函数 $V$，吐出一次备份后的新价值函数。值迭代 $V_{k+1}=T^*V_k$ 就是反复套用 $T^*$.$V^*$ 是 $T^*$ 的**不动点**（fixed point）:$T^*V^*=V^*$——这正是贝尔曼最优方程。<Cite n={1} />要证值迭代收敛，只需证 $T^*$ 是**压缩映射**。

### 关键引理：$|\max_a f(a) - \max_a g(a)| \le \max_a |f(a)-g(a)|$

证明 $T^*$ 是压缩前，先需要一个关于 $\max$ 的小引理。设 $a_f=\arg\max_a f(a)$、$a_g=\arg\max_a g(a)$，则：

$$
\max_a f(a) - \max_a g(a) \;=\; f(a_f) - g(a_f) \;\le\; |f(a_f)-g(a_f)| \;\le\; \max_a |f(a)-g(a)|
$$

（中间用了 $g(a_f)\le\max_a g(a)$ 把 $f(a_f)-\max_a g(a)$ 放大成 $f(a_f)-g(a_f)$。）对称地交换 $f,g$ 得到另一半，合并即 $|\max f-\max g|\le\max|f-g|$。直觉：**取 max 不会放大两个函数的差距**——max 是「1-Lipschitz」的。

### 定理：$T^*$ 是 $\gamma$-压缩

用无穷范数 $\|V\|_\infty=\max_s|V(s)|$ 度量价值函数的距离。对任意 $V,W$：

$$
\|T^*V - T^*W\|_\infty \;\le\; \gamma\,\|V-W\|_\infty
$$

**证明**：对每个状态 $s$，用上面的 max 引理，

$$
|(T^*V)(s)-(T^*W)(s)| \;\le\; \max_a \Big|\sum_{s'} P(s'\mid s,a)\,\gamma\,(V(s')-W(s'))\Big|
$$

把 $\gamma$ 提出、把 $|V(s')-W(s')|$ 放大成 $\|V-W\|_\infty$，再用 $\sum_{s'}P(s'\mid s,a)=1$：

$$
\le\; \gamma\,\|V-W\|_\infty \,\underbrace{\sum_{s'} P(s'\mid s,a)}_{=1} \;=\; \gamma\,\|V-W\|_\infty
$$

对 $s$ 取 max 即得。$\square$

**$\gamma<1$ 是全部关键**：每次套 $T^*$，价值函数之间的距离至少乘以 $\gamma$ 缩小。$\gamma=1$（无折扣）时 $T^*$ 不再压缩，有限 MDP 上可能不收敛——这就是为什么 DP 的收敛保证需要折扣。

### Banach 不动点定理：压缩映射必有唯一不动点

**定理（Banach, 1922）**：若 $T$ 是完备度量空间上的 $\gamma$-压缩，则：（i） 存在唯一不动点 $V^*$ 使 $T V^*=V^*$；（ii） 从任意初值 $V_0$ 出发，$V_k=T^kV_0$ 必收敛到 $V^*$。

证明思路：相邻两次的距离 $\|V_{k+1}-V_k\|=\|T V_k-TV_{k-1}\|\le\gamma\|V_k-V_{k-1}\|$，递推得 $\|V_{k+1}-V_k\|\le\gamma^k\|V_1-V_0\|$。对部分和用三角不等式，$\{V_k\}$ 是 Cauchy 列，完备性保证收敛；极限 $V^*$ 满足 $T V^*=V^*$（压缩映射的不动点唯一：若 $V^*,W^*$ 都是不动点，$\|V^*-W^*\|=\|TV^*-TW^*\|\le\gamma\|V^*-W^*\|$，而 $\gamma<1$ 蕴含 $\|V^*-W^*\|=0$）。

把 $T=T^*$ 代入：**值迭代必然收敛到唯一的最优价值 $V^*$**。这就是「为什么 DP 一定收敛」的严格答案。

### 误差界：值迭代离 $V^*$ 还有多远

Banach 定理只说「会收敛」，没说「多快」。两条经典误差界把收敛速度量化（见 Puterman 1994《Markov Decision Processes》、Sutton & Barto 2018 §4.4）：<Cite n={[3,5]} />

**先验界（a priori）**——只用初值估计上界：

$$
\|V_k - V^*\|_\infty \;\le\; \frac{\gamma^k}{1-\gamma}\,\|V_1 - V_0\|_\infty
$$

**后验界（a posteriori）**——用最近两次的差估计（这才是**实践中当停止准则用的界**）：

$$
\|V_k - V^*\|_\infty \;\le\; \frac{\gamma}{1-\gamma}\,\|V_k - V_{k-1}\|_\infty
$$

直觉：相邻两次的差 $\|V_k-V_{k-1}\|$ 是个**可观测量**（每次 sweep 都能算），把它乘以 $\gamma/(1-\gamma)$ 就包住真实误差。$\gamma=0.9$ 时这个放大因子是 9——所以实践中常设停止阈值 $\theta=10^{-3}$，因为停时真实误差已被压到 $\le 9\times10^{-3}$。先验界告诉我们**要达到误差 $\epsilon$ 至多需 $k\ge\lceil\log_\gamma(\epsilon(1-\gamma)/\|V_1-V_0\|)\rceil$ 次 sweep**——对 $\gamma=0.9$、$\epsilon=0.01$、$\|V_1-V_0\|\approx 1$ 大约 657 次，这与下方玩具观察到的「$0.9^k$ 几何衰减」一致。

下面的玩具把后验界跑出来，亲眼看它**每一轮都包住真实误差**：

### 策略迭代：Howard 1960 的有限步收敛

值迭代是「渐近收敛」（无穷步才精确到 $V^*$），策略迭代更强——**有限步必收敛**。这是 Howard 1960《Dynamic Programming and Markov Processes》的核心结论：

**定理（策略迭代有限步收敛）**：在有限 MDP 上，策略迭代至多在 $|\mathcal{A}|^{|\mathcal{S}|}$ 轮内收敛到最优策略。<Cite n={2} />

证明依赖两个事实：① **策略改进单调不减**——若 $\pi'$ 是对 $V^\pi$ 的贪心策略，则 $V^{\pi'}\ge V^\pi$（每个状态都不变好则变好）；② **确定性策略总数有限**——恰好 $|\mathcal{A}|^{|\mathcal{S}|}$ 个。单调不减 + 有限状态空间 $\Rightarrow$ 必然在有限步内到达「再改进也不变」的策略，此时 $\pi$ 已最优（若 $V^\pi=V^{\pi'}$ 则 $V^\pi$ 满足贝尔曼最优方程 $\Rightarrow V^\pi=V^*$）。

> ⚠️ **$|\mathcal{A}|^{|\mathcal{S}|}$ 是个松上界**：4×4 网格有 $4^{16}\approx4.3\times10^9$ 个确定性策略，但实际策略迭代通常**几轮**就锁定。下面玩具在同一网格上跑，亲眼看它多少轮收敛：

### 修正策略迭代：在 VI 与 PI 之间连续插值

值迭代（每轮做 1 次备份就改进）和策略迭代（评估做到底再改进）是两个极端。**修正策略迭代（Modified Policy Iteration, van Nunen 1976; Puterman & Shin 1978）**取中间：每轮做 $m$ 次部分评估（$m>1$）再做 1 次改进。<Cite n={[3,4]} />$m=1$ 退化成值迭代，$m\to\infty$ 退化成策略迭代——$m$ 是「评估深度」旋钮，在「单次备份便宜但粗糙」与「完整评估精确但昂贵」间权衡。它仍收敛（本质是 GPI），且往往比两端都快。

### VI vs PI：收敛速率的权衡

前面三小节分别给了 VI 的几何收敛界、PI 的有限步收敛定理、修正 PI 的插值定位。但它们各讲各的，没正面回答一个工程上最关心的问题：**给定一个 MDP，该选 VI 还是 PI？** 这一小节把三者的收敛速率与每步开销摆在一起，看清权衡的几何。

**值迭代：渐近几何收敛，速率 $\gamma$。** 前面误差界小节已证 $\|V_k-V^*\|_\infty\le\gamma^k\|V_0-V^*\|_\infty$——误差以 $\gamma$ 的速率几何衰减。要达到精度 $\varepsilon$，需

$$
k\;\ge\;\frac{\log(\varepsilon/\|V_0-V^*\|_\infty)}{\log\gamma}
$$

步。$\gamma$ 越接近 1（长程问题），收敛越慢：$\gamma=0.9$ 需约 66 步到 $10^{-3}$，$\gamma=0.99$ 需约 688 步。**每步开销** $O(|\mathcal S|^2|\mathcal A|)$（对每个 $(s,a)$ 扫一遍后继状态）。

**策略迭代：有限步收敛，每步贵。** Howard 1960 保证至多 $|\mathcal A|^{|\mathcal S|}$ 轮收敛，但实际通常几轮就锁定。**每步开销** $O(|\mathcal S|^3)$（策略评估解线性方程组 $(I-\gamma P_\pi)V=R_\pi$）。PI 的收敛不是「几何衰减」而是「策略单调改进直到稳定」——每轮要么策略严格变好，要么已最优。

**修正策略迭代：用有偏评估换步数。** 前面说 $m$ 是评估深度旋钮。关键洞见：修正 PI 的**策略**仍在有限步稳定（同 PI 的单调改进论证），但策略稳定时 $V$ **不一定**等于 $V^*$——$m$ 次 backup 只给了 $V^\pi$ 的近似，策略稳定意味着「贪心策略不再变」，可 $V$ 还在朝 $V^\pi$ 走的路上。这正是修正 PI 与 PI 的本质区别：**PI 每轮精确评估，策略稳定即 $V=V^*$；修正 PI 每轮部分评估，策略稳定时 $V$ 仍有偏**。$m$ 越大越接近 PI（偏差小但每步贵），$m=1$ 退化 VI（每步便宜但策略改进慢）。

**权衡的几何。** 三者的收敛曲线形状根本不同：

| 方法 | 收敛性质 | 每步开销 | 典型步数 | 适合 |
|---|---|---|---|---|
| 值迭代 | 渐近几何 $\gamma^k$ | $O(S^2A)$ | $\frac{\log\varepsilon}{\log\gamma}$ 步 | $S$ 大、$\gamma$ 不太接近 1 |
| 策略迭代 | 有限步单调改进 | $O(S^3)$ | 几轮（理论界 $A^S$ 极松） | $S$ 中等、需要精确 $V^*$ |
| 修正 PI | 策略有限步 + $V$ 有偏 | $O(mS^2A)$ | 几轮（$V$ 末误差 $\propto\gamma^m$） | $S$ 大、PI 的 $S^3$ 扛不住 |

直觉：VI 每步便宜但几何速率受 $\gamma$ 钳制，PI 每步贵但步数极少。当 $S$ 小时 PI 的 $S^3$ 可接受、几轮就收敛，选 PI；当 $S$ 大时 PI 的 $S^3$ 成为瓶颈，选 VI 或修正 PI。修正 PI 是工程折中——用 $m$ 次 backup 近似 $V^\pi$ 绕开 $S^3$ 求解，代价是 $V$ 的有偏。

### 异步 DP：不必整齐扫全表

前面所有算法都有一个隐含前提：**每一轮把状态表从头到尾扫一遍（sweep）**，而且用的是上一轮的旧值。这叫**同步 DP(synchronous DP)**，也叫 **Jacobi 迭代**——需要开两份数组（旧 $V_k$、新 $V_{k+1}$），一轮内所有 backup 都读同一份旧值。可现实里状态空间常常大到「扫一遍」本身就是奢侈：西洋双陆棋约 $10^{20}$ 个状态，连一次完整 sweep 都跑不完。**异步 DP（asynchronous DP, Bertsekas 1982 [9];Sutton & Barto §4.5 [5]）**打破了「整齐扫全表」的枷锁——它以**任意次序、原地（in-place）**更新单个状态，只要保证**每个状态被更新的次数趋于无穷**，就仍收敛到 $V^*$。<Cite n={[5,9]} />这不是近似，是等价的收敛保证，却给了两个自由度：**更新次序**与**更新频率**。

#### Gauss-Seidel：原地更新，让新值立刻传播

最小的一步改动：不开第二份数组，**原地覆写**——backup 一个状态就立刻写回，后面状态的 backup 就能读到这个刚更新的新值。这就是 **Gauss-Seidel 迭代**（前面「值迭代」小节的网格代码其实已经是原地版，只是没点名）。它与 Jacobi 的唯一区别是「读旧值还是读刚写的新值」，但收敛常常快近一倍——因为信息在**一轮之内**就能跨多个状态传播，而 Jacobi 要等下一轮。

关键洞见：**Gauss-Seidel 的收敛速度强烈依赖 sweep 的方向**。若价值需要从目标「倒灌」回起点，而你恰好**逆着信息流**扫（从起点扫到目标），那新值要下一轮才用得上，退化回 Jacobi；若**顺着信息流**扫（从目标扫回起点），一轮就能把价值灌穿整条链。下面在一条 50 状态的链上实测（目标在最右端，价值向左传播）：

#### 优先扫描（prioritized sweeping）：把算力花在刀刃上

Gauss-Seidel 仍在「扫全表」，只是原地。更激进的想法：**根本不按次序扫，而是永远先更新「最该更新的状态」**。哪个状态最该更新？**贝尔曼误差（Bellman error）** $|(\mathcal T V)(s) - V(s)|$ 最大的那个——它离自洽最远，更新它收益最大。更新完一个状态 $s$ 后，只有能**转移到 $s$ 的前驱状态（predecessors）**的贝尔曼误差会改变，于是把这些前驱按新误差压回优先队列。这就是 **优先扫描（prioritized sweeping, Moore & Atkeson 1993 [10];Peng & Williams 1993）**，后来直接被搬进免模型 RL（Sutton & Barto §8.4，配 Dyna 用）。<Cite n={10} />

#### 三种「什么时候 backup 哪个状态」的策略

异步 DP 把 DP 从「同步扫全表」解放成「一个 backup 调度问题」——同一个贝尔曼备份，换个**时机与次序**就是不同算法：

| 策略 | backup 次序 | 内存 | 何时最优 |
|---|---|---|---|
| Jacobi（同步 VI） | 全表，读旧值 | 两份数组 | 向量化/并行硬件（GPU 批量） |
| Gauss-Seidel | 全表，原地读新值 | 一份数组 | 有好的静态次序（顺信息流） |
| 优先扫描 | 贝尔曼误差最大者优先 | 一份 + 优先队列 + 前驱表 | 稀疏 MDP、价值局部剧变 |
| 实时 DP(RTDP) | 只更新智能体实际访问的状态 | 一份（按需） | 状态空间巨大、只关心可达子集 |

最后一行的**实时 DP（Real-Time DP, RTDP, Barto, Bradtke & Singh 1995 [11]）**把异步推到极致：根本不枚举状态，而是**让智能体从起点出发实际走轨迹，只 backup 脚踩到的状态**。<Cite n={11} />它是 DP 与在线 RL 的正式接榫点——一旦「只更新访问过的状态」，再把「已知模型的期望 backup」换成「采样得到的样本 backup」，你就从 DP 滑进了 Q-learning。这正是下一批教程（[时序差分](/tutorials/temporal-difference)、[蒙特卡洛](/tutorials/monte-carlo)）的起点：**异步 + 采样 = 免模型 RL**。

> 💡 **一句话串起来**：同步 DP → 异步 DP（去掉「整齐扫全表」）→ 实时 DP（去掉「枚举状态」）→ TD/Q-learning（再去掉「已知模型」）。每一步都在拆掉一个理想化假设，DP 的骨架（贝尔曼备份）始终不变，变的只是「在哪、何时、用什么信息」做这次备份。

### 线性规划：把 DP 写成优化问题

值迭代与策略迭代都是「**迭代逼近**」:$V_k\to V^*$ 是渐近过程，无穷步才精确。还有一种根本不同的解法——把求 $V^*$ 直接写成一个**线性规划（Linear Programming, LP）**，交给 LP 求解器一步到位。这是 DP 的第三种经典解法（d'Epenoux 1963;Puterman 1994 §6.4 [3][6]），也是「**精确有限步算法**」——不像 VI 那样渐近收敛。<Cite n={[3,6]} />

#### 原始 LP：$V^*$ 是满足贝尔曼不等式的最小元

贝尔曼最优方程 $V^*(s)=\max_a\bigl[r(s,a)+\gamma\sum_{s'}P(s'|s,a)V^*(s')\bigr]$ 里的 $\max$ 可以拆成一组**不等式**：对每个 $(s,a)$，

$$V^*(s)\;\ge\;r(s,a)+\gamma\sum_{s'}P(s'|s,a)\,V^*(s').$$

$V^*$ 恰好是「**满足全部这 $|\mathcal S|\cdot|\mathcal A|$ 条不等式的最小价值函数**」（逐状态最小）。于是求 $V^*$ 等价于原始 LP:

$$\min_{V}\;\sum_{s}\mu(s)\,V(s)\quad\text{s.t.}\quad V(s)\ge r(s,a)+\gamma\sum_{s'}P(s'|s,a)\,V(s')\;\;\forall s,a.$$

目标里的 $\mu$ 是任意严格正的初始状态分布（只给各状态权重，不影响最优解——因为 $V^*$ 是逐状态唯一最小的）。直觉是**上境图（epigraph）**：每条不等式给 $V(s)$ 一个下界，$V^*$ 是同时满足所有下界的「最低」价值面，LP 最小化把它压到恰好贴上贝尔曼包络。

> 💡 **为何最小化就拿到 $V^*$？** 任取一个满足所有不等式的 $V$，在每个状态 $s$ 它都 $\ge$ 贝尔曼备份的最大值，故 $V\ge V^*$ 逐状态成立；反过来 $V^*$ 自己满足所有不等式（最优动作取等）。所以可行域的逐状态最小元就是 $V^*$。LP 求解器找到的就是这个顶点。

#### 对偶 LP：占用测度 $x(s,a)$

对原始 LP 求对偶，得到一个关于**折扣状态-动作占用测度（discounted state-action occupancy measure）** $x(s,a)\ge 0$ 的 LP:

$$\max_{x\ge 0}\;\sum_{s,a}x(s,a)\,r(s,a)\quad\text{s.t.}\quad\sum_a x(s,a)-\gamma\sum_{s',a}P(s\mid s',a)\,x(s',a)=\mu(s)\;\;\forall s.$$

约束是**流守恒**：$\mu(s)$ 注入的质量，等于在 $s$ 被吸收的 $\sum_a x(s,a)$ 减去从别处 $s'$ 转移进 $s$ 的折扣流 $\gamma\sum P(s|s',a)x(s',a)$。$x(s,a)$ 的物理意义是「从 $\mu$ 出发，$(s,a)$ 被访问的折扣总次数」，$\sum_a x(s,a)$ 即折扣状态占用。

**强对偶定理**保证两个 LP 的最优值相等：

$$\min_V\;\mu^\top V\;=\;\max_x\;\sum_{s,a}x(s,a)\,r(s,a)\;=\;\mu^\top V^*.$$

#### 由对偶解恢复最优策略

对偶变量 $x^*(s,a)$ 不仅给目标值，还**直接编码最优策略**：由互补松弛，凡是 $x^*(s,a)>0$ 的动作就是最优动作，策略按占用质量归一化：

$$\pi^*(a\mid s)\;=\;\frac{x^*(s,a)}{\sum_{a'}x^*(s,a')}.$$

也就是说，**解一次 LP 同时拿到 $V^*$（原始变量）和 $\pi^*$（由对偶变量归一化）**——这是 LP 相对 VI/PI 的独特优势：后者只给 $V^*$，$\pi^*$ 还要再 argmax 一次。

#### 为何 LP 在实践中不常用：维度灾难

LP 看似「一步到位精确解」，却有致命的**规模问题**：原始 LP 有 $|\mathcal S|\cdot|\mathcal A|$ 条约束、对偶 LP 有 $|\mathcal S|\cdot|\mathcal A|$ 个变量。4×4 网格才 $16\times 4=64$，但围棋有 $10^{170}$ 状态——约束数直接爆炸。这就是为什么 LP 只在**小状态空间、需要精确解**时（如小型运筹优化、库存管理、作为理论分析工具）才用得上，大问题仍退回 VI/PI 或采样近似。

> 💡 **理论价值 > 实用价值**：LP 解 MDP 的真正意义在理论侧——它把「求最优策略」归约到一个**多项式时间可解的优化问题**（Papadimitriou & Tsitsiklis 1987 [7] 证明 MDP 最优策略在 P 类），给出「DP 不是 NP-hard」的复杂度保证；对偶变量 $x(s,a)$ 还把「策略」与「占用测度」联系起来，是后续 offline RL（策略约束 = 占用测度约束）、最大熵 RL（占用测度上的 KL 正则）等理论分析的基础工具。<Cite n={7} />

#### 三种解法对照

| 解法 | 求什么 | 求解器 | 精确性 | 复杂度 | 适用规模 |
|---|---|---|---|---|---|
| 值迭代 | $V^*$（迭代逼近） | 反复贝尔曼备份 | 渐近（$\gamma^k\to 0$） | $O(|\mathcal S|^2|\mathcal A|)$/sweep | 大状态空间 |
| 策略迭代 | $\pi^*$（评估+改进） | 解线性方程组 + 贪心 | 有限步（Howard 1960） | 每轮解方程 $O(|\mathcal S|^3)$ | 中等 |
| 线性规划 | $V^*$ + $\pi^*$（一次优化） | LP 求解器（单纯形/内点） | **精确有限步** | 多项式时间，但 $O(|\mathcal S||\mathcal A|)$ 维 | 小状态空间 |

> ⚠️ 注意「精确有限步」不等于「快」：LP 维度爆炸后，单纯形法虽多项式时间，常数项远大于 VI 的几次备份。三种解法是**精度-规模-速度**的不同权衡，没有谁绝对胜出——这正是「广义策略迭代」框架的用武之地：实践中混合使用（如 Actor-Critic 用采样近似 GPI），把「精确但贵」与「粗糙但快」按需调配。

### 广义策略迭代（GPI）：统一所有 RL 算法的框架

把「评估」和「改进」两步**任意交错**，只要两个过程都持续进行，就必然收敛到 $V^*/\pi^*$——这就是**广义策略迭代（Generalized Policy Iteration, GPI）**。<Cite n={5} />Sutton & Barto 用它统一整个 RL:

| 算法 | 评估深度 | 改进频率 |
|---|---|---|
| 值迭代 | 1 次备份 | 每 sweep |
| 修正策略迭代 | $m$ 次备份 | 每 $m$ sweep |
| 策略迭代 | 完整收敛 | 每轮 |
| [Actor-Critic](/tutorials/policy-gradient) | TD（0） 一步 | 每步 |
| [Q-learning](/tutorials/reinforcement-learning) | 一步采样 | 隐式每步 |

GPI 的洞见是：**评估与改进是两个相互竞争的力**——评估把 $V$ 拉向当前 $\pi$ 的真值，改进把 $\pi$ 拉向当前 $V$ 的贪心策略。两者都「开」着时，系统被推向二者的交集：最优 $V^*$ 与 $\pi^*$。这解释了为什么 Q-learning（免模型、采样、一步）和值迭代（已知模型、精确、全扫描）虽看起来天差地别，**结构上却是同一套 GPI**——只是评估用采样近似、改进隐式藏在 max 里。

## 函数逼近：当状态空间大到枚举不动

到此为止的所有解法——值迭代、策略迭代、修正策略迭代、线性规划——都有一个**隐藏前提**：$V(s)$ 和 $Q(s,a)$ 能当作长度 $|\mathcal S|$ 或 $|\mathcal S||\mathcal A|$ 的**表格**存下来。LP 的对偶变量 $x(s,a)$、值迭代的 sweep、策略迭代的评估步，无一不是逐状态枚举。可现实问题的状态空间几乎总是天文数字：围棋 $10^{170}$ 种局面、机器人关节角度连续、Atari 像素 $256^{84\times84\times4}$。表格存不下，贝尔曼备份扫不动。

出路是**函数逼近（function approximation）**：用一个参数化函数 $Q_\theta(s,a)\approx Q^*(s,a)$ 代替表格，其中 $\theta$ 的维度 $d$ 远小于 $|\mathcal S||\mathcal A|$。最简单的形式是**线性逼近** $Q_\theta(s,a)=\phi(s,a)^\top w$，其中 $\phi(s,a)\in\mathbb R^d$ 是人为设计的**特征向量**，$w\in\mathbb R^d$ 是待学权重。[DQN](/tutorials/dqn) 用神经网络代替线性特征，能力更强但理论保证变弱。下面这条线性路线，是「DP 的精确表格解」与「DQN 的神经黑箱」之间的**理论桥梁**——它保留了 DP 的可证明性，又跨过了状态爆炸。

### linear MDP：让函数逼近「可证明」的关键假设

直接把表格 DP 里的 $Q(s,a)$ 换成 $\phi(s,a)^\top w$ 会怎样？贝尔曼最优方程 $Q^*(s,a)=r(s,a)+\gamma\sum_{s'}P(s'|s,a)\max_{a'}Q^*(s',a')$ 右端的 $\sum_{s'}P(s'|s,a)V^*(s')$ 一般**不再是 $\phi(s,a)$ 的线性函数**——即使 $V^*$ 恰好线性，$P(s'|s,a)$ 这个转移核本身对 $\phi$ 也未必线性。于是线性 $Q$ 与贝尔曼方程不自洽，没有收敛保证（这正是 [DQN 致命三态](/tutorials/dqn)发散的根源）。

Jin, Yang, Wang & Jordan (2020) [8] 给出了一个让线性逼近重新自洽的假设——**linear MDP**:<Cite n={8} />

> **Assumption A(linear MDP)**。 对每一步 $h\in[H]$，存在 $d$ 个未知的（符号）测度 $\boldsymbol\mu_h=(\mu_h^{(1)},\dots,\mu_h^{(d)})$ over $\mathcal S$ 和一个未知向量 $\boldsymbol\theta_h\in\mathbb R^d$，使得对任意 $(s,a)$：
> - 转移 $P_h(\cdot\mid s,a)=\langle\phi(s,a),\,\boldsymbol\mu_h(\cdot)\rangle=\sum_{i=1}^d\phi_i(s,a)\,\mu_h^{(i)}(\cdot)$
> - 奖励 $r_h(s,a)=\langle\phi(s,a),\,\boldsymbol\theta_h\rangle$

也就是说，**转移核和奖励都线性地分解在同一个特征 $\phi(s,a)$ 上**。直观理解：每个 $\mu_h^{(i)}$ 是一张「原型转移分布」，$\phi_i(s,a)$ 是这张原型在 $(s,a)$ 处的权重，真实转移 $P(\cdot|s,a)$ 是这些原型的加权混合；奖励同理。

### 结构结果：价值函数自动线性（Proposition 2.3）

linear MDP 假设的威力在于一个看似平凡的推论——**任何**价值函数的贝尔曼备份都自动线性：

$$
\sum_{s'}P(s'|s,a)\,V(s')=\int V(s')\,\langle\phi(s,a),d\boldsymbol\mu_h(s')\rangle=\Big\langle\phi(s,a),\,\underbrace{\int V(s')\,d\boldsymbol\mu_h(s')}_{=:\,\boldsymbol w_V}\Big\rangle
$$

内积结构让 $V$ 从积分号里「提」了出来，剩下的是个只依赖 $V$ 与 $\boldsymbol\mu_h$ 的固定权重 $\boldsymbol w_V$。于是贝尔曼最优方程右端 $r+\gamma PV^*$ 对 $\phi$ 线性，故 $Q^*$ 本身也线性：

> **Proposition 2.3**。 在 linear MDP 下，对任意策略 $\pi$，存在权重 $\boldsymbol w_h^\pi$ 使得 $Q_h^\pi(s,a)=\langle\phi(s,a),\boldsymbol w_h^\pi\rangle$。

这把「价值函数属于什么函数空间」从 $|\mathcal S||\mathcal A|$ 维表格降到了 $d$ 维线性空间——**线性逼近与贝尔曼方程重新自洽**，这正是表格 DP 收敛性论证能搬过来的根基。

### LSVI-UCB：线性版「值迭代 + 乐观探索」

有了线性结构，价值迭代可以照搬，只需把「表格 backup」换成「最小二乘回归」——这就是 **LSVI(Least-Squares Value Iteration)**:

1. 从 $V_H=\mathbf 0$ 出发，向后递推 $h=H-1,\dots,0$；
2. 第 $h$ 步收集到数据 $\{(s_t,a_t,r_t,s'_t)\}$，用它们的最小二乘解拟合 $w_h$：
$$
\boldsymbol w_h=\Big(\lambda I+\sum_t\phi(s_t,a_t)\phi(s_t,a_t)^\top\Big)^{-1}\sum_t\phi(s_t,a_t)\big(r_t+V_{h+1}(s'_t)\big)
$$
   这正是岭回归的闭式解，$\Lambda_h:=\lambda I+\Phi^\top\Phi$ 是（正则化的）经验二阶矩；
3. 估出 $Q_h(s,a)=\phi(s,a)^\top\boldsymbol w_h$，$V_h(s)=\max_a Q_h(s,a)$，回到第 2 步递推 $h-1$。

但光有 LSVI 还不够——它需要数据，而数据靠探索收集。朴素 $\varepsilon$-greedy 在线性逼近下没有 regret 保证。**LSVI-UCB** 给 $Q$ 估加一个**置信椭球 bonus**驱动乐观探索：

$$
Q_h(s,a)=\phi(s,a)^\top\boldsymbol w_h+\beta\sqrt{\phi(s,a)^\top\Lambda_h^{-1}\phi(s,a)}
$$

第二项的几何含义是置信椭球的「半径方向」：在数据稀疏的方向 $\phi^\top\Lambda^{-1}\phi$ 大（不确定，多探索），在数据密集的方向小（已摸清，少探索）。这正是 [bandit 置信椭球](/tutorials/multi-armed-bandit)在状态空间上的推广。$\beta$ 的取值由自归一化鞅界给出（Abbasi-Yadkori et al. 2011），保证高概率覆盖真值。

### regret 保证：与状态数无关

在 linear MDP 假设下，LSVI-UCB 的 regret 有如下界（Jin et al. 2020 [8]）：<Cite n={8} />

$$
\mathrm{Regret}(K)=\tilde O\!\Big(\sqrt{d^3 H^3 T}\Big),\qquad T=KH
$$

其中 $K$ 是回合数、$H$ 是每回合步数、$T=KH$ 是总步数。**这个界只依赖特征维度 $d$ 和视野 $H$，与状态-动作空间大小 $|\mathcal S||\mathcal A|$ 无关**——这是 linear MDP 的全部意义：用 $d$ 维特征把「表格 DP 的 $O(\sqrt{|\mathcal S||\mathcal A|H^3T})$ regret」压缩成与状态数脱钩的 $O(\sqrt{d^3H^3T})$。对照表格设定（$d=|\mathcal S||\mathcal A|$）两界同阶，说明线性版严格推广了表格理论。

### 与 DQN 的对照：可证明的线性 vs 黑箱的神经

| 维度 | 表格 DP(VI/PI/LP) | linear MDP + LSVI-UCB | DQN（神经逼近） |
|---|---|---|---|
| 价值函数表示 | 长度 $\lvert\mathcal S\rvert\lvert\mathcal A\rvert$ 表格 | $d$ 维线性 $Q=\phi^\top w$ | 神经网络 $Q_\theta(s,a)$ |
| 状态空间 | 必须可枚举 | 任意（只需特征 $\phi$） | 任意（网络吃原始输入） |
| 表达能力 | 精确但维度爆炸 | 线性族（受 linear MDP 假设约束） | 通用近似（几乎任意 $Q^*$） |
| regret 保证 | $O(\sqrt{\lvert\mathcal S\rvert\lvert\mathcal A\rvert H^3T})$ | $\tilde O(\sqrt{d^3H^3T})$，**与 $\lvert\mathcal S\rvert\lvert\mathcal A\rvert$ 无关** | 无（致命三态可能发散） |
| 适用场景 | 棋盘/库存等小问题 | 结构清晰、特征可设计的中等问题 | 围棋/Atari/机器人等高维复杂问题 |

这条谱系把本篇的表格解法、本节的线性理论、与 [DQN](/tutorials/dqn) 的深度方法串成一条「**精确-可证明-黑箱**」的递进线：**DP 给地基，linear MDP 给可证明的桥梁，DQN 给实用但失控的上层**。linear MDP 的价值不在它本身能解围棋（特征 $\phi$ 难设计），而在它划清了「函数逼近下 RL 何时仍有理论保证」的边界——这是理解 DQN 为何会发散、以及现代 RL 理论为何走向 [linear MDP 的各种推广](/tutorials/dqn)（线性 mixture model、神经网络 NTK 近似等）的起点。

## 典型案例：DP 在真实系统里的位置

| 场景 | 为什么用/不用 DP |
|---|---|
| **棋盘/网格等已知规则的小问题** | 直接 DP 精确求解，无需学习 |
| **库存管理、最优控制** | 状态可枚举、模型可写出 → 价值/策略迭代经典应用 |
| **围棋、Atari、机器人** | 状态爆炸或模型未知 → 退回 Q-learning / DQN 等**采样近似** |
| **AlphaZero** | 用学到的模型 + 搜索做「近似 DP」——[自我博弈](/tutorials/reinforcement-learning#常见问题-faq)里的 MCTS 就是一种前瞻规划 |

> 💡 记住这条主线：**DP = 已知模型、精确扫描；TD/Q-learning = 未知模型、采样近似。** 贝尔曼方程是二者共同的心脏——Q-learning 更新式里的 $r+\gamma\max_{a'}Q(s',a')$，正是贝尔曼最优方程的采样版。

## 常见问题 FAQ

**Q：既然 DP 能精确求解，为什么还要 Q-learning?**
DP 有两个硬前提：**模型已知**且**状态可枚举**。现实里两者常常不满足——你不知道下棋对手会怎么走（模型未知），围棋有 $10^{170}$ 种局面（状态爆炸）。这时只能用采样（Q-learning）+ 函数逼近（[DQN](/tutorials/dqn)）去近似 DP 做不到的精确扫描。

**Q：价值迭代和策略迭代该选哪个？**
状态空间不大时都行。价值迭代实现最简单；策略迭代每轮更贵但收敛轮数极少，状态多、评估可高效求解时更划算。二者可折中为「广义策略迭代」——评估不必跑到完全收敛就去改进。

**Q：「广义策略迭代（GPI）」是什么？**
把「评估」和「改进」两步交替进行的通用模式。价值迭代是「评估只做一步就改进」的极端，策略迭代是「评估做到底再改进」的极端，几乎所有 RL 算法（含 Actor-Critic）都落在这条谱系上。

**Q：为什么 DP 一定收敛？**
贝尔曼最优算子 $T^*$ 是 $\gamma$-压缩映射：$\|T^*V-T^*W\|_\infty\le\gamma\|V-W\|_\infty$（$\gamma<1$）。由 Banach 不动点定理，$T^*$ 有唯一不动点 $V^*$，且从任意初值出发反复套用 $T^*$ 必收敛到 $V^*$。收敛速度有两条误差界：先验界 $\|V_k-V^*\|\le\frac{\gamma^k}{1-\gamma}\|V_1-V_0\|$、后验界 $\|V_k-V^*\|\le\frac{\gamma}{1-\gamma}\|V_k-V_{k-1}\|$（后者是实践中当停止准则用的界）。策略迭代更强：有限 MDP 上至多 $|\mathcal{A}|^{|\mathcal{S}|}$ 轮内必收敛（Howard 1960）。详见上面「收敛理论」一节。

**Q：既然有「精确有限步」的线性规划解法，为什么还要值迭代？**
LP 把求 $V^*$ 写成一次优化，理论上「一步到位」且多项式时间可解（Papadimitriou & Tsitsiklis 1987 证明 MDP 在 P 类）。但 LP 的约束数 = $|\mathcal S|\cdot|\mathcal A|$：4×4 网格才 64 条，围棋 $10^{170}$ 状态直接爆炸。值迭代虽是渐近收敛（无穷步逼近 $V^*$），但每 sweep 只需 $O(|\mathcal S|^2|\mathcal A|)$ 且可增量、可采样近似（Q-learning 就是采样版备份），scalability 远胜 LP。所以 LP 只在**小状态空间要精确解**时用得上，大问题必退回 VI/PI。LP 的真正价值在理论侧：复杂度保证 + 对偶占用测度 $x(s,a)$ 是 offline RL / 最大熵 RL 分析的基础工具。

## 小结

| 概念 | 含义 |
|---|---|
| 动态规划 | 已知模型时，用贝尔曼方程精确求解最优策略 |
| 贝尔曼期望方程 | 评估固定策略的价值 $V^\pi$ |
| 贝尔曼最优方程 | 带 $\max$，刻画最优价值 $V^*$ |
| 价值迭代 | 反复做最优备份直到 $V$ 收敛，再贪心抽策略 |
| 策略迭代 | 评估 ↔ 改进交替，直到策略稳定 |
| 贝尔曼算子 $T^*$ | 一次全空间备份；是 $\gamma$-压缩映射 $\Rightarrow$ 有唯一不动点 $V^*$ |
| Banach 不动点定理 | 压缩映射必有唯一不动点，反复套用必收敛——DP 收敛的理论根基 |
| 误差界 | 先验 $\frac{\gamma^k}{1-\gamma}\lVert V_1-V_0\rVert$、后验 $\frac{\gamma}{1-\gamma}\lVert V_k-V_{k-1}\rVert$（停止准则） |
| 策略迭代有限步收敛 | 单调改进 + 有限策略数 $\Rightarrow$ 至多 $\lvert\mathcal{A}\rvert^{\lvert\mathcal{S}\rvert}$ 轮（Howard 1960） |
| 修正策略迭代 | VI 与 PI 的折中：每轮 $m$ 次部分评估（van Nunen 1976; Puterman & Shin 1978） |
| 线性规划 | 把求 $V^*$ 写成 LP：原始 $\min\mu^\top V$ s.t. 贝尔曼不等式 / 对偶 $\max\sum x\,r$ s.t. 流守恒；精确有限步，但 $\lvert\mathcal S\rvert\lvert\mathcal A\rvert$ 维度爆炸（d'Epenoux 1963;Puterman 1994） |
| 广义策略迭代 GPI | 评估与改进任意交错，只要都继续就收敛——统一所有 RL 算法的框架 |
| 与 Q-learning 的关系 | Q-learning = 模型未知时用采样近似贝尔曼备份 |

> 🎯 一句话记住：**动态规划是「上帝视角」的强化学习——知道全部规则，就能不试错、直接把最优策略算出来；而现实中模型未知、状态爆炸，才逼出了下一篇[蒙特卡洛方法](/tutorials/monte-carlo)（纯靠经验回报）与[时序差分学习](/tutorials/temporal-difference)（边走边学、免模型），以及 [Q-learning](/tutorials/reinforcement-learning)、[DQN](/tutorials/dqn) 这些采样近似的方法。**
