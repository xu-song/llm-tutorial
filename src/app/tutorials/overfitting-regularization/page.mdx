# 🎚️ 过拟合与正则化

[决策树长太深](/tutorials/decision-tree)、[KNN 的 K 太小](/tutorials/knn-classification)、神经网络太大……你已经在多篇教程里撞见同一个幽灵：**过拟合**。这一篇把它讲透，并给出最通用的解药 —— **正则化**。

> 过拟合就像一个只会背题、不懂原理的学生：平时做过的题全对（训练集 100%），一上考场遇到新题就崩（测试集很差）。

## 欠拟合 vs 过拟合：阶数的故事

模型太简单，抓不住规律 → **欠拟合**；模型太复杂，把噪声也当规律学进去 → **过拟合**。两者之间存在一个「刚刚好」的甜蜜点。

<OverfittingExplorer />

你会看到三个阶段：

- **阶数 1~2（欠拟合）**：直线/抛物线太死板,训练和测试误差都高
- **阶数 3~4（刚刚好）**：曲线贴合真实趋势,两个误差都低且接近
- **阶数 8~9（过拟合）**：曲线疯狂扭曲穿过每个训练点（训练误差→0）,却在测试点上大错特错

**关键现象：训练误差随复杂度单调下降，但测试误差先降后升 —— 这条 U 形曲线就是过拟合的指纹。**

「太简单→欠拟合、太复杂→过拟合、中间有甜蜜点」是机器学习的普适图景。下面这张来自经典方法综述的三联图，正是三个阶段的教科书示意：左图线性模型欠拟合、中图适中、右图高阶模型过拟合（曲线为迁就每个训练点而剧烈扭曲）：

## 偏差-方差权衡

这个 U 形背后是机器学习的核心理论 ——**偏差-方差权衡（Bias-Variance Tradeoff）**：

| | 偏差（Bias） | 方差（Variance） |
|---|---|---|
| 含义 | 模型假设太死，系统性偏离真相 | 模型太敏感，随训练数据剧烈波动 |
| 表现 | **欠拟合** | **过拟合** |
| 怎么办 | 用更复杂的模型 | 简化模型 / 正则化 / 加数据 |

总误差 ≈ 偏差² + 方差 + 不可消除的噪声。降低一个常常抬高另一个，目标是找到**总和最小**的平衡点。

## 正则化：给复杂度上一道「闸」

与其手动挑模型复杂度，不如让模型**自动**抑制过拟合。**正则化**的思路：在损失函数里加一个**惩罚项**，逼模型不要把权重学得太大（大权重 = 曲线陡峭 = 容易扭曲）。

$$
L_{\text{总}} = \underbrace{L_{\text{数据}}}_{\text{拟合误差}} + \lambda \underbrace{\sum_i w_i^2}_{\text{惩罚大权重}}
$$

- **L2 正则（岭回归 Ridge）**：惩罚 $\sum w_i^2$,把权重压小但不归零
- **L1 正则（Lasso）**：惩罚 $\sum |w_i|$,能把部分权重压成**恰好 0**（自动特征选择）
- $\lambda$ 是强度旋钮：越大越「保守」（防过拟合），太大则欠拟合

下面看正则化如何驯服一个高阶多项式 —— 同样 9 阶，加了正则化后曲线立刻平滑下来：

import numpy as np
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline

rng = np.random.RandomState(0)

y = np.sin(2 * np.pi * X).ravel() + rng.randn(15) * 0.15

def fit_score(model):
    model.fit(X, y)
    return np.sqrt(np.mean((model.predict(X) - y) ** 2))

print(f"L2 正则权重最大绝对值: {np.abs(ridge_w).max():.1f}  (被显著压小)")

## 防过拟合的常用手段

正则化只是其中一招，实战中常组合使用：

- **加正则项**：Ridge(L2)、Lasso(L1)、弹性网络（两者结合）
- **简化模型**：决策树限制 `max_depth`、减少神经网络层数/神经元
- **更多数据 / 数据增强**：样本越多越难过拟合（图像可翻转、裁剪扩充）
- **Dropout**：训练神经网络时随机「关闭」部分神经元,逼网络不依赖个别特征

- **早停（Early Stopping）**：监控验证误差,一旦回升就停止训练
- **交叉验证**：用 K 折交叉验证可靠地选超参数（$\lambda$、`max_depth` 等）

## 典型应用场景

- **高维线性模型**：特征数 ≥ 样本数时,Ridge/Lasso 几乎是必需品
- **特征选择**：Lasso 把无关特征权重压成 0,自动挑出重要特征
- **深度学习**：Dropout + 权重衰减（本质是 L2）是标配
- **金融/基因数据**：成千上万特征、样本有限,正则化防止「学到噪声」
- **超参数调优**：用交叉验证网格搜索最佳正则强度

## 常见问题 FAQ

**Q：L1 和 L2 正则到底怎么选？**
想要**特征选择**（把不重要的特征权重归零、得到稀疏模型）用 L1(Lasso)；只想**平滑地压小**所有权重、防过拟合用 L2(Ridge)。不确定时可用弹性网络（ElasticNet）兼顾两者。

**Q：正则化强度 λ（sklearn 里的 alpha）怎么定？**
没有理论最优值，用**交叉验证**在一组候选值里挑验证误差最小的。`RidgeCV`、`LassoCV` 能自动完成。

**Q：为什么正则化前要标准化特征？**
惩罚项对所有权重一视同仁，若特征量纲不同，大尺度特征的权重天然偏小、被「少罚」，不公平。标准化后正则化才作用均匀。

**Q：过拟合一定是坏事吗？能彻底消除吗？**
过拟合意味着泛化差，通常要避免。但无法「彻底消除」—— 目标是在偏差和方差间找平衡，而非把训练误差降到 0。训练误差为 0 往往正是过拟合的信号。

**Q：增加数据为什么能防过拟合？**
模型要「记住」全部训练点才能过拟合；数据越多越难死记，模型被迫去学真正的普遍规律。数据充足时，即使复杂模型也不易过拟合。

## 小结

| 概念 | 说明 |
|---|---|
| 欠拟合 | 模型太简单（高偏差），训练/测试都差 |
| 过拟合 | 模型太复杂（高方差），训练好、测试崩 |
| 偏差-方差权衡 | 总误差 ≈ 偏差² + 方差 + 噪声，求平衡 |
| 正则化 | 损失里加惩罚项，抑制大权重 |
| L1 / L2 | L1 稀疏（选特征），L2 平滑压小 |
| 其他手段 | 加数据、Dropout、早停、剪枝、交叉验证 |

> 🎯 一句话：**过拟合是模型在「死记」而非「理解」。** 正则化通过惩罚复杂度，逼模型学普遍规律 —— 它是贯穿线性模型、树、神经网络的通用解药。
