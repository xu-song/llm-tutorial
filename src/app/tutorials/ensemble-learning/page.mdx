# 🌲 集成学习:随机森林与提升

[决策树](/tutorials/decision-tree)那篇留了个尾巴:单棵树容易[过拟合](/tutorials/overfitting-regularization)、对数据微小变化很敏感。**集成学习(Ensemble Learning)** 的思路一句话就能说清:**与其信一个专家,不如让一群人投票。** 把很多棵不完美的树组合起来,效果远超任何单棵 —— 随机森林和 XGBoost 至今仍统治着表格数据竞赛。

> 三个臭皮匠,顶个诸葛亮。单个模型会犯错,但多个模型的错误往往相互抵消。

## 核心直觉:平均能抵消方差

单棵决策树是**高方差**的:换一批训练数据,它可能长得完全不同。但如果训练很多棵**各不相同**的树,让它们的预测**平均(回归)或投票(分类)**,随机误差会相互抵消,得到又稳又准的结果。

你会发现:N=1 时绿线和灰线一样乱;N 越大,平均曲线越平滑、越接近真实 —— 误差随 N 稳步下降。这就是集成的魔力:**用数量换稳定**。

## 两大流派:Bagging 与 Boosting

集成主要有两条技术路线:

| | **Bagging(装袋)** | **Boosting(提升)** |
|---|---|---|
| 代表 | 随机森林 | AdaBoost、GBDT、XGBoost |
| 训练方式 | 各树**并行**、相互独立 | 各树**串行**,后一棵纠正前一棵的错 |
| 主要降低 | 方差(防过拟合) | 偏差(提升精度) |
| 每棵树 | 强(深树) | 弱(浅树,如「树桩」) |
| 特点 | 稳健、不易过拟合、可并行 | 精度极高,但需仔细调参防过拟合 |

## 随机森林:两重随机

**随机森林 = 很多决策树 + 两重随机**,确保每棵树都「不一样」(否则平均没意义):

1. **样本随机(Bootstrap)**:每棵树用**有放回抽样**得到的不同训练子集
2. **特征随机**:每次分裂只从**随机一部分特征**里挑最优切分

下面用 scikit-learn 对比单棵树和随机森林在带噪声数据上的表现:

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split

X, y = make_moons(n_samples=400, noise=0.35, random_state=0)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=0)

tree = DecisionTreeClassifier(random_state=0).fit(Xtr, ytr)
forest = RandomForestClassifier(n_estimators=200, random_state=0).fit(Xtr, ytr)

print(f"单棵决策树   训练 {tree.score(Xtr,ytr):.2f}  测试 {tree.score(Xte,yte):.2f}")
print(f"随机森林     训练 {forest.score(Xtr,ytr):.2f}  测试 {forest.score(Xte,yte):.2f}")
print("\\n单棵树训练近满分却测试差(过拟合);森林测试更高、差距更小(方差被抹平)。")
`} />

Breiman 在随机森林原始论文里,把集成效果归结为两个量:**单棵树的强度(strength)**与**树与树之间的相关性(correlation)** —— 强度越高泛化误差上限越低,相关性越高误差上限越大。下图就是论文中的经典分析:左图展示误差上限如何随强度与相关系数变化,右图是在一个数据集上,随机森林的测试误差与袋外(OOB)误差随「每次分裂可选特征数」变化的曲线:

## 梯度提升:XGBoost 的威力

**Boosting** 换了个思路:让每棵新树专门去**拟合前面所有树累计的残差(错误)**,一步步「提升」。梯度提升树(GBDT)及其高效实现 **XGBoost / LightGBM** 是 Kaggle 表格赛的常胜将军。它的核心是一个**串行**循环——每一轮都盯着「当前还没预测对的部分」再加一棵小树:

```
# 梯度提升 (GBDT) 伪代码
F = 初始预测(常数, 如 y 的均值)      # 当前集成模型
for m in range(树的数量):
    r = y - F(X)                      # 残差 = 真实值 - 当前预测
                                      #  (更一般地: r = -∂损失/∂F,故名"梯度"提升)
    h = 训练一棵弱树拟合 (X, r)         # 让新树去学"还差多少"
    F = F + lr * h                    # 以学习率 lr 累加进集成(缩步防过拟合)
# 最终预测 = 所有树的加权和
```

XGBoost 原始论文的首图正是这个思想的「全家福」:每轮加入一棵回归树去拟合当前残差,若干轮之后,所有树的预测**相加**就是最终模型:

对比 Bagging(随机森林):Bagging 让许多**独立**的高方差树**并行**取平均、压方差;Boosting 让许多弱树**串行**接力、每棵纠正前面的偏差。GBDT 及其高效实现 **XGBoost / LightGBM** 是 Kaggle 表格赛的常胜将军:

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.ensemble import GradientBoostingClassifier, RandomForestClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score

X, y = make_classification(n_samples=500, n_features=20, n_informative=8,
                           random_state=0)

rf = RandomForestClassifier(n_estimators=100, random_state=0)
gb = GradientBoostingClassifier(n_estimators=100, random_state=0)

print("随机森林   5 折交叉验证:", cross_val_score(rf, X, y, cv=5).mean().round(3))
print("梯度提升树 5 折交叉验证:", cross_val_score(gb, X, y, cv=5).mean().round(3))
`} />

> 💡 想要极致精度、且愿意调参,选梯度提升(XGBoost);想要开箱即用、稳健少调参,选随机森林。二者都远强于单棵树。

## 特征重要性:附赠的可解释性

集成树还能告诉你**哪些特征最重要** —— 这在实际业务里极有价值:

<CodeRunner
  packages={["scikit-learn"]}
  defaultCode={`
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris

iris = load_iris()
rf = RandomForestClassifier(n_estimators=200, random_state=0).fit(iris.data, iris.target)

print("特征重要性(越高越关键):")
for name, imp in sorted(zip(iris.feature_names, rf.feature_importances_),
                        key=lambda t: -t[1]):
    bar = "█" * int(imp * 50)
    print(f"  {name:20s} {imp:.3f} {bar}")
`} />

## 典型应用场景

- **表格数据竞赛**:Kaggle 上结构化数据赛,XGBoost/LightGBM 几乎是默认首选
- **金融风控 / 信用评分**:随机森林稳健、能给特征重要性,便于合规解释
- **推荐 / 点击率预估**:GBDT 曾是工业界 CTR 模型的主力
- **医疗、生物**:小样本高维下,集成树往往比单模型更可靠
- **特征筛选**:先用随机森林的特征重要性挑关键特征,再喂给别的模型

## 常见问题 FAQ

**Q:随机森林里的树越多越好吗?**
基本是的 —— 树越多,预测方差越小、越稳定,测试误差会**单调收敛而不再上升**(注意:这不等于「随机森林绝不过拟合」——若单棵树本身过深已过拟合,加树只是让误差稳定在那个水平,不会变得更好)。收益递减、还变慢,所以常用几百棵即可。Boosting 则不同,树太多会过拟合,需要早停。

**Q:为什么随机森林要「特征随机」?**
若不限制,每棵树都会优先选那个最强特征,导致所有树高度相似,平均起来没意义。随机选特征子集**强制树的多样性**,多样性才是集成有效的前提。

**Q:Bagging 和 Boosting 到底怎么选?**
随机森林(Bagging):稳健、易用、能并行、几乎不用怎么调参,适合快速拿到好结果;梯度提升(Boosting):精度上限更高,但需仔细调学习率、树深、树数防过拟合。先上随机森林做基线,再考虑 XGBoost 冲精度。

**Q:集成模型还可解释吗?**
比单棵树差(看不到一张清晰流程图),但能给出**特征重要性**;需要更细的解释可用 SHAP 值。总体上是「用可解释性换精度」。

**Q:为什么深度学习没取代 XGBoost?**
在**表格/结构化数据**上,梯度提升树往往仍优于神经网络,且训练快、调参少、不需要海量数据。深度学习的主场是图像、文本、语音等非结构化数据。

## 小结

| 要点 | 说明 |
|---|---|
| 核心 | 组合多个弱模型 → 强模型(众树成林) |
| Bagging | 并行、独立训练,降**方差**(随机森林) |
| Boosting | 串行、纠错,降**偏差**(XGBoost/GBDT) |
| 随机森林 | 决策树 + 样本随机 + 特征随机 |
| 优点 | 精度高、稳健、给特征重要性 |
| 代价 | 可解释性下降、模型更大更慢 |

> 🎯 一句话:**集成学习让一群平庸的模型投票,得到远超个体的结果。** 随机森林靠「平均」降方差、XGBoost 靠「纠错」降偏差,它们是表格数据上至今难以撼动的王者。
